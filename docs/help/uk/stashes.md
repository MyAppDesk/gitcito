# Стеші

Стешування в Gitcito — це не «все або нічого».

| Дія | Що вона робить |
|---|---|
| **Стеш** | Усе, разом із невідстежуваними файлами, якщо хочете, і з повідомленням |
| **Частковий стеш** | Позначте лише потрібні файли; за бажанням `--keep-index` |
| **Застосувати / Витягнути** | Увесь стеш або **лише частину його файлів** |
| **Стеш → гілка** | `git stash branch` — запасний вихід, коли стеш не хоче застосовуватися чисто |

Вибраний стеш показує свої файли та діфи — точно так само, як коміт.

![Частковий стеш: позначте лише ті файли, що мають туди потрапити](../../screenshots/stash-partial.webp)

## Коли стеш не застосовується

Якщо застосування стешу затерло б невідстежувані файли, git зупиняється. Gitcito
пропонує перезаписати їх і спробувати ще раз, замість того щоб лишити вас
самотужки згадувати потрібне заклинання.

Якщо дерево відійшло надто далеко, **стеш → гілка** відтворює гілку, з якої стеш
було взято, чисто застосовує його там і прибирає сам стеш.

## Не плутайте зі знімками

[WIP-знімки](recovery.md) автоматичні й приховані; стеші — навмисні й показані у
списку. Знімки ніколи не чіпають ваш список стешів.
