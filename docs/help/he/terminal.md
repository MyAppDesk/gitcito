# טרמינל משולב

PTY אמיתי (xterm + node-pty), לא מריץ פקודות. המעטפת שלכם, השורה שלכם, הכינויים
שלכם.

![הטרמינל המשולב](../../screenshots/terminal.webp)

- **כמה לשוניות לכל מאגר**, כל אחת מתחילה בתיקייה של אותו מאגר.
- עגנו אותו **מתחת** לגרף או כ**עמודה ימנית**; הפאנל זוכר את גודלו.
- נראות הטרמינל היא לכל מאגר בנפרד: מעבר ללשונית שמעולם לא פתחה אחד משאיר אותו
  סגור.
- לשוניות נותנות לעצמן שם לפי מה שרץ בהן.
- כיווץ רשימת הטרמינלים מקטין אותה ל**מסילה**: סמל אחד לכל טרמינל (טרמינלים
  מפוצלים מציגים מפת פאנלים מוקטנת), לחיצה כדי להחליף, לחיצה ימנית לתפריט הרגיל
  של שינוי שם/פיצול/הריגה.
- **גררו טרמינל אחד על אחר** ברשימה כדי למזג אותם לקבוצה מפוצלת. כל טרמינל
  שומר על שמו כחלונית; הקבוצה הממוזגת מקבלת שם ממוספר חדש.

![שני פאנלים מפוצלים זה לצד זה בקבוצת טרמינלים אחת](../../screenshots/terminal-split.webp)

כל מה שאתם מריצים כאן בלתי נראה לנעילה של Gitcito עצמו, ולכן `git rebase` ארוך
שהוקלד ביד ולחיצה בממשק עדיין יכולים להתנגש — האפליקציה מרעננת מהדיסק כשהטרמינל
משנה משהו.
