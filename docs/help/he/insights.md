# תובנות

לוח מחוונים שנבנה מהיסטוריית ה־Git שלכם — בלי שירות, בלי חשבון, רק `git log`
שנקרא מקומית. פתחו אותו מגלגל הגדרות המאגר שליד כלי סרגל הכלים.

![לוח המחוונים של התובנות](../../screenshots/insights.webp)

| פאנל | מה הוא אומר לכם |
|---|---|
| **כרטיסי סיכום** | קומיטים ליום, תורמים, קבצים שנגעו בהם, שורות שהשתנו |
| **תחלופה שבועית** | הוספות מול מחיקות, שבוע אחר שבוע |
| **התורמים המובילים** | לפי קומיטים ולפי שורות |
| **מוקדים חמים בקבצים** | הקבצים שהשתנו הכי הרבה — לחצו על אחד כדי לקפוץ להיסטוריה שלו |

סננו את הכול לפי **30 יום / 90 יום / שנה / כל הזמן**.

המוקדים החמים הם הפאנל המעניין: קובץ שנמצא בראש הרשימה הזו שבוע אחר שבוע בדרך
כלל אומר לכם משהו על התכנון, ולא על האנשים שעורכים אותו.

עבור אותה היסטוריה בתור תמונה נעה, ראו [טיים־לאפס](timelapse.md).
