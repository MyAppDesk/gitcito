# 按仓库的设置

工具栏工具旁边那个齿轮，打开的是属于**这个**仓库的设置，而不是应用的设置。

![按仓库的设置](../../screenshots/repo-settings.webp)

| 标签页 | 里面有什么 |
|---|---|
| **通用** | 受保护分支（一个分支多选框，存在 git config 里）、签名, 标签页图片 |
| **Config** | 这个仓库在 `.gitcito.json` 里[携带的规则](repo-config.md)，以及检查它们的 doctor |
| **信息** | 关于这个仓库的自由格式笔记与字段，只保存在本地 |
| **保险库** | 这个仓库的[保险库](vault.md)条目 |
| **洞察** | [历史仪表盘](insights.md) |
| **统计** | 你在这个仓库里做过什么，在本地计数 |
| **历史** · **日志** | 操作日志：Gitcito 运行过的每一条 git 命令，连同它的输出 |

操作日志是诚实的那一个：当某件事表现得古怪时，它会给出确切的命令和确切的错误，这样一份缺陷报告就能带上事实，而不是形容词。

## 标签页图片

打开十个标签页时，开头相同的名称——`api`、`api-gateway`、`api-docs`——
很难分辨。标签页上的一张小图比文字更容易找到。

在 **常规** 中点击图片输入框，会列出仓库自身的图片（PNG、JPEG、GIF、WebP、
SVG、ICO、BMP 和 AVIF），每张都带缩略图，名称像 logo 或 icon 的文件排在最前。
输入即可筛选（`logo dark` 会找到 `assets/logo-dark.png`），用方向键移动，
按回车选择；也可以手动输入路径。路径按 **相对于仓库根目录** 保存，因此无论
文件夹位于何处，图片都会跟随仓库。

标签页显示什么是整个应用的设置，位于 **设置 → 常规 → 仓库标签页显示**：

| 选项 | 标签页显示 |
|---|---|
| **图片和名称**（默认） | 用图片代替文件夹图标，后面是名称 |
| **仅名称** | 文件夹图标和名称，与未设置图片时相同 |
| **仅图片** | 只有图片；名称移到提示框中 |

需要了解的限制：

- 列表包含 git 能看到的文件——已跟踪和未跟踪的，不含被忽略的——一次最多
  40 个；输入即可找到其余的。被忽略的图片仍可手动输入路径。
- 超过 1 MB 或无法读取的图片显示为灰色，无法选择：20 像素的图标用不着更多。
- **没有** 图片的仓库无论选哪个选项都始终显示名称——空白的标签页无法辨认。
- 如果路径 **失效**——文件被删除、改名、不是图片或过大——标签页会静默地改为
  显示名称，此设置页会在路径下方显示警告。其他地方不会提示。
- 图片每个会话只读取一次。如果用同名文件替换了图片，重新打开此设置页即可
  重新加载。
- 该设置保存在本机的 Gitcito 设置中，而不在仓库里，因此队友不会继承它。
