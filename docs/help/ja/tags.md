# タグとリリース

どのコミットからでもタグを作れます。

| 種類 | どんなとき |
|---|---|
| **軽量** | ただのポインタ。個人用の目印には十分です |
| **注釈付き** | メッセージ、作成者、日付を持ちます — リリースはこうあるべきです |
| **署名付き** | 注釈付きに加えて GPG／SSH 署名 |

![タグの作成: 名前、任意のメッセージ、署名するかどうか](../../screenshots/create-tag.webp)

タグはローカルで削除したり、プッシュしたり、リモート上で削除したりできます。
リモートのタグは、すべてフェッチしなくても閲覧できます。

GitHub では、公開された **リリース** が変更履歴ページとともにサイドバーに一覧
されます — [ホスティング](hosting.md) を参照してください。リリースノートの下書きには
[変更履歴ジェネレータ](changelog.md) を使ってください。

**関連項目:** [署名付きコミット](signing.md) · [変更履歴ジェネレータ](changelog.md)
