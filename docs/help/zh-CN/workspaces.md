# 工作空间、标签页与分组

三个层级，由松到紧。

## 标签页

一个仓库，一个标签页。用 <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> 打开新标签页选择器，
用 <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> 关闭当前标签页。你也可以拖动来重新排序、
中键点击关闭，或者按 <kbd>⌘⇧T</kbd> 重新打开最近关掉的那个。关掉最后一个标签页
之后，<kbd>⌘W</kbd> 关的就是窗口了。标签页上的一个圆点表示有未提交的工作；换一
种圆点则表示有冲突。

如果弹出了关闭警告，<kbd>Escape</kbd> 永远是取消。只有在标签页干净的时候
<kbd>Enter</kbd> 才代表确认——一旦存在未提交的变更或者冲突，这个警告就故意逼你
去够那个按钮，好让 <kbd>⌘W</kbd> 之后的一次误触关不掉你还攥在手里的工作。

## 分组

把相关的仓库打包成一个有名字、有颜色标识的**分组标签页**。进入分组后会多出一行，
每个仓库一枚徽章，而分组本身可以一次性**全部获取**或**全部拉取**。

![装着好几个仓库的分组标签页](../../screenshots/repo-groups.webp)

分组里可以放**文件夹，而且可以任意层级地嵌套**：右键点击分组 → *新建文件夹…*，
然后把仓库拖到文件夹徽章上。每个文件夹有自己的颜色，可以折叠成一枚带计数的徽章，
会汇总它里面所有东西的状态圆点，并且能对整棵子树做获取或拉取。

![分组标签栏里的文件夹，每个都是一枚带计数的徽章——Internal 嵌套在 Services 里面](../../screenshots/nested-folders.webp)

> 文件夹只负责整理。删掉一个文件夹，只会把它里面的仓库提到上一层——它绝不会关闭
> 任何仓库。

## 工作空间

一个工作空间就是**一整条保存下来的标签栏**。切换会把所有标签页一次换掉：`Work`
和 `Personal` 从此互不打扰。

工作空间的名字在左上角，紧挨着 Gitcito 的标志。点它可以切换、新建、重命名、重新
排序或删除。旁边那个仪表盘图标，会为你当前所在的工作空间打开
[任务中心](mission-control.md)。
