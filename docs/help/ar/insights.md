# الرؤى

لوحة معلومات مبنية من سجل Git عندك — بلا خدمة ولا حساب، مجرد `git log` يُقرأ
محليًا. افتحها من ترس إعدادات المستودع المجاور لأدوات شريط الأدوات.

![لوحة معلومات الرؤى](../../screenshots/insights.webp)

| اللوحة | ما تخبرك به |
|---|---|
| **بطاقات الملخّص** | الالتزامات في اليوم، والمساهمون، والملفات الملموسة، والأسطر المتغيّرة |
| **معدل التغيّر الأسبوعي** | الإضافات مقابل الحذوفات، أسبوعًا بأسبوع |
| **أبرز المساهمين** | بحسب الالتزامات وبحسب الأسطر |
| **البقع الساخنة في الملفات** | أكثر الملفات تغيّرًا — انقر أحدها لتقفز إلى سجله |

رشّح ذلك كله بـ **30 يومًا / 90 يومًا / سنة / كل الوقت**.

البقع الساخنة هي اللوحة المثيرة للاهتمام: ملف يتصدّر تلك القائمة أسبوعًا بعد
أسبوع يخبرك عادةً بشيء عن التصميم، لا عن الأشخاص الذين يحرّرونه.

ولرؤية السجل نفسه صورةً متحركة، انظر [الشريط الزمني](timelapse.md).
