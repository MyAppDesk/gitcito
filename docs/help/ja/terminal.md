# 統合ターミナル

コマンドランナーではなく、本物の PTY（xterm + node-pty）です。あなたのシェル、あなたの
プロンプト、あなたのエイリアスがそのまま使えます。

![統合ターミナル](../../screenshots/terminal.webp)

- **リポジトリごとに複数のタブ**。それぞれそのリポジトリのフォルダで始まります。
- グラフの **下** にドッキングするか、**右側の列** として置けます。ペインはサイズを
  覚えています。
- ターミナルの表示状態はリポジトリごとです。一度も開いていないタブに切り替えても、
  閉じたままになります。
- タブは、その中で動いているものの名前を自分で名乗ります。
- ターミナルの一覧を畳むと **レール** に縮みます。ターミナルごとにアイコンが 1 つ
  （分割されたターミナルは小さなパネル図を出します）並び、クリックで切り替え、右クリック
  でいつもの名前変更・分割・終了のメニューが出ます。
- リストで**ターミナルを別のターミナルにドラッグ**すると、分割グループに統合
  されます。各ターミナルはペインとして自分の名前を保ち、グループは新しい番号付き
  の名前になります。

![1 つのターミナルグループの中で左右に分割された 2 つのパネル](../../screenshots/terminal-split.webp)

ここで実行したものは Gitcito 自身のロックからは見えないので、手で打った長い
`git rebase` と UI でのクリックはやはり衝突し得ます。ターミナルが何かを変えたときは、
アプリがディスクから読み直します。
