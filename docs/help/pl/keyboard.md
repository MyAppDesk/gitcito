# Klawiatura i skróty

Naciśnij <kbd>?</kbd> gdziekolwiek, żeby zobaczyć ściągę.

![Ściąga ze skrótami](../../screenshots/cheatsheet.webp)

## Te warte zapamiętania

| Klawisze | Co robią |
|---|---|
| <kbd>⌘K</kbd> | [Paleta poleceń](search.md) — gałęzie, commity, pliki, akcje |
| <kbd>⌘⇧F</kbd> | [Wyszukiwanie w kodzie](search.md) w całym drzewie roboczym |
| <kbd>⌘⇧V</kbd> | [Sejf](vault.md) |
| <kbd>⌘O</kbd> / <kbd>Ctrl+O</kbd> | Otwórz repozytorium |
| <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd> | Otwórz Ustawienia |
| <kbd>⌘F</kbd> | Szukaj wewnątrz czytanego pliku lub diffa |
| <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> | Otwórz wybór repozytorium lub grupy dla nowej karty |
| <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> | Zamknij aktywną kartę — albo okno, gdy nie została żadna |
| <kbd>⌘1</kbd>–<kbd>⌘9</kbd> / <kbd>Ctrl+1</kbd>–<kbd>Ctrl+9</kbd> | Przełącz na kartę po jej pozycji |
| <kbd>⌘⇧T</kbd> | Otwórz ponownie ostatnio zamkniętą kartę |
| <kbd>?</kbd> | Ta ściąga |

## Poruszanie się bez myszy

| Gdzie | Klawisze |
|---|---|
| Graf commitów | <kbd>↑</kbd> <kbd>↓</kbd> albo <kbd>j</kbd> <kbd>k</kbd> |
| Listy plików (commit, WIP, stash) | tak samo |
| [Wehikuł czasu](time-machine.md) | <kbd>←</kbd> <kbd>→</kbd>, <kbd>⇧</kbd> po dziesięć, <kbd>Home</kbd>/<kbd>End</kbd> |
| [Centrum dowodzenia](mission-control.md) | <kbd>↑</kbd><kbd>↓</kbd>, <kbd>Enter</kbd> otwiera, <kbd>f</kbd>/<kbd>p</kbd> to fetch/pull, <kbd>/</kbd> filtruje |
| Pole wiadomości commita | <kbd>↑</kbd> <kbd>↓</kbd> przywołuje twoje ostatnie wiadomości |

## Przemapowanie

**Ustawienia → Skróty**. Podstawowe skróty nawigacyjne (paleta, wyszukiwanie
w kodzie, sejf, otwarcie repozytorium, ustawienia) da się przemapować,
z wykrywaniem konfliktów i resetem dla każdego skrótu z osobna.

Skróty z tabeli powyżej są stałe — i są też odrzucane jako _cel_: aplikacja
odpowiada na <kbd>⌘T</kbd>, <kbd>⌘W</kbd>, <kbd>⌘1</kbd>–<kbd>⌘9</kbd>,
<kbd>⌘⇧T</kbd>, <kbd>⌘S</kbd>, <kbd>⌘Z</kbd>, <kbd>⌘⇧Z</kbd> i <kbd>⌘F</kbd>
zanim zajrzy do twoich przypisań, więc skrót przypisany do któregoś z nich
wyglądałby na ustawiony i nigdy by nie zadziałał. Wybierz jeden z nich, a edytor
powie ci to wprost, zamiast go przyjąć.
