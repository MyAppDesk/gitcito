# İçgörüler

Git geçmişinizden kurulan bir pano — servis yok, hesap yok, yalnızca yerelde
okunan `git log`. Araç çubuğundaki araçların yanındaki depo ayarları dişlisinden
açın.

![İçgörüler panosu](../../screenshots/insights.webp)

| Panel | Size ne söyler |
|---|---|
| **Özet kartları** | Gün başına commit, katkı verenler, dokunulan dosyalar, değişen satırlar |
| **Haftalık değişim hacmi** | Hafta hafta, eklemelere karşı silmeler |
| **En çok katkı verenler** | Commit sayısına ve satır sayısına göre |
| **Dosya sıcak noktaları** | En çok değişen dosyalar — birine tıklayıp geçmişine atlayın |

Tamamını **30 gün / 90 gün / 1 yıl / tüm zamanlar** ile filtreleyin.

Asıl ilginç panel sıcak noktalardır: haftalarca o listenin başında duran bir
dosya, genellikle size onu düzenleyen insanlar hakkında değil, tasarım hakkında
bir şey anlatıyordur.

Aynı geçmişi hareketli bir görüntü olarak izlemek için
[timelapse](timelapse.md) sayfasına bakın.
