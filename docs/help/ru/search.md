# Палитра команд и поиск

## Палитра — <kbd>⌘K</kbd>

Нечёткий переход к **ветке** (выгружает её), к **коммиту** (прокручивает граф к
нему), к **файлу рабочего дерева** или к **действию** — фетч, пул, пуш, стеш,
терминал, reflog, настройки и любая функция из этого справочника.

Палитра учится: то, чем вы пользовались недавно, идёт первым, а то, чем вы
пользуетесь часто, обгоняет то, чем не пользуетесь.

## Поиск по коду — <kbd>⌘⇧F</kbd>

Два разных вопроса, один диалог:

| Режим | На какой вопрос отвечает |
|---|---|
| **Содержимое** | «Где эта строка прямо сейчас?» — `git grep` по отслеживаемым *и* неотслеживаемым файлам, с учётом регистра / целым словом / регулярками. |
| **Pickaxe по истории** | «Когда эта строка появилась или исчезла?» — `git log -S` / `-G`. |

Совпадения возвращаются с подсветкой синтаксиса и отмеченным местом
совпадения, сгруппированные по файлам и раскрываемые до конкретных строк.
Кликните — и откроется файл на этой строке либо коммит, который её принёс.

![Результаты поиска по коду](../../screenshots/code-search.webp)

## Фильтрация графа

Поле поиска над графом фильтрует коммиты по сообщению, автору, SHA или статусу
деплоя. Для «только коммиты, которые трогали этот файл» используйте фильтр по
пути — см. [граф коммитов](graph.md).
