# 延时回放

看着仓库长大。

每个文件都是一个圆点，按它的顶层文件夹摆放：被添加时诞生，被某个提交碰到时搏动，一次又一次被编辑时鼓胀起来，被删除时淡出。日期、作者、标题以及不断累加的提交/文件/作者计数摆在上方，底部有一条进度条。

![播放到一半的延时回放](../../screenshots/timelapse.webp)

![一个仓库的一生，重放一遍](../../screenshots/clip-timelapse.webp)

## 操作

- **播放 / 暂停**，速度从 **4× 到 32×**，还有重新开始。
- 滑块是靠**从头重放**来定位的，所以往回拖会精确落在正确的那个世界上，而不是它的一个近似。

## 导出视频

**导出视频**会把画布从头到尾录下来，然后问你把 `.webm` 存到哪里。

录制发生在页面自身之内（`MediaRecorder`）——没有编码器要装，不需要 ffmpeg，也没有任何东西被上传到任何地方。在你选定路径之前，什么都不会写到磁盘上。

> 一个真有形状的仓库，比一个整整齐齐的仓库更能拍成好片子。重命名、删除，以及某个文件夹突然炸开，才是让它值得一看的东西。
