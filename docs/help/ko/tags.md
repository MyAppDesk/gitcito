# 태그와 릴리스

어떤 커밋에서든 태그를 만들 수 있어요:

| 종류 | 언제 |
|---|---|
| **경량** | 단순한 포인터. 개인용 표시로는 충분해요 |
| **주석** | 메시지와 작성자, 날짜를 담아요 — 릴리스라면 이래야 해요 |
| **서명** | 주석 태그에 GPG/SSH 서명을 더한 것 |

![태그 만들기: 이름, 선택적 메시지, 서명 여부](../../screenshots/create-tag.webp)

태그를 로컬에서 삭제하거나, 푸시하거나, 원격에서 삭제할 수 있어요. 원격 태그는 전부
페치하지 않고도 둘러볼 수 있어요.

GitHub에서는 공개된 **릴리스**가 변경 기록 페이지와 함께 사이드바에 나열돼요 —
[호스팅](hosting.md)을 보세요. 릴리스 노트 초안을 잡으려면
[변경 기록 생성기](changelog.md)를 쓰세요.
