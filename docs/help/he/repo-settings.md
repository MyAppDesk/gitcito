# הגדרות לכל מאגר

הגלגל שליד כלי סרגל הכלים פותח הגדרות ששייכות ל**מאגר הזה**, לא לאפליקציה.

![הגדרות לכל מאגר](../../screenshots/repo-settings.webp)

| לשונית | מה יש בה |
|---|---|
| **כללי** | ענפים מוגנים (בחירה מרובה של ענפים, נשמרת בתצורת git), חתימה |
| **מידע** | הערות ושדות חופשיים על המאגר הזה, נשמרים מקומית |
| **כספת** | רשומות ה[כספת](vault.md) של המאגר הזה |
| **תובנות** | [לוח המחוונים של ההיסטוריה](insights.md) |
| **אנליטיקה** | מה עשיתם במאגר הזה, נספר מקומית |
| **היסטוריה** · **לוגים** | יומן הפעולות: כל פקודת git ש־Gitcito הריץ, עם הפלט שלה |

יומן הפעולות הוא הכן שבהם: כשמשהו מתנהג מוזר, הוא מציג את הפקודה המדויקת ואת
השגיאה המדויקת, כך שדיווח באג יכול לשאת עובדות במקום שמות תואר.

**ראו גם:** [אבטחה וסודות](security.md) · [תובנות](insights.md)
