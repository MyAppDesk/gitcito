# Запуск и отладка

Gitcito читает ваш `.vscode/launch.json` — корневой и любые вложенные,
сгруппированные разделителями, — и запускает выбранную конфигурацию во
встроенном терминале.

![Выбор конфигурации запуска и плавающая панель](../../screenshots/launch-configs.webp)

- **Переменные VS Code раскрываются** (`${workspaceFolder}` и компания).
- **`preLaunchTask`** конфигурации выполняется первым.
- Значения **`${input:…}`** спрашиваются интерактивно перед запуском
  (`promptString` и `pickString`).
- Задачи с **`isBackground`** (вотчеры, dev-серверы) запускаются отдельно, так что
  никогда не блокируют старт.

Плавающая панель даёт **паузу / продолжение, перезапуск, остановку** и
переключает между запущенными сессиями.

Включается в **Настройки → Общие → Включить launch.json**. Кнопка **LAUNCH**
появляется рядом с вкладками Git / Файлы.

**См. также:** [Встроенный терминал](terminal.md)
