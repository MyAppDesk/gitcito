# Теги та релізи

Створіть тег із будь-якого коміта:

| Різновид | Коли |
|---|---|
| **Легкий** | Просто вказівник. Цілком годиться для особистої позначки |
| **Анотований** | Несе повідомлення, автора й дату — те, чим має бути реліз |
| **Підписаний** | Анотований, плюс підпис GPG/SSH |

![Створення тега: назва, необов’язкове повідомлення і чи підписувати його](../../screenshots/create-tag.webp)

Видаляйте теги локально, пушіть їх або видаляйте на віддаленому репозиторії.
Віддалені теги можна переглядати, не завантажуючи спершу всі до одного.

На GitHub опубліковані **релізи** перелічені в бічній панелі разом зі сторінкою
змін — див. [Хостинг](hosting.md). Щоб укласти нотатки, скористайтеся
[генератором чейнджлогу](changelog.md).
