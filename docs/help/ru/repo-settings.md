# Настройки репозитория

Шестерёнка рядом с инструментами панели открывает настройки, которые
принадлежат **этому** репозиторию, а не приложению.

![Настройки репозитория](../../screenshots/repo-settings.webp)

| Вкладка | Что там лежит |
|---|---|
| **Общие** | Защищённые ветки (мультивыбор веток, хранится в git-конфиге), подпись |
| **Config** | [Правила, которые несёт этот репозиторий](repo-config.md), в `.gitcito.json` — и доктор, который их проверяет |
| **Сведения** | Произвольные заметки и поля об этом репозитории, хранятся локально |
| **Сейф** | Записи [сейфа](vault.md) этого репозитория |
| **Инсайты** | [Панель истории](insights.md) |
| **Аналитика** | Что вы делали в этом репозитории, подсчитано локально |
| **История** · **Логи** | Журнал операций: каждая команда git, которую запустил Gitcito, вместе с её выводом |

Журнал операций — самая честная штука здесь: когда что-то ведёт себя странно, он
показывает точную команду и точную ошибку, так что баг-репорт может нести факты,
а не прилагательные.
