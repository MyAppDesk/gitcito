# Доступность

Gitcito стремится быть управляемым без мыши и читаемым для программы чтения с
экрана. Эта страница говорит, что это значит конкретно — и где проходят
границы.

## Клавиатура

- **Вкладки, строки боковой панели, списки файлов и меню панели
  инструментов** фокусируются и активируются Enter или Space. Разделённые
  кнопки (pull/push/stash) выставляют стрелку выпадающего меню отдельным
  фокусируемым элементом.
- **Граф коммитов** — одна остановка фокуса: сфокусируйте его и ходите по
  истории стрелками вверх/вниз (или j/k). Выбранный коммит объявляется с
  темой, автором и позицией. Shift+F10 (или клавиша меню) открывает
  контекстное меню выбранного коммита.
- **Контекстные меню** открываются с фокусом внутри: стрелки перемещают,
  Enter активирует, ArrowRight/ArrowLeft входят в подменю и выходят из них,
  Escape закрывает.
- **Диалоги** держат Tab внутри себя, при закрытии возвращают фокус туда,
  где вы были, и закрываются по Escape.
- **Палитра команд** (Cmd/Ctrl+K) — это комбобокс: результаты объявляются по
  мере ввода и при перемещении стрелками.

## Программы чтения с экрана

- Каждый диалог объявляется своим заголовком. Тосты — канал обратной связи
  приложения — это живые регионы: успехи объявляются вежливо, ошибки
  прерывают.
- Прогресс (клонирование, загрузка обновления) выставлен как индикатор
  прогресса с процентами, а состояния занятости («Получение…») объявляют
  себя сами.
- Статус файла проговаривается («Добавлен», «Изменён», «Конфликт»), а не
  только показывается цветным значком.
- Окно размечено ландмарками (banner, main, боковая панель, строка
  состояния), так что навигация по ландмаркам работает.

## Границы, названные прямо

- **Терминал** — это xterm.js, и он наследует его отношения с программами
  чтения с экрана, а они слабые. Считайте его поверхностью для зрячих;
  каждая git-операция, которую он предлагает, существует и как действие в
  интерфейсе.
- **Cosmos (история в 3D), дорожки графа коммитов и диффы изображений**
  визуальны по своей природе. Данные за ними — список коммитов, списки
  файлов — доступны; сама картинка — нет.
- **Перетаскивание** (переупорядочивание шагов интерактивного ребейза,
  перетаскивание веток для слияния) работает только указателем там, где это
  отмечено; у каждого перетаскивания есть эквивалент в меню или кнопке.
- Аудит за этой страницей делался с VoiceOver на macOS. NVDA/JAWS под
  Windows должны вести себя так же, но в деле не проверены — сообщения
  приветствуются в виде
  [issues](https://github.com/MyAppDesk/gitcito/issues).

## Связанные настройки

**Уменьшение движения** учитывается из системной настройки — анимации
сворачиваются в мгновенные переходы. Контраст темы можно донастроить для
каждой темы в [Настройки → Внешний вид](themes.md).
