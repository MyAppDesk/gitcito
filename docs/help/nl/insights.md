# Inzichten

Een dashboard opgebouwd uit je Git-geschiedenis — geen dienst, geen account,
alleen `git log`, lokaal gelezen. Open het via het tandwiel voor
repository-instellingen naast de tools in de werkbalk.

![Het inzichtendashboard](../../screenshots/insights.webp)

| Paneel | Wat het je vertelt |
|---|---|
| **Samenvattingskaarten** | Commits per dag, bijdragers, aangeraakte bestanden, gewijzigde regels |
| **Wekelijkse churn** | Toevoegingen tegenover verwijderingen, week voor week |
| **Belangrijkste bijdragers** | Naar commits en naar regels |
| **Bestandshotspots** | De meest gewijzigde bestanden — klik er een aan om zijn geschiedenis in te springen |

Filter het geheel op **30 dagen / 90 dagen / 1 jaar / alles**.

Hotspots is het interessante paneel: een bestand dat week na week bovenaan die
lijst staat vertelt je meestal iets over het ontwerp, en niet over de mensen die
het bewerken.

Voor dezelfde geschiedenis als bewegend beeld, zie [timelapse](timelapse.md).
