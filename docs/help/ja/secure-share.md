# 安全な共有

新しいマシン — あるいは新しいチームメイト — を整えるというのは、たいてい何もかもを
入力し直すことです。安全な共有はその代わりに、すべてを暗号化された 1 つの `.gitcito`
ファイルにまとめます。Gitcito のチーム機能には **バックエンドがありません**。だから
このファイル *こそ* が輸送手段です。普段ファイルを送っている方法でそのまま送って
ください。パスワードは別の経路で渡します。

![1 つのリポジトリの設定を暗号化バンドルとして書き出す](../../screenshots/secure-share.webp)

![同じ書き出しを、ワークスペース全体に対して](../../screenshots/secure-workspace.webp)

## 入れられるもの

| セクション | 中身 |
|---|---|
| **金庫** | グローバルな金庫のシークレット（リポジトリごとの金庫エントリは動きません） |
| **リポジトリファイル** | 未追跡の設定ファイルとシークレットファイル。インポート時に同じ相対パスへ再作成されます |
| **ワークスペース構成** | タブレイアウトそのもの — グループ、色、並び順。リポジトリはリモート URL で参照され、あなたのローカルパスは決して使われません |
| **コミットノート** | リポジトリの `refs/notes/commits`。インポート時に適用され、どのリモートへの書き込み権限も要りません |

シークレットが含まれるのは、**チェックボックスを入れたとき** だけです。そのチェックの
ないバンドルには、認証情報はいっさい入っていません。アプリの設定はバンドルでは運ばれ
ません — 設定には、設定画面に専用のプレーン JSON エクスポートがあります。

## インポート

インポート画面は、何かを適用する **前に** 中身をセクションごとに見せます。リポジトリは
すでに手元にあるものと突き合わされ — まずリモート URL で、次にフォルダーで — 世界を
もう一度クローンし直さずに済みます。

**ワークスペース構成** のセクションは、すでに手元にあるリポジトリでワークスペースを
再現します。持っていないリポジトリはリモートとともに一覧されるので、先にクローンして
からもう一度インポートできます — ここで Gitcito があなたの代わりにクローンすることは
ありません。**コミットノート** のセクションは、何が入るかをプレビューします — 新規、
同一、相違、あるいは持っていないコミットに付いたもの — そして相違するノートが置き
換えられるのは、**上書き** にチェックを入れたときだけです。分岐したノートのマージは
ありません。
