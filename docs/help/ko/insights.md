# 인사이트

Git 히스토리로 만든 대시보드예요. 서비스도 계정도 없고, 로컬에서 읽은
`git log` 뿐이에요. 툴바 도구들 옆에 있는 저장소 설정 톱니바퀴에서 열어요.

![인사이트 대시보드](../../screenshots/insights.webp)

| 패널 | 알려주는 것 |
|---|---|
| **요약 카드** | 하루 커밋 수, 기여자, 건드린 파일, 바뀐 줄 수 |
| **주간 변경량** | 주 단위로 본 추가와 삭제 |
| **주요 기여자** | 커밋 수 기준, 그리고 줄 수 기준 |
| **파일 핫스팟** | 가장 많이 바뀐 파일들 — 클릭하면 그 파일의 히스토리로 넘어가요 |

전체를 **30일 / 90일 / 1년 / 전체 기간** 으로 걸러 볼 수 있어요.

핫스팟이 흥미로운 패널이에요. 몇 주째 그 목록 맨 위에 있는 파일은 대개 그 파일을
고치는 사람들이 아니라 설계에 대해 뭔가를 말해 주고 있어요.
