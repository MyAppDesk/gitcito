# الالتزامات الموقَّعة

فعّل التوقيع لكل مستودع على حدة (**الإعدادات ← ترس المستودع**): GPG أو SSH أو
X.509، بالمفتاح الذي تختاره. يكتب Gitcito مفاتيح الإعداد `commit.gpgsign`
و`gpg.format` و`user.signingkey` لذلك المستودع — الإعداد نفسه الذي تقرؤه أي
أداة أخرى.

| | |
|---|---|
| ![عمود التوقيع، فاتح](../../screenshots/signed-commits-light.webp) | ![عمود التوقيع، داكن](../../screenshots/signed-commits-dark.webp) |

يكتسب الرسم البياني **عمود توقيع** مخصصًا قابلًا لإعادة الترتيب:

| الشارة | ما تعنيه |
|---|---|
| **موثَّق** | توقيع سليم من مفتاح يثق به git |
| **غير موثَّق** | موقَّع، لكن المفتاح مجهول أو غير مُتحقَّق منه |
| **منتهي الصلاحية** | انتهت صلاحية التوقيع أو مفتاحه |
| *(لا شيء)* | غير موقَّع |
