# בדיקת סביבה

יש תקלות שאין להן שום קשר למאגר. הן מגיעות מהמחשב: git ישן מדי לכניסה דרך פרופיל, טרמינל
שנפל בשקט למצב בסיסי, כניסה של GitHub CLI שאינה יכולה לדחוף קובצי workflow. כל אחת מהן צצה
מאוחר יותר כשגיאה מעורפלת באמצע משהו אחר. **הגדרות ← סביבה** (וגם *Settings: Environment*
בלוח הפקודות) בודקת אותן מראש.

[רופא המאגר](repo-settings.md) עונה על שאלה אחרת: האם אפשר לבנות כאן את *המאגר הזה*, לפי
מה שה-`.gitcito.json` שלו מבקש. בדיקת הסביבה נוגעת לאפליקציה עצמה וזהה לכל מאגר.

![בדיקות הסביבה בהגדרות](../../screenshots/settings-environment.webp)

## מה נבדק

| שורה | ירוק פירושו | צהוב או אדום פירושו |
|------|-------------|---------------------|
| **Git** | git 2.31 ומעלה נמצא ב-`PATH` | ישן מ-2.31: החשבון של [פרופיל](profiles.md) אינו יכול להיכנס ל-fetch ול-push. חסר: שום דבר לא עובד עד שמתקינים git |
| **Git LFS** | `git lfs` מותקן | לא מותקן. רק מאגרים ששומרים קבצים ב-LFS צריכים אותו |
| **טרמינל** | הטרמינל המקורי נטען | ה[טרמינל](terminal.md) רץ במצב בסיסי: בלי צבעים, בלי שינוי גודל, בלי תוכנות במסך מלא |
| **Credential helper** | ל-git יש helper לסיסמאות HTTPS — גלובלי, או לשרתים מסוימים (מה ש-`gh auth setup-git` מגדיר) | אין helper, ולכן git מחוץ ל-Gitcito שואל בכל פעם. או `store`, ששומר אותן כטקסט גלוי. ראו [Credential helper](credentials.md) |
| **GitHub CLI** | `gh` מחובר עם ההרשאה `workflow` | מחובר בלעדיה: GitHub דוחה כל push שמשנה את `.github/workflows` |
| **מעקב קבצים** (Linux) | מגבלת inotify היא לפחות 65,536 | מגבלה נמוכה יותר נגמרת עם כמה מאגרים גדולים פתוחים, ותיקיות חדשות מפסיקות לרענן את המצב |

שורה שאינה רלוונטית מושמטת: GitHub CLI כשאינו מותקן או מחובר, ומעקב קבצים ב-macOS
וב-Windows.

## תיקון מה שנמצא

כשיש תיקון, השורה מציגה אותו כפקודה עם כפתור העתקה. למשל,
`gh auth refresh -h github.com -s workflow` מוסיף את ההרשאה החסרה, ושורת `sysctl` מעלה את
מגבלת inotify. **הדף לעולם לא מריץ דבר בעצמו.** חלק מהתיקונים דורשים `sudo` או משנים הגדרות
גלובליות, ועליכם לקרוא אותם לפני שתריצו. אחר כך לחצו **בדיקה חוזרת**.

## מגבלות

- היא בודקת את מה שהאפליקציה רואה מהתהליך שלה. פרופיל מעטפת שמשנה את `PATH` רק בטרמינל
  שלכם עלול לגרום לשניים להיות שונים.
- שורת GitHub CLI משקפת את הכניסה של `gh` עצמו, לא את החשבונות שחוברו ב**הגדרות ← שילובים**.
  אלה פרטי כניסה נפרדים. הרשאת `workflow` חסרה שם תתגלה במקום זאת כ-push שנדחה.
- היא מדווחת מה מותקן. היא לא מתקינה ולא משדרגת דבר.
