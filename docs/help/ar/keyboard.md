# لوحة المفاتيح والاختصارات

اضغط <kbd>?</kbd> في أي مكان لتحصل على الورقة المرجعية.

![الورقة المرجعية للاختصارات](../../screenshots/cheatsheet.webp)

## التي تستحق التعلّم

| المفاتيح | تفعل |
|---|---|
| <kbd>⌘K</kbd> | [لوحة الأوامر](search.md) — الفروع والالتزامات والملفات والإجراءات |
| <kbd>⌘⇧F</kbd> | [البحث في الشيفرة](search.md) عبر شجرة العمل |
| <kbd>⌘⇧V</kbd> | [الخزنة](vault.md) |
| <kbd>⌘O</kbd> / <kbd>Ctrl+O</kbd> | فتح مستودع |
| <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd> | فتح الإعدادات |
| <kbd>⌘F</kbd> | البحث داخل الملف أو الفرق الذي تقرؤه |
| <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> | فتح منتقي مستودع أو مجموعة لتبويب جديد |
| <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> | إغلاق التبويب النشط — أو النافذة، متى لم يبقَ تبويب |
| <kbd>⌘1</kbd>–<kbd>⌘9</kbd> / <kbd>Ctrl+1</kbd>–<kbd>Ctrl+9</kbd> | التبديل إلى تبويب بحسب موضعه |
| <kbd>⌘⇧T</kbd> | إعادة فتح آخر تبويب مغلق |
| <kbd>?</kbd> | هذه الورقة المرجعية |

## التنقّل بلا فأرة

| أين | المفاتيح |
|---|---|
| الرسم البياني للالتزامات | <kbd>↑</kbd> <kbd>↓</kbd> أو <kbd>j</kbd> <kbd>k</kbd> |
| قوائم الملفات (الالتزام، العمل الجاري، المخبأ) | الشيء نفسه |
| [آلة الزمن](time-machine.md) | <kbd>←</kbd> <kbd>→</kbd>، و<kbd>⇧</kbd> لعشرة، و<kbd>Home</kbd>/<kbd>End</kbd> |
| [غرفة التحكم](mission-control.md) | <kbd>↑</kbd><kbd>↓</kbd>، و<kbd>Enter</kbd> للفتح، و<kbd>f</kbd>/<kbd>p</kbd> للجلب/السحب، و<kbd>/</kbd> للتصفية |
| صندوق رسالة الالتزام | <kbd>↑</kbd> <kbd>↓</kbd> يستعيدان رسائلك الأخيرة |

## إعادة الربط

**الإعدادات ← الاختصارات**. اختصارات التنقّل الأساسية (لوحة الأوامر، والبحث في
الشيفرة، والخزنة، وفتح مستودع، والإعدادات) قابلة لإعادة الربط، مع كشف التعارضات
وإعادة تعيين لكل اختصار على حدة.

أما الاختصارات الثابتة أعلاه فغير قابلة لإعادة الربط، وهي مرفوضة أيضًا كـ
_هدف_: فالتطبيق يستجيب لـ <kbd>⌘T</kbd> و<kbd>⌘W</kbd>
و<kbd>⌘1</kbd>–<kbd>⌘9</kbd> و<kbd>⌘⇧T</kbd> و<kbd>⌘S</kbd> و<kbd>⌘Z</kbd>
و<kbd>⌘⇧Z</kbd> و<kbd>⌘F</kbd> قبل أن يستشير روابطك، فالاختصار المسنَد إلى أحدها
سيبدو مضبوطًا ولن ينطلق أبدًا. اختر واحدًا منها وسيقول لك المحرر ذلك بدل أن
يقبله.
