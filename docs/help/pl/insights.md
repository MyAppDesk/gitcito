# Statystyki

Panel zbudowany z twojej historii Gita — bez serwisu, bez konta, po prostu
`git log` czytany lokalnie. Otwórz go z koła zębatego ustawień repozytorium obok
narzędzi na pasku.

![Panel statystyk](../../screenshots/insights.webp)

| Panel | Co ci mówi |
|---|---|
| **Karty podsumowania** | Commity na dzień, współtwórcy, dotknięte pliki, zmienione linie |
| **Tygodniowy churn** | Dodania kontra usunięcia, tydzień po tygodniu |
| **Najwięksi współtwórcy** | Według commitów i według linii |
| **Punkty zapalne plików** | Najczęściej zmieniane pliki — kliknij, żeby skoczyć w ich historię |

Przefiltruj całość po **30 dniach / 90 dniach / roku / całym czasie**.

Punkty zapalne to ten ciekawy panel: plik na szczycie tej listy, tydzień po
tygodniu, zwykle mówi ci coś o projekcie systemu, a nie o ludziach, którzy go
edytują.

Po tę samą historię w postaci ruchomego obrazu sięgnij po
[timelapse](timelapse.md).
