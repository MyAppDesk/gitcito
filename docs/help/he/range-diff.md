# מה השתנה מאז

סקרתם ענף. מישהו עשה לו ריבייס ודחף בכוח. דיף רגיל הוא עכשיו חסר ערך: כל קומיט
אחרי ריבייס הוא קומיט חדש, ולכן הכול נראה חדש.

`git range-diff` מזווג את שתי הגרסאות קומיט מול קומיט, ו־Gitcito קורא את המיקומים
הישנים ישירות מתוך ה**reflog** — כך שלא היה צריך לתעד שום דבר מראש כדי שזה יעבוד.

![קומיטים שנכתבו מחדש, חדשים ונזרקו אחרי דחיפה כפויה](../../screenshots/range-diff.webp)

| פסק דין | המשמעות |
|---|---|
| **נכתב מחדש** | אותו קומיט, שונה. הרחיבו אותו כדי לראות את האינטר־דיף — התיקון בהודעה והבדיקה הנוספת, לא את כל הקובץ. |
| **חדש** | נוסף מאז שהסתכלתם. |
| **נזרק** | נעלם מאז שהסתכלתם. |
| **ללא שינוי** | שרד את הכתיבה מחדש בלי שנגעו בו. |

## איך מגיעים לשם

- **הבאה שמגלה היסטוריה שנכתבה מחדש אומרת לכם.** הודעה קופצת נוקבת בשם הענף,
  והשורה שלו תחת רימוטים מקבלת **⟳** שאפשר ללחוץ עליו כדי לפתוח את ההשוואה בדיוק
  בקומיט שאליו הוא הצביע קודם.
- לחיצה ימנית על כל ענף ← *מה השתנה מאז…*
- <kbd>⌘K</kbd> ← *מה השתנה מאז*

## מיקומים קודמים

הצ׳יפים שמתחת לשדות ה־refs הם ה־reflog של הענף: עדכונים כפויים, ריבייסים,
ריסטים, כל אחד עם מועד ההתרחשות. בחרו אחד וההשוואה תרוץ מחדש מולו. זו כל
התכונה — ההיסטוריה של המקומות שבהם ענף היה נמצאת כבר על הדיסק שלכם.
