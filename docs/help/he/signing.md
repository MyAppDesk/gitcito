# קומיטים חתומים

הפעילו חתימה לכל מאגר בנפרד (**הגדרות ← גלגל המאגר**): GPG, SSH או X.509, עם
המפתח שתבחרו. Gitcito כותב `commit.gpgsign`, `gpg.format` ו־`user.signingkey`
עבור המאגר הזה — אותה תצורה שכל כלי אחר קורא.

| | |
|---|---|
| ![עמודת החתימה, בהיר](../../screenshots/signed-commits-light.webp) | ![עמודת החתימה, כהה](../../screenshots/signed-commits-dark.webp) |

הגרף מקבל **עמודת חתימה** ייעודית וניתנת לסידור מחדש:

| תג | פירושו |
|---|---|
| **מאומת** | חתימה תקינה ממפתח ש־git סומך עליו |
| **לא מאומת** | חתום, אבל המפתח אינו מוכר או לא אומת |
| **פג תוקף** | החתימה או המפתח שלה פגו |
| *(כלום)* | לא חתום |

גם תגיות ניתנות לחתימה — ראו [תגיות](tags.md).

**ראו גם:** [אבטחה וסודות](security.md)
