# 命令面板与搜索

## 命令面板——<kbd>⌘K</kbd>

模糊跳转到一个**分支**（会检出它）、一个**提交**（会把图滚动到它）、一个**工作区文件**，或者一个**动作**——获取、拉取、推送、贮藏、终端、reflog、设置，以及这本手册里的每一项功能。

它会学习：你最近用过的排在前面，你常用的压过你不常用的。

![命令面板](../../screenshots/command-palette.webp)

## 代码搜索——<kbd>⌘⇧F</kbd>

两个不同的问题，一个对话框：

| 模式 | 它回答的问题 |
|---|---|
| **内容** | 「这个字符串现在在哪儿？」——对已跟踪*和*未跟踪的文件执行 `git grep`，支持区分大小写／全词／正则。 |
| **历史镐（pickaxe）** | 「这个字符串是什么时候出现或消失的？」——`git log -S` ／ `-G`。 |

命中结果带语法高亮返回，匹配处被标出，按文件分组，可以展开到具体的行。点击其中一条即可在那一行打开文件，或者打开引入它的那个提交。
