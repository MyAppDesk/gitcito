# LFS, צ׳קאאוט חלקי וטלאים

## Git LFS

![מנהל ה־LFS](../../screenshots/lfs.webp)

מזהה האם `git-lfs` מותקן, האם המאגר הזה משתמש בו, ואילו תבניות נמצאות במעקב.
רשימת הקבצים מראה מה **הורד** לעומת מה שעדיין **מצביע**, ומשם אפשר למשוך או
לגזום.

## צ׳קאאוט חלקי

![צ׳קאאוט חלקי במצב קונוס](../../screenshots/sparse-checkout.webp)

מצב קונוס: סמנו את תיקיות העל שאתם באמת עובדים בהן, והשאר עוזב את עץ העבודה שלכם
בעודו נשאר בהיסטוריה. שימושי במונורפו שבו אתם מחזיקים רק שתי חבילות.

**שכפול חלקי** (`--filter=blob:none`) מוצע בזמן השכפול, כדי שלא תורידו בלובים
שלעולם לא תפתחו.

## טלאים

- **ייצוא** של קומיט (או של בחירה מרובה) בתור `.patch`.
- **החלה** של טלאי על עץ העבודה (`git apply`) או כקומיט (`git am`).

שניהם מתפריט הכלים.
