# Git LFS والسحب الجزئي والرقع

## Git LFS

![مدير Git LFS](../../screenshots/lfs.webp)

يكتشف ما إذا كان `git-lfs` مثبَّتًا، وما إذا كان هذا المستودع يستخدمه، وأي
الأنماط متتبَّعة. تُظهر قائمة الملفات ما جرى **تنزيله** مقابل ما لا يزال
**مؤشرًا**، ويمكنك السحب أو التشذيب من هناك.

## السحب الجزئي

![السحب الجزئي بنمط cone](../../screenshots/sparse-checkout.webp)

نمط cone: أشّر على المجلدات العليا التي تعمل فيها فعلًا، فيغادر ما تبقّى شجرة
عملك مع بقائه في السجل. مفيد في مستودع أحادي ضخم لا تملك فيه سوى حزمتين.

ويُعرض عليك **استنساخ جزئي** (`--filter=blob:none`) عند الاستنساخ، كي لا تنزّل
كائناتٍ لن تفتحها أبدًا.

## الرقع

- **صدّر** التزامًا (أو تحديدًا متعددًا) كملف `.patch`.
- **طبّق** رقعة على شجرة العمل (`git apply`) أو كالتزام (`git am`).

كلاهما من قائمة الأدوات.
