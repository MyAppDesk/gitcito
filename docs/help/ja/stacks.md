# スタックブランチ

スタックとは、それぞれが下のブランチの上に積み上がったブランチの連なりです。
`main → api → ui` のような形です。小さなプルリクエスト 3 つのレビューは、巨大なもの
1 つのレビューに勝ります。

![ブランチスタック](../../screenshots/branch-stack.webp)

Gitcito はスタックを下から上へ、各段のコミット数とともに表示し、**段ごとにプルリクエスト
を開く** ことができます。それぞれの宛先は `main` ではなく、自分の親です。

## リスタック

下のブランチが変わったとき — `api` でレビュー指摘に対応した、というような場合 — その上の
ブランチはどれも間違ったベースの上に乗っています。**リスタック** は `rebase --onto` で
連鎖全体をリベースし直すので、親を書き換えても子にコミットが重複しません。

## つながりが保存される場所

親へのつながりは **git config** に保存されるので、リポジトリと一緒に移動し、クローンし
直しても残ります。どこかのサービスに置かれるものはありません。
