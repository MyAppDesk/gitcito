# マージとリベース

## サイドバーから

ブランチを右クリックすると **現在のブランチへマージ** や **この上にリベース** が
選べます。普通のマージがいつも同じところで失敗するなら
**オプション付きでマージ…** を使ってください。[マージオプション](merge-options.md)
を参照。

## ref を別の ref にドラッグする

アプリでいちばん速いジェスチャーです。ブランチをつかんで、別のブランチの上に落と
します。Gitcito はそのドロップがどういう意味になりうるかを小さなメニューで見せ、
あなたが選ぶまで何もしません。

![ブランチを別のブランチにドラッグすると、そのドロップの意味を選ぶメニューが開く](../../screenshots/clip-branch-drop.webp)

ref が表示される **両方** の場所で使えます — サイドバーのブランチ、リモート、タグ
の行と、グラフのなかの色付き **ref バッジ** です。どの組み合わせでもドラッグでき、
ドロップ先はホバー中にハイライトされます。

| ドロップ | 意味 |
|------|-------|
| **{source} を {target} にマージ** | ターゲットをチェックアウトし、そこへソースをマージします |
| **{source} を {target} の上にリベース** | ソースのコミットをターゲットの上に載せ直します |
| **比較** | [比較](#任意の-2-つの-ref-を比較する) を開きます — 何も変更しません |

**メニューには git にできることだけが並びます。** マージはターゲットの上にコミット
するので、ターゲットはローカルブランチでなければなりません。タグやリモート追跡
ref にはマージできません。リベースはソースを書き換えるので、ソースがローカルブラ
ンチである必要があります。リモートブランチの上にタグを落とすと *比較* しか出てき
ませんが、それが本当に唯一できることだからです。

リベースは先に確認を求めます。載せ直したコミットにはすべて新しいハッシュが付くの
で、ブランチをすでに公開しているなら強制プッシュになるからです。マージは尋ねませ
ん — 追加するだけだからです。どちらの場合も、**取り消し** 一回で元に戻せます。

## マージ

可能なら fast-forward、トポロジーを記録に残したいときはマージコミットを強制でき
ます。コンフリクトしたら [リゾルバ](conflicts.md) に着地します。

## 任意の 2 つの ref を比較する

ベースと比較対象の ref を選ぶと — ブランチ、タグ、生の SHA が使え、入れ替えボタン
も付いています — 進み/遅れの件数、それぞれの側に固有のコミット、まとめた差分の全
体、そして **PR を作成** へのワンクリックの受け渡しが得られます。

![2 つのブランチの比較。それぞれの側に固有のものと、まとめた差分](../../screenshots/branch-compare.webp)

サイドバー（現在のブランチとの比較）、ツールメニュー、<kbd>⌘K</kbd> から開けます。

## チェリーピック、リバート、リセット

3 つともグラフのコンテキストメニューから使えます。リセットは **soft / mixed /
hard** を提示し、選ぶ前にそれぞれが作業ツリーに何をするのかを明示します。

先に複数のコミットを選択しておけば、チェリーピックは選択したものを順番にまとめて
適用します。

## 何かをマージする前に

[コンフリクトレーダー](conflict-radar.md) は、すべてのブランチをベースに対して
スキャンし、どれが揉めるかを何もチェックアウトせずに教えてくれます。
