# リポジトリ wiki

リポジトリを指定すると、そのコードベースを解説する短い wiki を書き上げます。

## リポジトリカード

- **言語の内訳** — バイト数によるもの。
- **スタック** — フレームワークをバッジで表示します（Next、Angular、Electron、
  Tailwind…）。
- **依存関係** — マニフェスト（`package.json`、`Cargo.toml`、`go.mod`、
  `pyproject.toml`、`pubspec.yaml`、`Gemfile`…）から直接読み取り、アーキテクチャ上の
  役割ごとにまとめます。足場にあたるもの — 型スタブ、ローダー、lint プラグイン — は
  先に取り除かれ、プロジェクトが実際に宣言しているパッケージだけが現れます。
- **モジュール依存グラフ** — ソース（JS/TS、Python、Go、Rust、Dart、Ruby、C/C++、
  PHP）を解析し、リポジトリ自身のファイルに対して解決するので、パッケージの import
  が偽の辺になることはありません。

## 書かれるページ

Gitcito はリポジトリが追跡しているファイルから数ページ分の構成を立て — まずドキュ
メントとマニフェスト、次に変更の多いもの — 各ページをそれが扱うファイルから書き
起こします。

**あらゆる記述には出典となったファイルが添えられ**、どのファイルにも裏付けられない
主張は公開されずに却下されます。ページは並行して書かれ、まとめて一度に保存されるので、
失敗した実行が良い wiki を置き換えてしまうことはありません。wiki が古いコミット時点で
書かれた場合は、そのことを伝えます。

## エクスポート

**docs/ へエクスポート** は全体を `docs/wiki/` にリンク付き Markdown として書き出し
ます — コミットでき、PR でレビューでき、ホスティング先で読めるようになります。

秘密情報らしきファイルが送られることはありません。
