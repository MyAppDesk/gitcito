# Etiquetas y releases

Crea una etiqueta desde cualquier commit:

| Tipo | Cuándo |
|---|---|
| **Ligera** | Un puntero. Suficiente para una marca personal |
| **Anotada** | Lleva mensaje, autoría y fecha — lo que debería ser un release |
| **Firmada** | Anotada, más una firma GPG/SSH |

![Crear una etiqueta: nombre, mensaje opcional y si firmarla](../../screenshots/create-tag.webp)

Borra etiquetas en local, publícalas, o bórralas en el remoto. Las etiquetas
remotas se pueden explorar sin traértelas todas antes.

En GitHub, los **releases** publicados aparecen en la barra lateral con su
página de changelog — mira [Hosting](hosting.md). Para redactar las notas, usa
el [generador de changelog](changelog.md).
