# إعدادات المستودع

يفتح الترس المجاور لأدوات شريط الأدوات إعداداتٍ تخصّ **هذا** المستودع، لا
التطبيق.

![إعدادات المستودع](../../screenshots/repo-settings.webp)

| التبويب | ما يحويه |
|---|---|
| **عام** | الفروع المحمية (اختيار متعدد للفروع، محفوظ في إعدادات git)، والتوقيع, صورة علامة التبويب |
| **Config** | [القواعد التي يحملها هذا المستودع](repo-config.md) في `.gitcito.json`، والطبيب الذي يفحصها |
| **معلومات** | ملاحظات وحقول حرّة عن هذا المستودع، تُحفظ محليًا |
| **الخزنة** | مدخلات [الخزنة](vault.md) الخاصة بهذا المستودع |
| **الرؤى** | [لوحة معلومات السجل](insights.md) |
| **التحليلات** | ما فعلته في هذا المستودع، محسوبًا محليًا |
| **السجل** · **السجلات** | سجل العمليات: كل أمر git شغّله Gitcito، مع خرجه |

سجل العمليات هو الشاهد النزيه: حين يتصرّف شيء ما تصرّفًا غريبًا، يعرض الأمر
بالضبط والخطأ بالضبط، كي يحمل تقرير العلة وقائع لا نعوتًا.

## صورة علامة التبويب

مع عشر علامات تبويب مفتوحة، يصعب التمييز بين الأسماء التي تبدأ بالطريقة نفسها
— `api` و`api-gateway` و`api-docs`. والصورة الصغيرة على علامة التبويب
أسرع في العثور عليها من النص.

في **عام**، انقر حقل الصورة. يعرض صور المستودع نفسه — PNG وJPEG وGIF وWebP
وSVG وICO وBMP وAVIF — لكل منها صورة مصغّرة، وتأتي أولًا الملفات المسمّاة
كشعار أو أيقونة. اكتب للتضييق (`logo dark` تجد `assets/logo-dark.png`)،
وتنقّل بمفاتيح الأسهم، واضغط Enter للاختيار؛ أو اكتب المسار يدويًا. يُحفظ
المسار **نسبةً إلى جذر المستودع**، فتتبع الصورة المستودع أينما كان مجلده.

ما تعرضه علامة التبويب خيار على مستوى التطبيق كله، في **الإعدادات ← عام ←
تعرض علامات تبويب المستودعات**:

| الخيار | تعرض علامة التبويب |
|---|---|
| **الصورة والاسم** (الافتراضي) | الصورة مكان أيقونة المجلد، ثم الاسم |
| **الاسم فقط** | أيقونة المجلد والاسم، كأن لا صورة |
| **الصورة فقط** | الصورة وحدها؛ وينتقل الاسم إلى التلميح |

حدود ينبغي معرفتها:

- تضم القائمة الملفات التي يراها git — المتتبَّعة وغير المتتبَّعة، دون
  المتجاهَلة — و40 على الأكثر في المرة الواحدة؛ اكتب للوصول إلى البقية. ويمكن
  كتابة صورة متجاهَلة يدويًا مع ذلك.
- الصور الأكبر من 1 ميغابايت، أو التي تتعذّر قراءتها، تظهر باهتة ولا يمكن
  اختيارها: أيقونة بحجم 20 بكسل لا تحتاج إلى أكثر.
- المستودع **بلا** صورة يعرض اسمه دائمًا أيًّا كان الخيار — فعلامة تبويب فارغة
  لا يمكن التعرّف عليها.
- إذا كان المسار **معطوبًا** — حُذف الملف أو أُعيدت تسميته أو ليس صورة أو كبير
  جدًا — تعود علامة التبويب إلى الاسم بصمت، وتعرض علامة تبويب الإعدادات هذه
  تحذيرًا تحت المسار. ولا شيء غير ذلك يشتكي.
- تُقرأ الصورة مرة واحدة في كل جلسة. إذا استبدلت الملف بالاسم نفسه، فافتح
  علامة تبويب الإعدادات هذه مجددًا لإعادة تحميلها.
- يُحفظ الإعداد في إعدادات Gitcito على هذا الجهاز، لا في المستودع، فلا يرثه
  زملاؤك.
