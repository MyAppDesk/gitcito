# インサイト

Git の履歴から組み立てたダッシュボードです。サービスもアカウントも要らず、ローカルで
`git log` を読むだけです。ツールバーのツール群の隣にある、リポジトリ設定の歯車から
開きます。

![インサイトのダッシュボード](../../screenshots/insights.webp)

| パネル | 分かること |
|---|---|
| **サマリーカード** | 1 日あたりのコミット数、貢献者、変更されたファイル、変更された行数 |
| **週ごとの変更量** | 追加と削除を、週ごとに突き合わせて |
| **主な貢献者** | コミット数と行数で |
| **ファイルのホットスポット** | 最も変更されたファイル — クリックするとその履歴へ飛べます |

全体を **30 日 / 90 日 / 1 年 / 全期間** で絞り込めます。

面白いのはホットスポットのパネルです。週を追うごとにその一覧の先頭に居座るファイルは、
たいてい編集している人々についてではなく、設計について何かを告げています。

同じ履歴を動く絵として見たいときは、[タイムラプス](timelapse.md) をどうぞ。
