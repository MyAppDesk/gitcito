# תגיות וריליסים

צרו תגית מכל קומיט:

| סוג | מתי |
|---|---|
| **קלה** | מצביע. בסדר גמור לסימון אישי |
| **מבוארת** | נושאת הודעה, מחבר ותאריך — מה שריליס צריך להיות |
| **חתומה** | מבוארת, ובנוסף חתימת GPG/SSH |

![יצירת תגית: שם, הודעה לבחירה, והאם לחתום עליה](../../screenshots/create-tag.webp)

מחקו תגיות מקומית, דחפו אותן, או מחקו אותן ברימוט. תגיות מרוחקות ניתנות לדפדוף
בלי להביא את כולן קודם.

ב־GitHub, **ריליסים** שפורסמו מופיעים בסרגל הצד עם עמוד יומן שינויים — ראו
[אירוח](hosting.md). כדי לנסח את ההערות, השתמשו
ב[מחולל יומן השינויים](changelog.md).

**ראו גם:** [קומיטים חתומים](signing.md) · [מחולל יומן השינויים](changelog.md)
