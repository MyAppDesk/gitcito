# 保险库

一个项目需要的 `.env` 值总得放在某个地方。保险库就是那个地方，而且不会让它们最终
进到仓库里。

![保险库](../../screenshots/vault.webp)

- **静态加密**，用你的操作系统钥匙串。
- **两种作用域**：绑定到某个仓库的条目，以及一套可以在任何地方引用的**全局**条目。
- **它不是文件，也和你的 `.env` 没有关系。** 条目只是与仓库*关联*，从不写入其中，
  从不提交，从不推送。
- **任何东西都不会离开你的机器。** 没有同步，没有云。

## 怎么用

用 <kbd>⌘⇧V</kbd> 打开，也可以从工具菜单、设置或命令面板打开。你可以在任意已知仓库
之间切换，显示或复制某个值，或者把一整套条目 **以 .env 格式复制** 到剪贴板。

## 在多台机器之间搬运

[安全分享](secure-share.md)可以把保险库打包成一个加密包——而且只有在你明确要求包含
机密时才会这么做。
