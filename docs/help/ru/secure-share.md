# Безопасная передача

Настройка новой машины обычно означает, что всё придётся вводить заново. Вместо
этого безопасная передача упаковывает всё в один зашифрованный бандл.

![Экспорт настроек одного репозитория в виде зашифрованного бандла](../../screenshots/secure-share.webp)

![Тот же экспорт для целого рабочего пространства](../../screenshots/secure-workspace.webp)

## Что можно положить внутрь

| Раздел | Содержимое |
|---|---|
| **Настройки** | Темы, компоновка, горячие клавиши, предпочтения |
| **Сейф** | Глобальные и порепозиторные секреты |
| **Репозитории** | Репозитории рабочего пространства, при импорте сопоставляемые по удалённому адресу или папке |

Секреты попадают внутрь, только если вы **поставили галочку**. Бандл без этой
галочки не содержит никаких учётных данных вообще.

## Импорт

Экран импорта показывает, что внутри, **до** того как что-либо применяется,
раздел за разделом, а репозитории сопоставляются с тем, что у вас уже есть —
сначала по URL удалённого репозитория, потом по папке, — так что импорт не
клонирует полмира заново.
