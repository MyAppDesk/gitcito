# コマンドパレットと検索

## パレット — <kbd>⌘K</kbd>

**ブランチ**（チェックアウトします）、**コミット**（グラフをそこまでスクロールします）、
**作業ツリーのファイル**、**アクション** — フェッチ、プル、プッシュ、スタッシュ、
ターミナル、reflog、設定、そしてこのハンドブックにあるすべての機能 — へ、あいまい検索で
跳べます。

学習します。最近使ったものが先に来て、よく使うものはそうでないものより上に並びます。

![コマンドパレット](../../screenshots/command-palette.webp)

## コード検索 — <kbd>⌘⇧F</kbd>

2 つの異なる問いを、1 つのダイアログで。

| モード | 答える問い |
|---|---|
| **内容** | 「この文字列はいまどこにあるのか」— 追跡中 *および* 未追跡のファイルへの `git grep`。大文字小文字、単語単位、正規表現に対応。 |
| **履歴の pickaxe** | 「この文字列はいつ現れ、いつ消えたのか」— `git log -S` / `-G`。 |

ヒットは構文強調され、一致箇所に印が付いた状態で、ファイルごとにまとめられて返り、
展開すればその行まで辿れます。クリックすればその行でファイルを開くか、それを持ち込んだ
コミットを開けます。

![コード検索の結果](../../screenshots/code-search.webp)

## グラフを絞り込む

グラフの上の検索ボックスは、メッセージ、作者、SHA、デプロイ状態でコミットを絞り込み
ます。「このファイルに触れたコミットだけ」が欲しいときはパス絞り込みを使ってください
