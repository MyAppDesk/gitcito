# Диффы и предпросмотр

## Как читать дифф

| Переключатель | Что делает |
|---|---|
| **Единый ↔ раздельный** | Бок о бок — когда хочется сравнивать, друг под другом — когда хочется читать |
| **По словам** | Подсвечивает только изменившиеся токены внутри отредактированной строки — красным в старой, зелёным в новой |
| **Игнорировать пробелы** | Прячет перестановку отступов, чтобы всплыло настоящее изменение |
| **Перенос** (только в двух колонках) | Переносит длинные строки внутри колонки вместо прокрутки |
| **Связано** (две колонки, без переноса) | Прокручивает обе половины вместе, по вертикали и по горизонтали — выключено, каждая колонка сама по себе |
| <kbd>⌘F</kbd> | Поиск внутри диффа, с переходом к следующему и предыдущему |

Перенос по умолчанию выключен: одна строка занимает один ряд, поэтому обе
стороны остаются сопоставимыми строка к строке, а каждая половина
прокручивается по горизонтали своей полосой. Включайте его, когда длинную
строку хочется прочитать, а не догонять, — расплата в том, что строка,
свёрнутая в три ряда, больше не стоит напротив своей пары. Каждый
переключатель запоминает состояние между файлами и сеансами.

Без переноса обе половины по умолчанию прокручиваются **связанно** — по
вертикали, что держит строки друг напротив друга, и по горизонтали, поэтому
90-я колонка слева стоит над 90-й справа. Развяжите их, когда стороны
разошлись — блок с отступом против блока без него, переименование, сдвинувшее
каждую строку, — или когда хочется сравнить два далёких участка одного файла,
и оставьте каждую половину там, где её содержимое.

![Раздельный дифф с подсветкой по словам](../../screenshots/split-diff.webp)

Над каждым диффом стоит [семантическая сводка](semantic-diff.md) — что
изменилось, символ за символом, а не строка за строкой.

## Диффы изображений

Изменившиеся картинки получают настоящее сравнение: бок о бок или ползунок,
которым перетаскиваешь границу между «до» и «после».

![Дифф изображения](../../screenshots/image-diff.webp)

## Предпросмотр чего угодно

Режим **Предпросмотр** отрисовывает файл, а не показывает его исходник: Markdown,
Word (`.docx`), Excel (`.xlsx`), PDF, видео, аудио, картинки — и код с подсветкой
синтаксиса для всего остального.

![Предпросмотр Markdown](../../screenshots/markdown-preview.webp)

## Очень большие файлы

Предпросмотр и просмотр файла загружают файл в память целиком, поэтому оба
отказываются открывать файлы сверх лимита размера (32 МБ для предпросмотра,
16 МБ для текста) и вместо этого показывают, насколько велик файл. **Всё равно
загрузить** снимает лимит для этого файла — ничто не остаётся недоступным,
большие загрузки просто требуют явного согласия. Файлы и диффы длиннее
нескольких тысяч строк по-прежнему рендерятся целиком, но строки за пределами
видимой области больше не компонуются и не отрисовываются — гигантский дифф
lockfile-а перестаёт стоить памяти целого ноутбука.

![Файл сверх лимита размера с кнопкой «Всё равно загрузить»](../../screenshots/file-too-large.webp)

висят бейджи статуса (добавлено / изменено / удалено), суммирующие то, что внутри.
