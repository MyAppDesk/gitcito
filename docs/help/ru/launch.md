# Запуск и отладка

Gitcito читает ваш `.vscode/launch.json` — корневой и любые вложенные,
сгруппированные разделителями, — и запускает выбранную конфигурацию во
встроенном терминале.

![Выбор конфигурации запуска и плавающая панель](../../screenshots/launch-configs.webp)

- **Переменные VS Code раскрываются** (`${workspaceFolder}` и компания).
- **`preLaunchTask`** конфигурации выполняется первым.
- Значения **`${input:…}`** спрашиваются интерактивно перед запуском
  (`promptString` и `pickString`).
  `pickString` показывает варианты как настоящий выбор со значением по
  умолчанию; `promptString` с пометкой `password` маскируется.
- Задачи с **`isBackground`** (вотчеры, dev-серверы) запускаются отдельно, так что
  никогда не блокируют старт.
- **Compounds** запускают каждого участника как **собственную параллельную
  сессию** — в одном разделённом терминале с именем compound, по панели на
  участника, ровно как debug-сессии VS Code. С `stopAll: true` остановка
  одного участника останавливает всех.
  Задачи, общие для нескольких участников, выполняются **один раз**, в своей
  панели, до запуска участников — запрос повышения версии спрашивает один раз,
  а не по разу на участника.
  Эта панель закрывается сама при успехе и остаётся открытой при ошибке.
- **`serverReadyAction`** учитывается: когда вывод сессии совпадает с заданным
  шаблоном, объявленный URL открывается в браузере
  (`openExternally`; `debugWithChrome` / `debugWithEdge` тоже открывают браузер
  — Gitcito не может подключить к нему отладчик).

![Compound, запустивший две параллельные сессии](../../screenshots/launch-compound.webp)

![Выбор ${input} со значением по умолчанию](../../screenshots/launch-input.webp)

Плавающая панель даёт **паузу / продолжение, перезапуск, остановку** и
переключает между запущенными сессиями.

Включается в **Настройки → Общие → Включить launch.json**. Кнопка **LAUNCH**
появляется рядом с вкладками Git / Файлы.

Участник compound отображается как *compound › участник*, а его перезапуск
перезапускает только этого участника.
Если панель закрывает что-то нужное, перетащите её в сторону за ручку —
позиция запоминается, а двойной щелчок по ручке возвращает её в центр.

Чего Gitcito сознательно **не** делает: он запускает ваши программы в
настоящих терминалах, но он не отладчик — без точек останова, без просмотра
переменных, без Debug Adapter Protocol. Конфигурации только-attach работают,
когда несут `preLaunchTask` (задача и есть работа); чистый attach запускать
нечего.
