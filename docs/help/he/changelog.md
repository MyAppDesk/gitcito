# מחולל יומן השינויים

תנו לו שני refs — ברירת המחדל היא **התגית האחרונה ← HEAD** — והוא יהפוך את
הקומיטים שביניהם ליומן שינויים, מקובץ לפי סוג Conventional Commit.

![מחולל יומן השינויים](../../screenshots/changelog-gen.webp)

- **שינויים שוברים** עולים ראשונים, מאיזה סוג שלא יגיעו.
- אחר כך Features, Fixes, Performance וכן הלאה.
- קומיטים שאינם עוקבים אחרי שום קונבנציה נוחתים תחת **Other** במקום להיזרק —
  יומן שינויים שמאבד קומיטים בשקט גרוע מיומן מבולגן.

העתיקו את התוצאה, או **הוסיפו אותה ישירות בראש `CHANGELOG.md`**.

> כתיבת ההודעות שלכם [בסגנון Conventional](committing.md) היא מה שהופך את זה
> לשימושי. המחולל טוב בדיוק כמו הכותרות שהוא קורא.
