# Командний рядок

```sh
gitcito .                        # open this folder
gitcito ~/code/api               # …or that one
gitcito . -n "My API"            # with a display name
gitcito . -g "Work"              # inside a group tab
gitcito . -n "My API" -g "Work"  # both
```

## Встановлення шима

Палітра команд (<kbd>⌘K</kbd>) → **Install 'gitcito' command in PATH** (macOS).
Вона створює символьне посилання на невеликий шим у `/usr/local/bin` або
`/opt/homebrew/bin`, а права адміністратора питає лише тоді, коли жодна з цих тек
вам не доступна на запис. Та сама команда, виконана вдруге, видаляє шим.

## Як воно поводиться

- Якщо шлях **уже відкрито** — як вкладку чи всередині групи — Gitcito
  **переводить фокус на нього**, а не відкриває дублікат.
- Якщо це ще не Git-репозиторій, він усе одно відкриється й запропонує сценарій
  «ініціалізувати репозиторій тут».
- `-g` додає репозиторій до групи з такою назвою, створюючи групу, якщо її ще
  немає.
- Gitcito працює **в одному екземплярі**: запуск `gitcito`, коли застосунок уже
  відкрито, передає запит тому вікну, а не запускає другу копію.
