# Чат репозитория

Некоторые вопросы быстрее задать, чем искать на них ответ. *Где на самом деле
обновляется токен? Что изменил этот коммит, одной фразой? Зачем существует этот
файл?* Чат репозитория отвечает по открытому репозиторию и показывает строки, на
которые опирался.

Он делит правую колонку с **Подробностями**: вкладки сверху переключают между
ними, поэтому граф не теряет выделение, когда вы что-то спрашиваете.

## Что он читает

Каждый ответ строится в два прохода. Первый выбирает небольшой набор путей и
буквальных поисковых строк из списка отслеживаемых файлов самого репозитория.
Второй отвечает только по принесённым фрагментам и может ссылаться только на них:
выдуманный файл или строка — ошибка валидации, а не правдоподобный ответ.

| Включено | Исключено |
|---|---|
| Отслеживаемые файлы в том виде, что в рабочем каталоге | Неотслеживаемые файлы |
| Проиндексированные и непроиндексированные диффы отслеживаемых файлов | Всё, что попадает под правило игнорирования, даже отслеживаемое |
| Ветка, впереди/позади и список изменённых путей | [Файлы, похожие на секреты](security.md), бинарные файлы, сгенерированные пути |

Чтение рабочего каталога позволяет обсуждать незакоммиченные правки. Оно же
означает, что эти правки покидают машину при вопросе: их получает провайдер,
настроенный в [Функциях ИИ](ai.md).

## Закрепление контекста

Что читать, решает модель. Закрепление — способ это переопределить: закреплённое
читается **первым** и забирает большую долю бюджета контекста.

Четыре способа, все ведут в один ряд фишек над полем сообщения:

| Сделайте так | Получите |
|---|---|
| Нажмите предложенную фишку | Файл, открытый в просмотрщике, или коммит, выбранный в графе |
| Перетащите строку из вкладки **Файлы** | Этот файл |
| Перетащите строку из **графа коммитов** | Этот коммит — его сообщение и дифф по фрагментам |
| **+** → *Выбрать файл…* или перетаскивание из Finder/Проводника | Любой файл на диске, в том числе вне репозитория |

Фишки остаются закреплёнными для следующих вопросов; `×` убирает одну, очистка
беседы — все. Предел — восемь.

Закреплённый коммит даёт своё сообщение и до двенадцати фрагментов диффа.
Фрагменты по исключённым путям выпадают из этого диффа, а не весь коммит.

## Настройки

**Настройки → ИИ → Чат репозитория**:

| Настройка | Что делает |
|---|---|
| **Задавайте вопросы о репозитории** | Выключено убирает вкладку, кнопку панели и цель сочетания клавиш. Остальной ИИ работает |
| **Модель чата** | Модель только для чата. Пусто — модель профиля: вопрос дешевле ревью, меньшей часто достаточно |
| **Только закоммиченное** | Отвечает по последнему коммиту, а не по рабочему каталогу: незакоммиченные правки не покидают машину |

Если ИИ выключен целиком, чат исчезает вместе с ним — нет панели, обещающей
ответ, которого никто не даст.

## В чём он отказывает

- **Файлы, похожие на секреты, не читаются никогда**, закреплены они или нет:
  фишка возвращается помеченной как пропущенная, с причиной. Закрепление не
  обходит [маскирование секретов](security.md).
- **Бинарные файлы и файлы больше 512 КБ** извне репозитория пропускаются так же.
  Внутри действуют обычные правила.
- **Он никогда не пишет.** Ни индекса, ни коммитов, ни смены веток — у него нет
  инструментов, только текст. Ответ, утверждающий, что что-то сделано, описывает,
  а не сообщает.
- **Беседы живут только в памяти.** У каждого репозитория своя нить; выход из
  Gitcito их удаляет.

## Как открыть

| Клавиши | Что делают |
|---|---|
| Кнопка с облачком речи на панели инструментов | Переключает вкладку «Чат» |
| <kbd>⌘⌥B</kbd> / <kbd>Ctrl+Alt+B</kbd> | Переключает всю правую панель |
| <kbd>⌘⏎</kbd> / <kbd>Ctrl+Enter</kbd> | Отправляет сообщение |

Остальное, включая переназначение переключателей панелей, — в разделе
[Клавиатура и сочетания](keyboard.md).
