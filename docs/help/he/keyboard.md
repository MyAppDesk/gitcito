# מקלדת וקיצורים

לחצו <kbd>?</kbd> בכל מקום כדי לקבל את דף העזר.

![דף העזר של הקיצורים](../../screenshots/cheatsheet.webp)

## אלה ששווה ללמוד

| מקשים | מה זה עושה |
|---|---|
| <kbd>⌘K</kbd> | [פלטת הפקודות](search.md) — ענפים, קומיטים, קבצים, פעולות |
| <kbd>⌘⇧F</kbd> | [חיפוש בקוד](search.md) בכל עץ העבודה |
| <kbd>⌘⇧V</kbd> | [הכספת](vault.md) |
| <kbd>⌘O</kbd> / <kbd>Ctrl+O</kbd> | פתיחת מאגר |
| <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd> | פתיחת ההגדרות |
| <kbd>⌘F</kbd> | חיפוש בתוך הקובץ או הדיף שאתם קוראים |
| <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> | פתיחת בורר המאגרים או הקבוצות ללשונית חדשה |
| <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> | סגירת הלשונית הפעילה — או החלון, ברגע שלא נותרה אף לשונית |
| <kbd>⌘1</kbd>–<kbd>⌘9</kbd> / <kbd>Ctrl+1</kbd>–<kbd>Ctrl+9</kbd> | מעבר ללשונית לפי מיקומה |
| <kbd>⌘⇧T</kbd> | פתיחה מחדש של הלשונית האחרונה שנסגרה |
| <kbd>?</kbd> | דף העזר הזה |

## תנועה בלי העכבר

| היכן | מקשים |
|---|---|
| גרף הקומיטים | <kbd>↑</kbd> <kbd>↓</kbd> או <kbd>j</kbd> <kbd>k</kbd> |
| רשימות קבצים (קומיט, עבודה בתהליך, סטאש) | אותו דבר |
| [מכונת הזמן](time-machine.md) | <kbd>←</kbd> <kbd>→</kbd>, <kbd>⇧</kbd> לעשרה, <kbd>Home</kbd>/<kbd>End</kbd> |
| [חדר הבקרה](mission-control.md) | <kbd>↑</kbd><kbd>↓</kbd>, <kbd>Enter</kbd> לפתיחה, <kbd>f</kbd>/<kbd>p</kbd> להבאה/משיכה, <kbd>/</kbd> לסינון |
| תיבת הודעת הקומיט | <kbd>↑</kbd> <kbd>↓</kbd> מעלה את ההודעות האחרונות שלכם |

## שינוי השיוך

**הגדרות ← קיצורים**. קיצורי הניווט המרכזיים (פלטה, חיפוש בקוד, כספת, פתיחת
מאגר, הגדרות) ניתנים לשיוך מחדש, עם זיהוי התנגשויות ואיפוס לכל קיצור בנפרד.

הקיצורים הקבועים שלמעלה אינם ניתנים לשיוך מחדש, והם גם נדחים בתור _יעד_:
האפליקציה עונה על <kbd>⌘T</kbd>, <kbd>⌘W</kbd>, <kbd>⌘1</kbd>–<kbd>⌘9</kbd>,
<kbd>⌘⇧T</kbd>, <kbd>⌘S</kbd>, <kbd>⌘Z</kbd>, <kbd>⌘⇧Z</kbd> ו־<kbd>⌘F</kbd>
לפני שהיא מתייעצת עם השיוכים שלכם, ולכן קיצור שהוקצה לאחד מהם ייראה מוגדר ולעולם
לא יופעל. בחרו אחד מאלה, והעורך יאמר זאת במקום לקבל אותו.
