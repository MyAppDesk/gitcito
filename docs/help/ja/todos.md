# TODO

開発中に書き留めることの半分は一行で足り、その日の午後だけ生きています。
*PR の前にあの変数の名前を直す*、*フィクスチャのパスが違う*、*リトライ回数の
上限を確認する*。イシュートラッカーはこれには重すぎ、走り書きのファイルは
うっかりコミットされ、付箋はリポジトリを切り替えた瞬間に消えます。

TODO はそのためのリストで、いま開いているリポジトリに結び付いています。

![1 件を開いた TODO 一覧。メモと優先度が見える](../../screenshots/todos.webp)

## どこに保存されるか

リポジトリの中ではありません。TODO は Gitcito 自身の設定に、リポジトリのパスを
キーとして保存されます。ここから知っておく価値のある 3 つの結果が出ます。

- **何もコミットされません。** `git status` にファイルは現れないので、TODO が
  コミットや差分に紛れ込むことはありません。
- **他の人には見えません。** これは自分宛てのメモであって、共有バックログでは
  ありません。チームの仕事なら、それはイシューの領分です。
- **ブランチではなくフォルダーに付きます。** 同じクローンを 2 つのタブで開いても
  リストは 1 つです。同じプロジェクトをディスクの別の場所にもう一度クローンすれば、
  別のリストになります。

書いたときにチェックアウトしていたブランチは *文脈* として記録され、詳細に
表示されます。どこにいたかの手掛かりであり、絞り込みではありません。別の
ブランチに切り替えても TODO は消えません。

## 書き方

一覧を開きます — **TODO** セクション見出しの ↗ ボタン、ステータスバーのチップ、
またはコマンドパレットの **TODO**。行を入力して <kbd>Enter</kbd> を押すだけです。
サイドバーのセクションは読んでチェックを付けるための一覧のままで、書く場所は
一箇所に保たれます。

並び順は決まっています。まず未完了 — 優先度「高」が「標準」より上、「標準」が
「低」より上 — で、同じ優先度なら古いものが先。いちばん長く放置されたものこそ
見る価値があるからです。完了したものは下に沈み、直近でチェックしたものが上に
来るので、押し間違いはすぐ戻せます。

## 自分の順番に並べる

既定の並び順には主張があり、ときどき外れます。今日の午後に本当にやるつもりの三つ
は、必ずしもいちばん声の大きい三つではありません。行のグリップをつかんでドラッグ
するか、行の ▲ / ▼ ボタンを押すと — <kbd>Alt</kbd> と矢印キーでも同じ — 並べた順
のまま保たれます。

最初のドラッグや移動で **手動の並び順** が有効になります。フィルター行のチェック
を外せば優先度による並び順に戻り、そちらは元のまま覚えられています。知っておきた
い制限が二つ:

- **動くのは未完了のタスクだけです。** 完了したものはどのモードでも下の山に、最後
  にチェックしたものを先頭にして残ります。
- **フィルターに文字が入っている間は並べ替えが引っ込みます。** 見えていない隣を飛
  び越した行は、思っていない場所に着地するからです。

優先度は各行の横のシグナルバーとして表示され続けます（低は 1 本、高は 3 本）。
ステータスバーの黄色いチップも引き続きこれで決まります。

## 見に行かなくても分かる

![サイドバーのセクションとステータスバーのチップが 1 つのウィンドウに](../../screenshots/todos-markers.webp)

| 目印 | 場所 | 意味 |
|---|---|---|
| <kbd>☑ 3</kbd> チップ | ステータスバー、ブランチ名の左 | 未完了の件数。優先度「高」があれば黄色 |
| 件数バッジ | サイドバーのセクション見出し | 同じ数字を、一覧のすぐ隣に |

どちらも 0 件では消えます。「0 件」を出し続ける表示は家具であり、家具はやがて
目に入らなくなるものです。

## 詳細ビュー

TODO をクリックすると — サイドバー、ステータスバーのチップ、コマンドパレットの
**TODO** のいずれからでも — 詳細ペイン付きの一覧が開きます。

| 項目 | 役割 |
|---|---|
| **タイトル** | その一行。その場で編集でき、保存ボタンはありません。 |
| **メモ** | タイトルに収まらないすべて。なぜ必要か、どのファイルか、何をもって完了とするか。 |
| **優先度** | 低・標準・高。並び順とステータスチップの色を決めます。 |
| **作成 / 完了** | 書いた日時と、チェックを付けた日時。 |
| **作成時のブランチ** | そのときチェックアウトしていたブランチ。 |

同じ画面に絞り込み欄、**完了も表示** の切り替え、そして **完了を削除** があり、
最後のものはチェック済みを完全に消す前に確認します。

この切り替えは **設定 → 外観 → 完了したタスクを隠す** と同じスイッチです。オフにすると、チェック済みのタスクはこの一覧からもサイドバーのセクションからも消えます。削除はされず、件数には引き続き含まれます。既定では隠す設定なので、最初は未完了のタスクだけが表示されます。

## あえてしないこと

- **期限も、催促も、通知もありません。** せかす TODO リストはカレンダーです。
  これは見に来るまで黙って待ちます。
- **同期も共有もしません。** 端末から出ませんし、ワークスペースのエクスポートにも
  含まれません。
- **イシューやコミットとの紐付けはありません。** それだけの構造が必要なメモは
  この一覧を卒業しています — [イシュー](hosting.md)を立ててください。
- **削除は取り消せません。** git が記録していなかったものなので、削除に対する
  取り消し履歴もありません。
