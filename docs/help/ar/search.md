# لوحة الأوامر والبحث

## اللوحة — <kbd>⌘K</kbd>

قفزة غامضة إلى **فرع** (فيُسحب)، أو **التزام** (فيتمرر الرسم البياني إليه)، أو
**ملف في شجرة العمل**، أو **إجراء** — جلب، وسحب، وإرسال، وإخفاء، وطرفية، وسجل
مراجع، وإعدادات، وكل ميزة في هذا الدليل.

وهي تتعلم: ما استخدمته مؤخرًا يأتي أولًا، وما تستخدمه كثيرًا يسبق ما لا تستخدمه.

![لوحة الأوامر](../../screenshots/command-palette.webp)

## البحث في الشيفرة — <kbd>⌘⇧F</kbd>

سؤالان مختلفان، وحوار واحد:

| الوضع | السؤال الذي يجيب عنه |
|---|---|
| **المحتويات** | «أين هذه السلسلة الآن؟» — `git grep` على الملفات المتتبَّعة *وغير* المتتبَّعة، مع مطابقة حالة الأحرف / الكلمة الكاملة / التعابير النمطية. |
| **معول السجل** | «متى ظهرت هذه السلسلة أو اختفت؟» — `git log -S` / `-G`. |

تعود النتائج مُبرَزة نحويًا مع تعليم المطابقة، مجمَّعةً بحسب الملف وقابلةً للتوسيع
إلى الأسطر بالضبط. اضغط إحداها لتفتح الملف عند ذلك السطر، أو الالتزام الذي
أدخلها.

![نتائج البحث في الشيفرة](../../screenshots/code-search.webp)
