# ריבייס אינטראקטיבי

רשימת ה־todo של `git rebase -i`, בתור רשימה שאפשר לגרור.

![עורך הריבייס האינטראקטיבי](../../screenshots/interactive-rebase.webp)

| פעולה | פירושה |
|---|---|
| **pick** | להשאיר כמו שהוא |
| **reword** | להשאיר את השינוי, לערוך את ההודעה |
| **squash** | לקפל לתוך הקומיט שמעל, ולמזג את שתי ההודעות |
| **fixup** | לקפל לתוך הקומיט שמעל, ולזרוק את ההודעה הזו |
| **edit** | לעצור כאן כדי שתוכלו לתקן |
| **drop** | לזרוק את הקומיט |

גררו שורות כדי לסדר מחדש. העורך לעולם אינו נפתח בטרמינל — Gitcito כותב את
ה־todo בשבילכם.

## Autosquash, בלחיצה אחת

- **קיפול השינויים שבסטייג׳ לתוך הקומיט הזה** יוצר בשבילכם את ה־`fixup!`.
- **Autosquash מכאן** מקפל כל `fixup!` / `squash!` לתוך היעד שלו.

אם יש לכם ערימה של תיקוני סקירה ולא אחד, [ספיגה](absorb.md) מבררת לאיזה קומיט
שייך כל קטע, כדי שלא תצטרכו.

> ריבייס כותב היסטוריה מחדש. כל מה שכבר נדחף יצטרך דחיפה כפויה, ומי שסקר אותו
> ירצה [מה השתנה מאז](range-diff.md).
