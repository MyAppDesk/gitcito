# Klavye ve kısayollar

Kopya kâğıdı için herhangi bir yerde <kbd>?</kbd> tuşuna basın.

![Kısayol kopya kâğıdı](../../screenshots/cheatsheet.webp)

## Öğrenmeye değer olanlar

| Tuşlar | Ne yapar |
|---|---|
| <kbd>⌘K</kbd> | [Komut paleti](search.md) — dallar, commit'ler, dosyalar, eylemler |
| <kbd>⌘⇧F</kbd> | Çalışma dizini genelinde [kod araması](search.md) |
| <kbd>⌘⇧V</kbd> | [Kasa](vault.md) |
| <kbd>⌘O</kbd> / <kbd>Ctrl+O</kbd> | Bir depo açar |
| <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd> | Ayarları açar |
| <kbd>⌘F</kbd> | Okuduğunuz dosyanın ya da diff'in içinde arama yapar |
| <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> | Yeni sekme için depo ya da grup seçiciyi açar |
| <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> | Etkin sekmeyi kapatır — hiç sekme kalmadıysa pencereyi |
| <kbd>⌘1</kbd>–<kbd>⌘9</kbd> / <kbd>Ctrl+1</kbd>–<kbd>Ctrl+9</kbd> | Konumuna göre bir sekmeye geçer |
| <kbd>⌘⇧T</kbd> | Son kapatılan sekmeyi yeniden açar |
| <kbd>?</kbd> | Bu kopya kâğıdı |

## Fareye dokunmadan gezinme

| Nerede | Tuşlar |
|---|---|
| Commit grafiği | <kbd>↑</kbd> <kbd>↓</kbd> ya da <kbd>j</kbd> <kbd>k</kbd> |
| Dosya listeleri (commit, WIP, stash) | Aynısı |
| [Zaman makinesi](time-machine.md) | <kbd>←</kbd> <kbd>→</kbd>, onar onar atlamak için <kbd>⇧</kbd>, <kbd>Home</kbd>/<kbd>End</kbd> |
| [Görev merkezi](mission-control.md) | <kbd>↑</kbd><kbd>↓</kbd>, açmak için <kbd>Enter</kbd>, fetch/pull için <kbd>f</kbd>/<kbd>p</kbd>, filtrelemek için <kbd>/</kbd> |
| Commit mesajı kutusu | <kbd>↑</kbd> <kbd>↓</kbd> son mesajlarınızı geri çağırır |

## Yeniden atama

**Ayarlar → Kısayollar**. Temel gezinme kısayolları (palet, kod araması, kasa,
depo açma, ayarlar) yeniden atanabilir; çakışma tespiti ve kısayol başına
sıfırlama ile birlikte.

Yukarıdaki sabit kısayollar yeniden atanamaz ve ayrıca _hedef_ olarak da kabul
edilmez: uygulama <kbd>⌘T</kbd>, <kbd>⌘W</kbd>, <kbd>⌘1</kbd>–<kbd>⌘9</kbd>,
<kbd>⌘⇧T</kbd>, <kbd>⌘S</kbd>, <kbd>⌘Z</kbd>, <kbd>⌘⇧Z</kbd> ve <kbd>⌘F</kbd>
tuşlarını sizin atamalarınıza bakmadan önce yanıtlar; dolayısıyla bunlardan
birine atanmış bir kısayol ayarlanmış görünür ama hiç çalışmaz. Bunlardan birini
seçtiğinizde düzenleyici, kabul etmek yerine bunu size söyler.
