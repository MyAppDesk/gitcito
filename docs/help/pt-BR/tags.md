# Tags e releases

Crie uma tag a partir de qualquer commit:

| Tipo | Quando |
|---|---|
| **Leve** | Um ponteiro. Suficiente para uma marca pessoal |
| **Anotada** | Carrega mensagem, autoria e data — o que um release deveria ser |
| **Assinada** | Anotada, mais uma assinatura GPG/SSH |

![Criando uma tag: nome, mensagem opcional, e se deve ser assinada](../../screenshots/create-tag.webp)

Apague tags localmente, publique-as, ou apague-as no remote. Tags remotas podem ser
exploradas sem buscar todas antes.

No GitHub, os **releases** publicados são listados na barra lateral com uma página
de changelog — veja [Hosting](hosting.md). Para redigir as notas, use o
[gerador de changelog](changelog.md).
