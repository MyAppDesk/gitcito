# Blame и история файла

Откройте любой файл и переключите режим просмотра: **Просмотр · Файл · Дифф ·
Blame · История**.

![Blame: в поле слева коммит, стоящий за каждой строкой](../../screenshots/blame.webp)

## Blame

Каждая строка несёт свой коммит, автора и дату, с цветовой кодировкой по
коммиту, так что блоки общей истории видны с одного взгляда.

- **Проследить строку до диффа**: перейти от строки blame прямо к изменению,
  которое её породило.
- **Blame до этого коммита**: правый клик по строке, чтобы посмотреть blame
  файла таким, каким он был *до* этого коммита, — так историю строки
  разматывают назад, не покидая вида.

## История

Каждый коммит, трогавший этот файл, свежие сверху. Выбор коммита показывает его
версию файла, так что можно пролистать, как файл рос.

![Каждый коммит, трогавший один файл, свежие сверху](../../screenshots/file-history.webp)

Для всего репозитория, а не одного файла, есть
[машина времени](time-machine.md).

## Наведите, чтобы получить объяснение

Если ИИ включён, удержание <kbd>⇧</kbd> (настраивается, можно и вовсе без
клавиши) и наведение на идентификатор дают его однострочное объяснение и строки,
на которые оно опирается, — кликните по одной, чтобы туда перейти. Читается
только пронумерованное окно вокруг токена, поэтому, когда что-то определено в
другом месте, ИИ так и говорит, а не выдумывает. См.
[возможности ИИ](ai.md).
