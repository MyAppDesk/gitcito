# Запуск і налагодження

Gitcito читає ваш `.vscode/launch.json` — кореневий і будь-які вкладені,
згруповані з роздільниками — і запускає вибрану вами конфігурацію у вбудованому
терміналі.

![Вибір конфігурації запуску та плавальна панель інструментів](../../screenshots/launch-configs.webp)

- **Змінні VS Code розв’язуються** (`${workspaceFolder}` і компанія).
- **`preLaunchTask`** конфігурації виконується першим.
- Значення **`${input:…}`** запитуються інтерактивно перед запуском
  (`promptString` і `pickString`).
- Завдання з **`isBackground`** (спостерігачі, dev-сервери) виконуються
  відокремлено, тож ніколи не блокують запуск.

Плавальна панель інструментів дає **паузу / продовження, перезапуск, зупинку** і
перемикає між запущеними сесіями.

Увімкніть це в **Налаштування → Загальні → Увімкнути launch.json**. Кнопка
**LAUNCH** з’явиться поруч із вкладками Git / Files.
