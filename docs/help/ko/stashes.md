# 스태시

Gitcito에서 스태시는 전부 아니면 전무가 아니에요.

| 동작 | 하는 일 |
|---|---|
| **스태시** | 전부, 원한다면 추적되지 않는 파일까지, 메시지와 함께 |
| **부분 스태시** | 원하는 파일만 체크; 필요하면 `--keep-index` |
| **적용 / 팝** | 스태시 전체, 또는 **그중 일부 파일만** |
| **스태시 → 브랜치** | `git stash branch` — 스태시가 깨끗하게 적용되지 않을 때의 비상구 |

스태시를 선택하면 커밋과 똑같이 그 파일들과 차이를 볼 수 있어요.

![부분 스태시: 들어가야 할 파일만 체크한 모습](../../screenshots/stash-partial.webp)

## 스태시가 적용되지 않을 때

스태시를 적용하면 추적되지 않는 파일을 덮어쓰게 될 경우, git은 멈춰 서요.
Gitcito는 주문을 알아내는 일을 당신에게 떠넘기는 대신, 그 파일들을 덮어쓰고 다시
시도할지 물어봐요.

작업 트리가 너무 멀리 가 버렸다면, **스태시 → 브랜치** 가 스태시를 뜬 그 브랜치를
다시 만들고, 거기에 깨끗하게 적용한 뒤, 스태시를 버려요.

## 스냅샷과 헷갈리지 않기

[WIP 스냅샷](recovery.md)은 자동이고 감춰져 있지만, 스태시는 의도적이고 목록에
나와요. 스냅샷은 당신의 스태시 목록을 절대 건드리지 않아요.
