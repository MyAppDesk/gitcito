# Контекстное меню репозитория

Щёлкните правой кнопкой по репозиторию — отдельной вкладке, чипу внутри группы,
чипу во вложенной папке, строке в списке приветствия/лаунчера или строке в
выпадающем списке репозиториев на панели инструментов — и вы получите одно и то
же меню, привязанное к репозиторию. Сам чип группы по-прежнему открывает меню
группы; клик должен попасть именно по репозиторию.

![Контекстное меню репозитория на чипе внутри группы](../../screenshots/repo-context-menu.webp)

Выпадающий список репозиториев на панели инструментов перечисляет каждый
открытый репозиторий — так же, как список веток перечисляет ветки. Левый клик по
строке переключает на неё. Правый клик по строке (или по самой плашке текущего
репозитория) даёт псевдоним, рабочие деревья, GitHub, терминал, показ в файловом
менеджере, редактор и удаление. **Открыть репозиторий…** внизу открывает
лаунчер.

![Правый клик по строке в выпадающем списке репозиториев на панели инструментов](../../screenshots/repo-dropdown-context-menu.webp)

## Что делает каждое действие

| Действие | Эффект |
|---|---|
| **Создать псевдоним…** / **Изменить псевдоним…** | Только отображаемое имя. Gitcito никогда не переименовывает и не перемещает папку на диске. Один и тот же псевдоним следует за репозиторием по вкладкам, группам и рабочим пространствам. |
| **Удалить псевдоним** | Показывается, когда псевдоним существует. Возвращает имя папки. |
| **Показать рабочие деревья** | Фокусирует этот репозиторий и открывает раздел рабочих деревьев в боковой панели. |
| **Новое рабочее дерево…** | Тот же диалог создания рабочего дерева, что и из ветки. Недоступно, пока путь отсутствует или идёт merge/rebase/cherry-pick/revert. |
| **Копировать имя репозитория** | Копирует каноническое имя папки, а не псевдоним. |
| **Копировать путь репозитория** | Копирует абсолютный путь. |
| **Открыть на GitHub** | Origin, если это github.com, иначе первый разбираемый удалённый GitHub. Недоступно, когда вывести его неоткуда. |
| **Открыть в терминале** | Открывает терминал Gitcito с этим репозиторием в качестве рабочего каталога. |
| **Показать в Finder / Проводнике** | Подсвечивает папку репозитория в файловом менеджере платформы. |
| **Открыть во внешнем редакторе** | Редактор, настроенный в Настройках. Виден, но недоступен, пока ни один не задан. |
| **Убрать…** | Закрывает вкладку или выбрасывает чип из группы. Использует то же предупреждение о незакоммиченной работе, что и кнопка **×**. Файлы с диска при этом никогда не удаляются. |

Отсутствующий или некорректный путь оставляет доступными копирование, псевдоним
и удаление, а всё, что открывало бы или просматривало каталог, делает серым.
