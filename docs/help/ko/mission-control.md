# 미션 컨트롤

저장소가 스무 개일 때, 질문은 늘 같아요. 어느 쪽이 나를 필요로 하지?

미션 컨트롤이 그 답을 줘요. **활성 작업 공간**의 모든 저장소를 한 화면에, 실제로
손이 필요한 순서대로 늘어놓아요.

1. **막힘** — 리베이스나 머지가 반쯤 끝난 채 남았거나, 충돌이 있거나, 아예 읽을 수
   없는 저장소.
2. **동기화 필요** — 먼저 풀할 커밋, 그다음 푸시할 커밋.
3. **작업 중** — 커밋하지 않은 작업, 추적되지 않는 파일.
4. **깨끗함** — 조용한 것들. 맨 아래, 있어야 할 자리에요.

![모든 저장소를 한 화면에, 급한 것부터](../../screenshots/mission-control.webp)

## 한 행이 알려 주는 것

브랜치와 그 업스트림 · ↑앞섬 / ↓뒤처짐 · 커밋하지 않은 것과 추적되지 않는 것의
개수 · 스태시 · 열린 PR(저장소가 이미 로드된 경우) · **14일치 커밋 스파크라인** ·
마지막 커밋 이후 흐른 시간.

행을 펼치면(꺾쇠, 또는 <kbd>space</kbd>) 정확히 어떤 커밋이 푸시를 기다리는지,
어떤 파일이 지저분한지 볼 수 있어요.

## 목록 다루기

- 위쪽의 상태 알약들은 **필터**예요 — "막힘 3개"를 누르면 그것만 보여요.
- **긴급도**, **이름**, **활동** 순으로 정렬할 수 있어요.
- **저장소 여러 개를 체크**해서 페치하거나, 뒤처진 것만 골라 풀할 수 있어요
  (버튼이 개수를 세어 줘요).
- 열려 있는 동안 30초마다 스스로 새로 고쳐요.

| 키 | 동작 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> 또는 <kbd>j</kbd> <kbd>k</kbd> | 목록 이동 |
| <kbd>Enter</kbd> | 그 저장소 열기 |
| <kbd>f</kbd> / <kbd>p</kbd> | 페치 / 풀 |
| <kbd>space</kbd> | 펼치기 |
| <kbd>/</kbd> | 필터로 이동 |

## 탭이 아니라 보기예요

작업 공간 이름 옆의 계기판이 이걸 켜고 꺼요. 아무 탭이나 누르면 하던 일로
돌아가요. 자기 탭을 따로 만들지 않고, 지금 있는 작업 공간에 속해요 — 작업 공간을
바꾸면 그 작업 공간의 대시보드가 나와요.

이 화면을 읽는 일은 **완전히 로컬이에요.** 저장소마다 `git status` 한 번이고,
네트워크도 토큰도 없어요. 대시보드를 여는 것만으로는 어디에도 인증하지 않아요.
페치는 언제나 여러분이 요청했을 때만 일어나요.
