# Машина времени

Чтобы прочитать старый коммит, обычно надо на него переключиться, а значит —
отложить в стеш то, чем вы были заняты. Здесь — не надо.

Тяните ползунок, и **дерево файлов перерисовывается для каждого коммита**:
появляются папки, файлы переезжают между ними, удалённые файлы возвращаются.
Выберите файл — и вы читаете его таким, каким он был на том коммите.

Всё читается из базы объектов (`git ls-tree`, `git show`). **Никакого чекаута,
HEAD не сдвигается, ваша незакоммиченная работа не тронута** — можно
промотать год истории посреди правки.

## Управление

| Клавиша | Действие |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | Один коммит |
| <kbd>⇧</kbd> + <kbd>←</kbd> <kbd>→</kbd> | Десять коммитов |
| <kbd>Home</kbd> / <kbd>End</kbd> | Самый старый / самый новый |

Стрелки по бокам от ползунка делают то же самое. Файлы, затронутые текущим
коммитом, подсвечиваются в дереве, а их количество показано в заголовке.

## Выбор переживает перемещение во времени

Выберите файл и промотайте назад за коммит, который его создал: панель скажет,
что здесь его не существует, и **сохранит ваш выбор**. Промотайте вперёд — и
файл вернётся со своим старым содержимым. В этом и суть: вы двигаете
репозиторий, а не курсор.

**Открыть эту версию** передаёт файл обычному просмотрщику файлов на том
коммите.
