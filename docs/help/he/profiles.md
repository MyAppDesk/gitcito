# פרופילים

פרופיל אוגד **זהות Git** (שם וכתובת דוא״ל) יחד עם **טוקני האינטגרציה** שלה.
החליפו פרופיל ושניהם משתנים יחד — הקומיטים נכתבים בשם הנכון וקריאות ה־API
משתמשות בחשבון הנכון.

שימושי כשאותה מכונה מטפלת גם במאגרי עבודה וגם באישיים, או כשיש לכם שני חשבונות
GitHub.

![פרופיל: זהות git בצד אחד, טוקני האינטגרציה שלה בצד השני](../../screenshots/settings-profiles.webp)

## קשירה לכל מאגר

מאגר יכול להיות **קשור לפרופיל**, כך שהבאה ברקע עליו תמיד מתאמתת בתור החשבון
הנכון — גם בזמן שאתם מסתכלים על מאגר ששייך לאחר.

הטוקנים חיים ב[מחזיק המפתחות של מערכת ההפעלה](security.md) שלכם, לעולם לא בקובץ
ההגדרות.

**ראו גם:** [אבטחה וסודות](security.md) · [אירוח](hosting.md)
