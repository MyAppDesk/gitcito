# オープンソースライセンス

Gitcito は 90 余りのオープンソースパッケージの上に作られており、そのほとんどが見返りに
同じことを求めています。著作権表示をバイナリと一緒に配布することです。MIT、BSD、Apache は
本文にそう書いています。このページはその表示を置く場所です。誰かがコピーを覚えておく
必要のあるファイルではなく、アプリそのものが義務を果たします。

「自分のマシンで実際に何が動いているのか」への正直な答えでもあります。

## 開き方

ステータスバーの**バージョン番号**をクリックすると**新機能**が開くので、そのヘッダーの
**ライセンス**をクリックします。またはコマンドパレットで *オープンソースライセンス* を
検索します。新機能と同じく、専用のタブで開きます。

![ライセンスのタブ](../../screenshots/licenses.webp)

| 列 | 内容 |
|----|------|
| 名前 | npm で公開されているパッケージ名 |
| バージョン | このビルドが解決した正確なバージョン |
| バッジ | パッケージのマニフェストにある SPDX 識別子 |

行を選ぶと、パッケージに含まれるライセンス全文を読めます。リンクのアイコンはプロジェクト
ページをブラウザーで開きます。フィルターはパッケージ名とライセンス識別子の両方を対象に
するので、`Apache` と入力すれば Apache ライセンスのパッケージだけに絞り込めます。

## 対象範囲と対象外

一覧はビルド時に**本番の依存関係ツリー**から生成されます — パッケージ化されたアプリに
入るすべて、あなたが直接求めたことのない推移的な依存関係も含みます — に加えて Electron
自体です。配布されないビルド用ツールは意図的に除外しています。

知っておきたい制限が 2 つあります:

- **ライセンスファイルを含まないパッケージがいくつかあります。** マニフェストに識別子を
  書いているだけです。そうした行は本文をでっち上げずにその旨を示します。読めない
  ライセンスは頼れるライセンスではないからです。
- **識別子はパッケージの自己申告です。** Gitcito はそれを表示するだけで、監査はしません。
  パッケージのマニフェストが間違っていれば、このページも同じく間違います。

Gitcito 自身のライセンスは MIT で、右上のバッジから GitHub で開けます。
