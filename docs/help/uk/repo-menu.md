# Контекстне меню репозиторію

Клацніть правою кнопкою по репозиторію — окремій вкладці, чіпу всередині
групи, чіпу у вкладеній теці, рядку в списку привітання/лаунчера чи рядку у
випадному списку репозиторіїв на панелі інструментів — і ви отримаєте те саме
меню в межах репозиторію. Чіп самої групи, як і раніше, відкриває меню групи;
клік має влучити саме в репозиторій.

![Контекстне меню репозиторію на чіпі в групі](../../screenshots/repo-context-menu.webp)

Випадний список репозиторіїв на панелі інструментів перелічує кожен відкритий
репозиторій — так само, як випадний список гілок перелічує гілки. Лівий клік
по рядку перемикає на нього. Правий клік по рядку (або по самій «пігулці»
поточного репозиторію) дає псевдонім, робочі дерева, GitHub, термінал, показ,
редактор і прибирання. **Відкрити репозиторій…** унизу відкриває лаунчер.

![Правий клік по рядку у випадному списку репозиторіїв на панелі інструментів](../../screenshots/repo-dropdown-context-menu.webp)

## Що робить кожна дія

| Дія | Ефект |
|---|---|
| **Створити псевдонім…** / **Змінити псевдонім…** | Лише назва для показу. Gitcito ніколи не перейменовує й не переміщує теку на диску. Той самий псевдонім супроводжує репозиторій у вкладках, групах і робочих просторах. |
| **Видалити псевдонім** | Показується, коли псевдонім існує. Повертає назву теки. |
| **Показати робочі дерева** | Фокусується на цьому репозиторії й відкриває розділ робочих дерев у бічній панелі. |
| **Нове робоче дерево…** | Той самий діалог створення робочого дерева, що й із гілки. Недоступно, поки шлях відсутній або триває merge/rebase/cherry-pick/revert. |
| **Копіювати назву репозиторію** | Копіює канонічну назву теки, а не псевдонім. |
| **Копіювати шлях репозиторію** | Копіює абсолютний шлях. |
| **Відкрити на GitHub** | Origin, якщо це github.com, інакше — перший GitHub-ремоут, який вдалося розібрати. Недоступно, коли жодного вивести не можна. |
| **Відкрити в терміналі** | Відкриває термінал Gitcito з цим репозиторієм як робочим каталогом. |
| **Показати у Finder / Провіднику** | Підсвічує теку репозиторію у файловому менеджері платформи. |
| **Відкрити у зовнішньому редакторі** | Редактор, налаштований у Налаштуваннях. Видимий, але недоступний, доки жодного не задано. |
| **Прибрати…** | Закриває вкладку або прибирає чіп із групи. Використовує те саме попередження про незакомічену роботу, що й кнопка **×**. Файли з диска ніколи не видаляються. |

Відсутній чи недійсний шлях лишає копіювання, псевдонім і прибирання
доступними, а все, що відкривало б чи оглядало каталог, пригашує.
