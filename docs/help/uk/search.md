# Палітра команд і пошук

## Палітра — <kbd>⌘K</kbd>

Нечіткий стрибок до **гілки** (робить на неї чекаут), **коміту** (прокручує до
нього граф), **файлу робочого дерева** або **дії** — фетч, пул, пуш, стеш,
термінал, рефлог, налаштування і кожна можливість із цього довідника.

Вона вчиться: те, чим ви користувалися нещодавно, іде першим, а те, чим ви
користуєтеся часто, випереджає те, чим не користуєтеся.

![Палітра команд](../../screenshots/command-palette.webp)

## Пошук по коду — <kbd>⌘⇧F</kbd>

Два різні питання, один діалог:

| Режим | На яке питання відповідає |
|---|---|
| **Вміст** | «Де цей рядок просто зараз?» — `git grep` по відстежуваних *і* невідстежуваних файлах, з урахуванням регістру / цілим словом / регулярним виразом. |
| **Кайло по історії** | «Коли цей рядок з’явився або зник?» — `git log -S` / `-G`. |

Збіги повертаються з підсвіченим синтаксисом і позначеним місцем збігу,
згруповані за файлами й розгортаються до конкретних рядків. Клацніть по
одному, щоб відкрити файл на тому рядку — або коміт, який його вніс.

![Результати пошуку по коду](../../screenshots/code-search.webp)

## Фільтрування графа

Поле пошуку над графом фільтрує коміти за повідомленням, автором, SHA або
станом розгортання. Для «лише коміти, які торкалися цього файлу» скористайтеся
фільтром за шляхом — дивіться [граф комітів](graph.md).
