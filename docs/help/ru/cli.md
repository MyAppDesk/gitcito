# Командная строка

```sh
gitcito .                        # open this folder
gitcito ~/code/api               # …or that one
gitcito . -n "My API"            # with a display name
gitcito . -g "Work"              # inside a group tab
gitcito . -n "My API" -g "Work"  # both
```

## Установка шима

Палитра команд (<kbd>⌘K</kbd>) → **Установить команду 'gitcito' в PATH**
(macOS). Она делает символическую ссылку на небольшой шим в `/usr/local/bin` или
`/opt/homebrew/bin`, запрашивая права администратора, только если ни один из них
вам не доступен на запись. Запустите ту же команду ещё раз, чтобы удалить шим.

## Как это себя ведёт

- Если путь **уже открыт** — как вкладка или внутри группы — Gitcito
  **фокусируется на нём**, а не открывает дубликат.
- Если это ещё не Git-репозиторий, он всё равно откроется, предложив сценарий
  «инициализировать репозиторий здесь».
- `-g` добавляет репозиторий в группу с таким именем, создавая группу, если её
  ещё нет.
- Gitcito работает **в одном экземпляре**: запуск `gitcito` при открытом
  приложении передаёт запрос в то же окно, а не запускает вторую копию.
