# טרמינל משולב

PTY אמיתי (xterm + node-pty), לא מריץ פקודות. המעטפת שלכם, השורה שלכם, הכינויים
שלכם.

![הטרמינל המשולב](../../screenshots/terminal.webp)

- **כמה לשוניות לכל מאגר**, כל אחת מתחילה בתיקייה של אותו מאגר.
- עגנו אותו **מתחת** לגרף או כ**עמודה ימנית**; הפאנל זוכר את גודלו.
- נראות הטרמינל היא לכל מאגר בנפרד: מעבר ללשונית שמעולם לא פתחה אחד משאיר אותו
  סגור.
- לשוניות נותנות לעצמן שם לפי מה שרץ בהן.
- כיווץ רשימת הטרמינלים מקטין אותה ל**מסילה**: סמל אחד לכל טרמינל (טרמינלים
  מפוצלים מציגים מפת פאנלים מוקטנת), לחיצה כדי להחליף, לחיצה ימנית לתפריט הרגיל
  של שינוי שם/פיצול/הריגה.
- **גררו טרמינל אחד על אחר** ברשימה כדי למזג אותם לקבוצה מפוצלת. כל טרמינל
  שומר על שמו כחלונית; הקבוצה הממוזגת מקבלת שם ממוספר חדש.

![שני פאנלים מפוצלים זה לצד זה בקבוצת טרמינלים אחת](../../screenshots/terminal-split.webp)

## מקשים

| מקשים | פעולה |
|---|---|
| <kbd>⌃`</kbd> | הצגה או הסתרה של הטרמינל — מקש Control הפיזי, בכל פלטפורמה |
| <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> | טרמינל חדש, כשהמיקוד בטרמינל |
| <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> | סגירת הטרמינל הממוקד; סגירת האחרון מסתירה את הלוח |
| <kbd>Ctrl+Shift+C</kbd> | העתקת הבחירה; <kbd>Ctrl+C</kbd> לבדו מעתיק גם הוא כל עוד יש בחירה, ונשאר SIGINT כשאין |
| <kbd>Ctrl+V</kbd> / <kbd>Ctrl+Shift+V</kbd> / <kbd>Shift+Ins</kbd> | הדבקה מהלוח |
| לחיצה ימנית | מעתיקה את הבחירה, או מדביקה כשדבר לא נבחר |

שני הראשונים פועלים בכוונה רק בטרמינל: מחוצה לו הם עדיין פותחים וסוגרים
[לשוניות של סביבת עבודה](workspaces.md). ב-macOS, העתקה/הדבקה מתפריט «עריכה» פועלות
באותו אופן.

## הצעות סקריפטים

הקלידו `npm run ` (או `pnpm`, `yarn`, `bun run`) ותופיע ליד הסמן רשימת הסקריפטים של
הפרויקט, מסוננת תוך כדי הקלדה: `npm run loc` מוצא את `LOCAL_SERVER`. כל שם מציג את הפקודה
שהוא מריץ.

| מקש | פעולה |
|-----|-------|
| **Tab** | משלים את הסקריפט הנבחר |
| **↑ / ↓** | בחירת סקריפט אחר |
| **Esc** | סוגר את הרשימה עד שתקלידו שוב |

לפקודות אחרות יש רשימה משלהן:

| מוקלד | מציג | נקרא מ- |
|-----|----|-------|
| `composer run ` | סקריפטים של Composer | ה-`composer.json` הקרוב ביותר |
| `make ` | יעדי Makefile, עם `## טקסט` אחרי היעד כתיאור | ה-`Makefile` של התיקייה הנוכחית, כפי ש-`make` קורא אותו |
| `git checkout `, `switch`, `merge`, `rebase` | ענפים מקומיים, ואחריהם מרוחקים לפי השם הקצר | המאגר שבו נמצאת המעטפת |

יעד Makefile שבנוי ממשתנים או מתבנית (`%.o`) אינו מופיע, ו-
`git checkout -b` אינו מקבל רשימה: הוא נותן שם לענף חדש.

הסקריפטים מגיעים מה-`package.json` הקרוב ביותר לתיקייה **הנוכחית** של המעטפת, כך שאחרי
`cd frontend` תקבלו את אלה של ה-frontend. שמות שמתחילים במה שהקלדתם מופיעים קודם, ואחריהם
שמות שמכילים אותו.

הרשימה מכירה רק את המקשים שהוקלדו מאז ה-Enter האחרון. שליפת פקודה עם ↑, הזזת הסמן או
שימוש בהשלמת Tab של המעטפת עצמה משנים את השורה מחוץ לטווח הראייה שלה, ולכן היא שותקת עד
ה-Enter הבא במקום להשלים דבר שגוי. ב-Windows אי אפשר לקרוא את התיקייה הנוכחית, ולכן
הרשימה עוקבת אחרי התיקייה שבה נפתח הטרמינל.

## ה‑PATH שלכם

המעטפת עולה כ**מעטפת התחברות (login shell)**, בדיוק כמו ב‑Terminal.app או
ב‑iTerm, ולכן `~/.zprofile`, `~/.zlogin` ו‑`~/.bash_profile` נטענים. זה חשוב
מפני שמנהלי גרסאות ו‑`brew shellenv` מתקינים את עצמם בדיוק שם — כלי כמו `fvm`,
`nvm` או `pyenv` שעובד בטרמינל שלכם יעבוד גם כאן.

בנוסף, Gitcito שואל את מעטפת ההתחברות שלכם מהו ה‑`PATH` האמיתי שלה בעת העלייה
וממזג אותו לכל מה שהוא מריץ, כי אפליקציה גרפית שנפתחת מה‑Dock כמעט לא יורשת
כלום. אם פקודה עדיין לא נמצאת, בדקו שהיא ב‑`PATH` של מעטפת התחברות ולא רק של
מעטפת אינטראקטיבית.

כל מה שאתם מריצים כאן בלתי נראה לנעילה של Gitcito עצמו, ולכן `git rebase` ארוך
שהוקלד ביד ולחיצה בממשק עדיין יכולים להתנגש — האפליקציה מרעננת מהדיסק כשהטרמינל
משנה משהו.

## מעטפת, ערכת נושא ו-Oh My Posh

ב-Windows, הגדרות ← פריסה בוחרות את המעטפת שכל טרמינל חדש מפעיל — PowerShell,
PowerShell Core (`pwsh`), `cmd`, Git Bash, WSL או קובץ הרצה מותאם. מראה הטרמינל (ערכת
נושא, גודל גופן ומשפחת גופן) נמצא בהגדרות ← ערכות נושא ← ערכת נושא לטרמינל, וחל מיד על כל
ההפעלות.

אם [Oh My Posh](https://ohmyposh.dev) מותקן, האזור מציג גם כל `*.omp.json` תחת
`%POSH_THEMES_PATH%` עם תצוגה מקדימה חיה — בחירה באחד מעבירה אותו לטרמינלים חדשים
כ-`POSH_THEME`, כך ש-`oh-my-posh init pwsh` פשוט בפרופיל שלכם יאמץ אותו. גם נתיב
`.omp.json` מותאם עובד; השארת השדה על «ברירת מחדל» שומרת את מה שהמעטפת/הפרופיל או
`POSH_THEME` גלובלי כבר מגדירים. הפעלות פתוחות שומרות על ערכת הנושא שלהן — סגרו ופתחו
מחדש טרמינל כדי להחיל ערכה חדשה. גליפים של שורת הפקודה דורשים Nerd Font במשפחת הגופן של
הטרמינל (למשל `CaskaydiaMono Nerd Font`), אחרת הסמלים יוצגו כריבועים.

לגבי מהירות: Oh My Posh מריץ את התוכנה שלו פעם אחת לכל שורת פקודה — כ-100–200 מילישניות
ב-Windows, ויותר בערכות עם מקטע git במאגר גדול — וזה מורגש כהשהיה קצרה לפני כל שורת פקודה,
לא כאיטיות של Gitcito. ערכות בלי מקטע git הן המהירות ביותר. גם סגנון החיזוי של PowerShell
משפיע: `-PredictionViewStyle InlineView` מצייר מחדש אזור קטן בכל הקשה, ואילו `ListView`
מצייר מחדש בלוק שלם.
