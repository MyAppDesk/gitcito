# 타임랩스

저장소가 자라나는 모습을 보세요.

파일 하나하나가 점이고, 최상위 폴더에 따라 자리를 잡아요. 추가될 때 태어나고,
커밋이 건드릴 때마다 고동치고, 계속 수정되면 부풀어 오르고, 삭제되면 서서히
사라져요. 위쪽에는 날짜, 작성자, 제목과 함께 지금까지의 커밋·파일·작성자 수가
올라가고, 아래쪽에는 진행 막대가 있어요.

![재생 중인 타임랩스](../../screenshots/timelapse.webp)

![한 저장소의 일생 전체를 되감아 본 모습](../../screenshots/clip-timelapse.webp)

## 조작

- **재생 / 일시정지**, **4배에서 32배까지**의 속도, 그리고 처음부터 다시 시작.
- 슬라이더는 **처음부터 다시 재생하는** 방식으로 탐색해요. 그래서 뒤로 훑어도
  대충 비슷한 상태가 아니라 정확히 그 시점의 세계에 도착해요.

## 영상 내보내기

**영상 내보내기**는 캔버스를 처음부터 끝까지 녹화하고 `.webm`을 어디에 저장할지
물어봐요.

녹화는 페이지 안에서 이뤄져요(`MediaRecorder`). 설치할 인코더도, ffmpeg도 필요
없고, 어디로도 업로드되지 않아요. 저장 경로를 고르기 전까지는 디스크에 아무것도
쓰이지 않아요.

> 잘 정돈된 저장소보다 진짜 굴곡이 있는 저장소가 더 좋은 영화가 돼요. 이름 변경,
> 삭제, 그리고 갑자기 폭발하듯 커지는 폴더 같은 것들이 볼 만한 구석을 만들어요.
