# Запуск і налагодження

Gitcito читає ваш `.vscode/launch.json` — кореневий і будь-які вкладені,
згруповані з роздільниками — і запускає вибрану вами конфігурацію у вбудованому
терміналі.

![Вибір конфігурації запуску та плавальна панель інструментів](../../screenshots/launch-configs.webp)

- **Змінні VS Code розв’язуються** (`${workspaceFolder}` і компанія).
- **`preLaunchTask`** конфігурації виконується першим.
- Значення **`${input:…}`** запитуються інтерактивно перед запуском
  (`promptString` і `pickString`).
  `pickString` показує варіанти як справжній вибір із попередньо вибраним
  типовим значенням; `promptString` із позначкою `password` маскується.
- Завдання з **`isBackground`** (спостерігачі, dev-сервери) виконуються
  відокремлено, тож ніколи не блокують запуск.
- **Compounds** запускають кожного учасника як **окрему паралельну сесію** —
  в одному розділеному терміналі з іменем compound, по панелі на учасника,
  точно як debug-сесії VS Code. Із `stopAll: true` зупинка одного учасника
  зупиняє всіх.
  Завдання, спільні для кількох учасників, виконуються **один раз**, у власній
  панелі, до запуску учасників — запит підвищення версії питає один раз, а не
  по разу на учасника.
  Ця панель закривається сама в разі успіху й лишається відкритою при помилці.
- **`serverReadyAction`** враховується: коли вивід сесії збігається з заданим
  шаблоном, оголошений URL відкривається у браузері
  (`openExternally`; `debugWithChrome` / `debugWithEdge` теж відкривають
  браузер — Gitcito не може під'єднати до нього налагоджувач).

![Compound, що запустив дві паралельні сесії](../../screenshots/launch-compound.webp)

![Вибір ${input} із типовим значенням](../../screenshots/launch-input.webp)

Плавальна панель інструментів дає **паузу / продовження, перезапуск, зупинку** і
перемикає між запущеними сесіями.

Увімкніть це в **Налаштування → Загальні → Увімкнути launch.json**. Кнопка
**LAUNCH** з’явиться поруч із вкладками Git / Files.

Учасник compound відображається як *compound › учасник*, а його перезапуск
перезапускає лише цього учасника.
Якщо панель закриває щось потрібне, перетягніть її вбік за ручку — позиція
запам’ятовується, а подвійний клік по ручці повертає її в центр.

Чого Gitcito свідомо **не** робить: він запускає ваші програми у справжніх
терміналах, але це не налагоджувач — без точок зупину, без перегляду змінних,
без Debug Adapter Protocol. Конфігурації лише-attach працюють, коли несуть
`preLaunchTask` (завдання і є роботою); чистому attach нема чого запускати.
