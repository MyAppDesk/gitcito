# 명령 팔레트와 검색

## 팔레트 — <kbd>⌘K</kbd>

**브랜치**(체크아웃해요), **커밋**(그래프를 그리로 스크롤해요), **작업 트리
파일**, 또는 **동작**으로 퍼지 검색해서 건너뛰세요. 동작에는 페치, 풀, 푸시,
스태시, 터미널, reflog, 설정을 비롯해 이 핸드북에 나오는 모든 기능이 들어 있어요.

팔레트는 배워요. 최근에 쓴 것이 먼저 오고, 자주 쓰는 것이 그렇지 않은 것보다 위로
올라와요.

![명령 팔레트](../../screenshots/command-palette.webp)

## 코드 검색 — <kbd>⌘⇧F</kbd>

서로 다른 두 가지 질문을, 하나의 대화 상자에서요.

| 모드 | 답해 주는 질문 |
|---|---|
| **내용** | "이 문자열이 지금 어디에 있지?" — 추적되는 파일*과* 추적되지 않는 파일 모두에 대한 `git grep`. 대소문자 / 단어 전체 / 정규식 옵션이 있어요. |
| **히스토리 픽액스** | "이 문자열이 언제 나타났고 언제 사라졌지?" — `git log -S` / `-G`. |

결과는 구문 강조된 채로 돌아오고 일치 부분이 표시돼요. 파일별로 묶여 있고, 펼치면
정확한 줄이 나와요. 하나를 누르면 그 줄에서 파일이 열리거나, 그것을 만든 커밋이
열려요.

![코드 검색 결과](../../screenshots/code-search.webp)

파일을 건드린 커밋만" 보고 싶다면 경로 필터를 쓰세요 —
