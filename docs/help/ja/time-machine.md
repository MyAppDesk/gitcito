# タイムマシン

古いコミットを読むには、ふつうチェックアウトが要り、つまりやりかけの作業をスタッシュ
することになります。これは違います。

スライダーを動かすと **ファイルツリーがコミットごとに描き直されます**。フォルダが
現れ、ファイルがその間を移動し、削除されたファイルが戻ってきます。ファイルを選べば、
そのコミット時点の姿で読めます。

すべてはオブジェクトデータベースから読まれます（`git ls-tree`、`git show`）。
**チェックアウトはせず、HEAD は動かず、コミットしていない作業にも触れません** —
変更の途中で 1 年分の履歴をスクラブして回れます。

## 操作

| キー | 動作 |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | 1 コミット |
| <kbd>⇧</kbd> + <kbd>←</kbd> <kbd>→</kbd> | 10 コミット |
| <kbd>Home</kbd> / <kbd>End</kbd> | 最古 / 最新 |

スライダーの両側の矢印も同じ働きをします。そのコミットが触れたファイルはツリー内で
強調され、件数がヘッダーに出ます。

## 選択は時間を越えて残る

ファイルを選んだまま、それが作られる前まで巻き戻してみてください。ペインは「ここには
存在しません」と言い、そして **選択を保持します**。前へ進めればファイルは以前の中身
とともに戻ってきます。それがこの機能の要点です。動かしているのはリポジトリであって、
カーソルではありません。

**このバージョンを開く** で、そのコミット時点のファイルを通常のファイルビューに渡せ
ます。
