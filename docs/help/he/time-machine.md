# מכונת הזמן

קריאה של קומיט ישן דורשת בדרך כלל צ׳קאאוט, ומשמעות הדבר סטאש למה שעשיתם. כאן לא.

גררו את המחוון ו**עץ הקבצים מרונדר מחדש לכל קומיט**: תיקיות מופיעות, קבצים עוברים
ביניהן, קבצים שנמחקו חוזרים. בחרו קובץ ותקראו אותו כפי שהיה באותו קומיט.

הכול נקרא ממסד האובייקטים (`git ls-tree`, `git show`). **בלי צ׳קאאוט, HEAD לא זז
אף פעם, והעבודה שלא נכנסה לקומיט לא נוגעת** — אפשר לגרור דרך שנה של היסטוריה
באמצע שינוי.

![העץ כפי שעמד בקומיט מוקדם יותר, עם קובץ פתוח לצדו](../../screenshots/time-machine.webp)

![גרירת המחוון: העץ בונה את עצמו מחדש קומיט אחר קומיט](../../screenshots/clip-time-machine.webp)

## פקדים

| מקש | פעולה |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | קומיט אחד |
| <kbd>⇧</kbd> + <kbd>←</kbd> <kbd>→</kbd> | עשרה קומיטים |
| <kbd>Home</kbd> / <kbd>End</kbd> | הישן ביותר / החדש ביותר |

החצים משני צדי המחוון עושים את אותו דבר. קבצים שהקומיט הנוכחי נגע בהם מודגשים
בעץ, עם מונה בכותרת.

## הבחירה שורדת את הזמן

בחרו קובץ וגררו אחורה אל מעבר לקומיט שיצר אותו: הפאנל אומר שהוא לא קיים כאן,
ו**שומר על הבחירה שלכם**. גררו קדימה והקובץ חוזר עם התוכן הישן שלו. זו כל
הפואנטה — אתם מזיזים את המאגר, לא את הסמן שלכם.

**פתיחת הגרסה הזו** מוסרת את הקובץ לתצוגת הקבצים הרגילה באותו קומיט.
