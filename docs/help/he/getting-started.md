# תחילת העבודה

Gitcito פותח תיקייה ומראה לכם את ההיסטוריה שלה. שום דבר לא נכתב אל המאגר שלכם
עד שתבקשו זאת.

![מאגר שזה עתה נפתח, עדיין בלי קומיטים](../../screenshots/empty-repo.webp)

## פתיחת מאגר

- **גררו תיקייה** אל תוך החלון, או השתמשו ב**פתיחת מאגר** במסך הפתיחה.
- **שכפלו** מאגר מכתובת URL או ישירות מהשירות המארח שלכם — ראו
  [שכפול](cloning.md) לאפשרויות שהופכות מאגר ענק לשכפול מהיר.
- מתוך טרמינל, הפקודה `gitcito .` פותחת את התיקייה הנוכחית באפליקציה שכבר רצה —
  ראו [שורת הפקודה](cli.md).
- גם תיקייה שאיננה מאגר Git עדיין נפתחת, ומציעה לאתחל אותה.

## שלושת הפאנלים

| פאנל | מה יש בו |
|---|---|
| שמאל | ענפים, רימוטים, תגיות, סטאשים ועצי עבודה — ולשונית **קבצים** לעץ העבודה |
| מרכז | גרף הקומיטים, וכל מה שתבחרו מתוכו |
| ימין | מלחין הקומיטים, או הפרטים של הקומיט הנבחר |

## איך מוצאים את כל השאר

שני מסלולים, ושניהם מובילים לאותם מקומות:

- **`⌘K`** (`Ctrl+K`) — פלטת הפקודות. הקלידו מה שאתם רוצים; היא גם קופצת לענפים,
  לקומיטים ולקבצים.
- **כלים** בסרגל העליון — אותה מערכת בדיוק בהיקף המאגר, בתור תפריט, כשהזנב הארוך
  מקופל לקבוצות כדי שיישאר קריא.

![תפריט הכלים: הכלים השכיחים ראשונים, השאר מקובץ](../../screenshots/tools-menu.webp)

כל מה שאפשר להגיע אליו בדרך אחת אפשר להגיע אליו גם בשנייה, ולכן אין שום דבר
שרק משתמשים מנוסים מוצאים.

## הקומיט הראשון שלכם

1. ערכו קובץ. הוא יופיע תחת **לא בסטייג׳**.
2. העלו אותו לסטייג׳ — את הקובץ כולו, קטע בודד, או [שורות בודדות](staging.md).
3. כתבו הודעה ולחצו **קומיט**.

כל השאר ב־Gitcito הוא רשות.
