# スタッシュ

Gitcito のスタッシュは、全部か無かではありません。

| 操作 | 内容 |
|---|---|
| **スタッシュ** | すべて。望むなら未追跡ファイルも含め、メッセージ付きで |
| **部分スタッシュ** | 入れたいファイルだけにチェック。必要なら `--keep-index` も |
| **適用 / ポップ** | スタッシュまるごと、または**その一部のファイルだけ** |
| **スタッシュ → ブランチ** | `git stash branch` — スタッシュがきれいに適用できないときの逃げ道 |

スタッシュを選ぶと、コミットとまったく同じようにファイルと差分が表示されます。

ファイル一覧は[ステージング](staging.md)と同じ操作で複数選択できます —
<kbd>⌘</kbd>/<kbd>Ctrl</kbd>+クリック、<kbd>⇧</kbd>+クリック、<kbd>⇧</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd>。右クリック（または
*n 件のファイルを適用* ボタン）で選択分だけを復元します。

![部分スタッシュ: 入れるべきファイルだけにチェックを入れる](../../screenshots/stash-partial.webp)

## スタッシュが適用できないとき

スタッシュの適用が未追跡ファイルを上書きしてしまう場合、git は止まります。Gitcito は
呪文を自分で組み立てさせる代わりに、上書きして再試行することを提案します。

作業ツリーが離れすぎてしまった場合は、**スタッシュ → ブランチ** がそのスタッシュを
取ったときのブランチを作り直し、そこにきれいに適用して、スタッシュを破棄します。

## スナップショットとの混同に注意

[WIP スナップショット](recovery.md) は自動で、目に見えません。スタッシュは意図的で、
一覧に並びます。スナップショットがスタッシュ一覧に触れることはありません。
