# Теги и релизы

Создайте тег на любом коммите:

| Вид | Когда |
|---|---|
| **Легковесный** | Просто указатель. Годится для личной пометки |
| **Аннотированный** | Несёт сообщение, автора и дату — то, чем должен быть релиз |
| **Подписанный** | Аннотированный плюс подпись GPG/SSH |

![Создание тега: имя, необязательное сообщение и выбор, подписывать ли его](../../screenshots/create-tag.webp)

Удаляйте теги локально, пушьте их или удаляйте на удалённом репозитории. Теги на
удалённом репозитории можно просматривать, не вытягивая их все заранее.

На GitHub опубликованные **релизы** перечислены в боковой панели со страницей
changelog — см. [Хостинги](hosting.md). Чтобы набросать текст заметок,
используйте [генератор changelog](changelog.md).
