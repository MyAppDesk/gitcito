# LFS、スパースチェックアウト、パッチ

## Git LFS

![LFS の管理画面](../../screenshots/lfs.webp)

`git-lfs` が入っているか、このリポジトリがそれを使っているか、どのパターンが管理
されているかを検出します。ファイル一覧は、**ダウンロード済み**のものと、まだ
**ポインター**のままのものを区別して表示し、その場で取得や削除ができます。

## スパースチェックアウト

![コーンモードのスパースチェックアウト](../../screenshots/sparse-checkout.webp)

コーンモード。実際に作業しているトップレベルのフォルダーにチェックを入れると、
残りは履歴に残ったまま作業ツリーから消えます。2 つのパッケージだけを受け持って
いるモノレポで役に立ちます。

クローン時には**部分クローン**（`--filter=blob:none`）も選べるので、一度も開かない
blob をダウンロードせずに済みます。

## パッチ

- コミット（あるいは複数選択）を `.patch` として**書き出す**。
- 作業ツリーに（`git apply`）、またはコミットとして（`git am`）**適用する**。

どちらもツールメニューからです。
