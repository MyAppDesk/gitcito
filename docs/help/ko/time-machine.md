# 타임머신

오래된 커밋을 읽으려면 보통 체크아웃을 해야 하고, 그러려면 하던 일을 스태시해야
해요. 이 기능은 그렇지 않아요.

슬라이더를 끌면 **파일 트리가 커밋마다 다시 그려져요**. 폴더가 나타나고, 파일이
폴더 사이를 옮겨 다니고, 지워진 파일이 되살아나요. 파일을 하나 고르면 그 커밋
당시 모습 그대로 읽을 수 있어요.

모든 것은 객체 데이터베이스에서 읽어 와요(`git ls-tree`, `git show`). **체크아웃은
없고, HEAD는 움직이지 않으며, 커밋하지 않은 작업은 그대로예요** — 무언가를 고치는
도중에도 1년치 히스토리를 훑어볼 수 있어요.

![슬라이더를 훑으면 트리가 커밋마다 스스로 다시 만들어집니다](../../screenshots/clip-time-machine.webp)

## 조작

| 키 | 동작 |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | 한 커밋씩 |
| <kbd>⇧</kbd> + <kbd>←</kbd> <kbd>→</kbd> | 열 커밋씩 |
| <kbd>Home</kbd> / <kbd>End</kbd> | 가장 오래된 커밋 / 가장 최근 커밋 |

슬라이더 양쪽의 화살표도 같은 일을 해요. 현재 커밋이 건드린 파일은 트리에서
강조되고, 헤더에 그 개수가 표시돼요.

## 선택은 시간을 넘어 살아남아요

파일을 하나 고른 뒤 그 파일이 생기기 이전 커밋까지 거슬러 올라가 보세요. 창에는
여기에는 그 파일이 없다고 나오지만, **선택은 그대로 유지돼요**. 다시 앞으로
훑으면 그 파일이 옛 내용과 함께 돌아와요. 그게 핵심이에요 — 움직이는 것은 커서가
아니라 저장소니까요.

**이 버전 열기**를 누르면 해당 커밋의 파일이 평소의 파일 보기로 넘어가요.
