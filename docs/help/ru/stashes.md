# Стеши

Стеш в Gitcito — не по принципу «всё или ничего».

| Действие | Что делает |
|---|---|
| **Стеш** | Всё, при желании вместе с неотслеживаемыми файлами, с сообщением |
| **Частичный стеш** | Отметьте только нужные файлы; по желанию `--keep-index` |
| **Применить / Извлечь** | Весь стеш — или **только часть его файлов** |
| **Стеш → ветка** | `git stash branch` — запасной выход, когда стеш не применяется чисто |

Выбранный стеш показывает свои файлы и диффы — ровно как коммит.

Список файлов выделяется группами теми же жестами, что и при
[индексировании](staging.md) — клик с <kbd>⌘</kbd>/<kbd>Ctrl</kbd>, клик с
<kbd>⇧</kbd>, <kbd>⇧</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd> — а правый клик (или
кнопка *Применить n файлов*) восстанавливает только выделенное.

![Частичный стеш: отмечены только те файлы, которые должны в него попасть](../../screenshots/stash-partial.webp)

## Когда стеш не применяется

Если применение стеша затёрло бы неотслеживаемые файлы, git останавливается.
Gitcito предлагает перезаписать их и повторить попытку, вместо того чтобы
оставить вас выяснять нужное заклинание.

Если дерево ушло слишком далеко, **стеш → ветка** воссоздаёт ветку, с которой
стеш был снят, чисто применяет его там и удаляет стеш.

## Не путать со снимками

[WIP-снимки](recovery.md) автоматические и скрытые; стеши — осознанные и
перечислены списком. Снимки никогда не трогают ваш список стешей.
