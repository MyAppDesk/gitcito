# Інтерактивний ребейз

Список завдань `git rebase -i` як список, який можна перетягувати.

![Редактор інтерактивного ребейзу](../../screenshots/interactive-rebase.webp)

| Дія | Що означає |
|---|---|
| **pick** | Лишити як є |
| **reword** | Лишити зміну, відредагувати повідомлення |
| **squash** | Скласти в коміт вище, злігши обидва повідомлення |
| **fixup** | Скласти в коміт вище, повідомлення цього відкинути |
| **edit** | Зупинитися тут, щоб можна було доправити |
| **drop** | Викинути коміт |

Перетягуйте рядки, щоб змінити порядок. Редактор ніколи не відкривається в
терміналі — Gitcito пише список завдань за вас.

## Autosquash, один клік

- **Підправити проіндексовані зміни в цей коміт** створює `fixup!` за вас.
- **Autosquash звідси** складає кожен `fixup!` / `squash!` у його ціль.

Якщо у вас не одне виправлення після рев’ю, а ціла купа,
[поглинання](absorb.md) саме з’ясує, до якого коміту належить кожен ханк, — щоб
цього не робили ви.

> Ребейз переписує історію. Усе, що вже запушено, потребуватиме примусового
> пушу, а той, хто це рецензував, захоче побачити
> [що змінилося відтоді](range-diff.md).
