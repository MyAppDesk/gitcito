# チームメイトレーダー

あなたは `api.ts` を編集しています。あなたがまだ見ていないブランチで、他の誰かも
編集しています。それを知るいつもの方法は来週のマージコンフリクトですが、レーダー
の方法は今日の一覧です。

すべてはあなたの **最後のフェッチ** から計算されます — リモート追跡 ref と、メモ
リ内の `merge-tree`、それだけです。サーバーもなく、チームメイトのマシンで動くエー
ジェントもなく、どのみち行っていたフェッチ以上のネットワークもありません。

![チームメイトレーダー](../../screenshots/teammate-radar.webp)

## 行が教えてくれること

あなたの `HEAD` にないコミットを持つすべてのリモートブランチについて:

| 列 | 意味 |
|--------|---------|
| 誰が・いつ | そのブランチの最後のコミッターと、どれくらい前か |
| コミット / ファイル | どれだけが入ってくるか、そして何ファイルに触れるか |
| **重なり** | そのうちどのファイルが **いまあなたの作業ツリーで変更中か** — 赤いピル |
| リスク | そのブランチを `HEAD` にマージするとコンフリクトするか（[コンフリクトレーダー](conflict-radar.md) と同じエンジン） |

行はあなたとどれだけ衝突するかで並びます。重なりが最初、次に予測されるコンフリク
ト、そして新しさの順です。行を展開すると正確なファイル一覧が見えます。**比較** は
ブランチ比較の全体を開きます。

## いつ声を上げるか

フェッチのたび — 手動でも自動でも — レーダーは静かに掃引します。トーストを表示す
るのは、アップストリームのコミットがあなたの変更したファイルに触れていて、**かつ**
その集合が前回の掃引から実際に変わったときだけです。変更中のファイルがなければ、
ノイズもありません。きれいな作業ツリーは何とも衝突できないからです。

## 制限

- 見えるのは最後のフェッチが見たものだけです。プッシュしていないチームメイトは見
  えません — これは ref を読むのであって、心を読むのではありません。
- 重なりはパス単位で、行単位ではありません。同じファイルに触れているのは注意喚起
  であって、コンフリクトの証明ではありません。**リスク** 列が行単位の答えですが、
  コミット済みの状態どうしに限られます。
- 45 日ほど動きのないブランチはスキップされ、最近動いた 30 本だけがスキャンされま
  す。
