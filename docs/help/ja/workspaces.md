# ワークスペース、タブ、グループ

ゆるいものから順に、3 つの階層があります。

## タブ

1 リポジトリにつき 1 タブです。<kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> で新規タブの
ピッカーが開き、<kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> でアクティブなタブを閉じます。
ドラッグして並べ替えたり、中クリックで閉じたり、<kbd>⌘⇧T</kbd> で最後に閉じたタブを
復元したりもできます。最後の 1 枚を閉じると、<kbd>⌘W</kbd> はウィンドウのほうを
閉じます。タブに付く点はコミットしていない作業があるしるしで、別の色の点は
コンフリクトを意味します。

閉じるときの警告が出た場合、<kbd>Escape</kbd> は必ずキャンセルします。<kbd>Enter</kbd>
で確定できるのはタブがきれいなときだけです。コミットしていない変更やコンフリクトが
あるときは、あえてボタンに手を伸ばさせます。<kbd>⌘W</kbd> のあとの余計なキー入力で、
まだ抱えていた作業が消えないようにするためです。

## グループ

関連するリポジトリを、名前と色のついた **グループタブ** にまとめられます。グループの
中ではリポジトリごとのチップが並ぶ 2 段目の列が現れ、グループ自体で **すべて
フェッチ** や **すべてプル** を一度に実行できます。

![複数のリポジトリを含むグループタブ](../../screenshots/repo-groups.webp)

グループは **何段でも入れ子にできるフォルダ** を持てます。グループを右クリック →
*新しいフォルダ…* を選び、リポジトリをフォルダのチップにドラッグします。フォルダは
それぞれ色を持ち、件数付きのチップに折りたためて、中にあるものすべての状態の点を
集約し、その配下をまとめてフェッチやプルできます。

![グループのタブ列に並ぶフォルダ。それぞれ件数付きのチップで、Internal が Services の中に入れ子になっている](../../screenshots/nested-folders.webp)

> フォルダは整理するだけのものです。削除してもその中のリポジトリは親に繰り上がる
> だけで、リポジトリが閉じられることはありません。

## ワークスペース

ワークスペースとは **タブ列まるごとを保存したもの** です。切り替えるとすべてのタブが
一度に入れ替わり、`Work` と `Personal` が互いの邪魔をしなくなります。

ワークスペース名は左上、Gitcito のマークの隣にあります。クリックすると切り替え、
作成、名前変更、並べ替え、削除ができます。その隣にあるゲージが、いま開いている
ワークスペースの [ミッションコントロール](mission-control.md) を開きます。
