# Tags & releases

Maak een tag vanaf elke commit:

| Soort | Wanneer |
|---|---|
| **Lichtgewicht** | Een pointer. Prima voor een persoonlijke markering |
| **Geannoteerd** | Draagt een boodschap, een auteur en een datum — wat een release hoort te zijn |
| **Ondertekend** | Geannoteerd, plus een GPG/SSH-handtekening |

![Een tag maken: naam, optionele boodschap, en of hij ondertekend wordt](../../screenshots/create-tag.webp)

Verwijder tags lokaal, push ze, of verwijder ze op de remote. Remote tags zijn te
doorbladeren zonder ze eerst allemaal op te halen.

Op GitHub staan gepubliceerde **releases** in de zijbalk met een
changelogpagina — zie [Hosting](hosting.md). Voor het opstellen van de notities
gebruik je de [changeloggenerator](changelog.md).
