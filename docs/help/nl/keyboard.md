# Toetsenbord & sneltoetsen

Druk overal op <kbd>?</kbd> voor het spiekbriefje.

![Het spiekbriefje met sneltoetsen](../../screenshots/cheatsheet.webp)

## De moeite van het leren waard

| Toetsen | Doet |
|---|---|
| <kbd>⌘K</kbd> | [Commandopalet](search.md) — branches, commits, bestanden, acties |
| <kbd>⌘⇧F</kbd> | [Code zoeken](search.md) door de werkboom |
| <kbd>⌘⇧V</kbd> | [Kluis](vault.md) |
| <kbd>⌘O</kbd> / <kbd>Ctrl+O</kbd> | Een repository openen |
| <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd> | Instellingen openen |
| <kbd>⌘F</kbd> | Zoeken binnen het bestand of de diff die je leest |
| <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> | De repository- of groepskiezer voor een nieuw tabblad openen |
| <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> | Het actieve tabblad sluiten — of het venster, zodra er geen tabblad over is |
| <kbd>⌘1</kbd>–<kbd>⌘9</kbd> / <kbd>Ctrl+1</kbd>–<kbd>Ctrl+9</kbd> | Naar een tabblad op zijn positie springen |
| <kbd>⌘⇧T</kbd> | Het laatst gesloten tabblad heropenen |
| <kbd>?</kbd> | Dit spiekbriefje |

## Rondbewegen zonder muis

| Waar | Toetsen |
|---|---|
| Commitgrafiek | <kbd>↑</kbd> <kbd>↓</kbd> of <kbd>j</kbd> <kbd>k</kbd> |
| Bestandslijsten (commit, WIP, stash) | dezelfde |
| [Tijdmachine](time-machine.md) | <kbd>←</kbd> <kbd>→</kbd>, <kbd>⇧</kbd> voor tien, <kbd>Home</kbd>/<kbd>End</kbd> |
| [Mission control](mission-control.md) | <kbd>↑</kbd><kbd>↓</kbd>, <kbd>Enter</kbd> om te openen, <kbd>f</kbd>/<kbd>p</kbd> om te fetchen/pullen, <kbd>/</kbd> om te filteren |
| Commitboodschapveld | <kbd>↑</kbd> <kbd>↓</kbd> haalt je recente boodschappen terug |

## Opnieuw toewijzen

**Instellingen → Sneltoetsen**. De kernsneltoetsen voor navigatie (palet, code
zoeken, kluis, repository openen, instellingen) zijn opnieuw toe te wijzen, met
conflictdetectie en een reset per sneltoets.

De vaste sneltoetsen hierboven zijn niet opnieuw toe te wijzen, en ze worden ook
als _doel_ geweigerd: de app beantwoordt <kbd>⌘T</kbd>, <kbd>⌘W</kbd>,
<kbd>⌘1</kbd>–<kbd>⌘9</kbd>, <kbd>⌘⇧T</kbd>, <kbd>⌘S</kbd>, <kbd>⌘Z</kbd>,
<kbd>⌘⇧Z</kbd> en <kbd>⌘F</kbd> voordat hij je toewijzingen raadpleegt, dus een
sneltoets die aan een van deze is toegekend zou ingesteld lijken en nooit
afgaan. Kies er een en de editor zegt dat in plaats van hem te aanvaarden.
