# Подписанные коммиты

Включайте подпись для каждого репозитория отдельно (**Настройки → шестерёнка
репозитория**): GPG, SSH или X.509, с выбранным вами ключом. Gitcito пишет для
этого репозитория `commit.gpgsign`, `gpg.format` и `user.signingkey` — ту же
самую конфигурацию, которую читает любой другой инструмент.

| | |
|---|---|
| ![Колонка подписи, светлая тема](../../screenshots/signed-commits-light.webp) | ![Колонка подписи, тёмная тема](../../screenshots/signed-commits-dark.webp) |

В графе появляется отдельная **колонка подписи**, которую можно переставлять:

| Бейдж | Что означает |
|---|---|
| **Проверено** | Хорошая подпись ключом, которому git доверяет |
| **Не проверено** | Подписано, но ключ неизвестен или не подтверждён |
| **Просрочено** | Подпись или её ключ истекли |
| *(ничего)* | Без подписи |

Теги тоже можно подписывать — см. [Теги](tags.md).
