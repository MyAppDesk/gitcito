# Машина часу

Прочитати старий коміт зазвичай означає зробити чекаут, а це означає застешити
те, чим ви були зайняті. Тут — ні.

Тягніть повзунок, і **дерево файлів перемальовується для кожного коміту**: теки
з’являються, файли переїжджають між ними, видалені файли повертаються. Виберіть
файл — і читаєте його таким, яким він був на тому коміті.

Усе читається з бази об’єктів (`git ls-tree`, `git show`). **Жодного чекауту,
HEAD не рухається, ваша незакомічена робота недоторкана** — ви можете прокрутити
рік історії посеред роботи над змінами.

## Керування

| Клавіша | Дія |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | Один коміт |
| <kbd>⇧</kbd> + <kbd>←</kbd> <kbd>→</kbd> | Десять комітів |
| <kbd>Home</kbd> / <kbd>End</kbd> | Найстаріший / найновіший |

Стрілки обабіч повзунка роблять те саме. Файли, яких торкнувся поточний коміт,
підсвічені в дереві, а їх кількість показана в заголовку.

## Вибір переживає час

Виберіть файл і прокрутіть назад за коміт, який його створив: панель скаже, що
тут його не існує, і **збереже ваш вибір**. Прокрутіть уперед — і файл
повернеться зі своїм старим вмістом. У цьому й суть — ви рухаєте репозиторій, а
не свій курсор.

**Відкрити цю версію** передає файл у звичайний перегляд файлу на тому коміті.
