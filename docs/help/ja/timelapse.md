# タイムラプス

リポジトリが育っていく様子を眺めます。

ファイルはすべて点で、最上位のフォルダごとに配置されます。追加されたときに生まれ、
コミットが触れると脈打ち、何度も編集されるほど膨らみ、削除されると消えていきます。
上には日付、作者、件名、そしてコミット・ファイル・作者の累計が表示され、下には進捗
バーが伸びます。

![再生中のタイムラプス](../../screenshots/timelapse.webp)

![リポジトリの一生を再生する](../../screenshots/clip-timelapse.webp)

## 操作

- **再生 / 一時停止**、速度は **4× から 32×** まで、そして最初から。
- スライダーは **最初から再生し直す** ことで目的の位置へ移動します。だから巻き戻すと、
  近似ではなく正確にその時点の世界に着きます。

## 動画の書き出し

**動画を書き出す** はキャンバスを最初から最後まで録画し、`.webm` の保存先を尋ねます。

録画はページ自身の中で行われます（`MediaRecorder`）。インストールすべきエンコーダも
ffmpeg も要らず、どこにもアップロードされません。保存先を選ぶまで、ディスクには何も
書き込まれません。

> 整ったリポジトリより、ちゃんと形のあるリポジトリのほうが良い映像になります。名前の
> 変更、削除、そして突然膨れ上がるフォルダ — 見る価値を生むのはそういうものです。
