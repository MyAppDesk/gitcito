# נגישות

Gitcito שואף להיות ניתן לתפעול בלי עכבר וקריא לקורא מסך. העמוד הזה אומר מה זה
אומר בפועל — ואיפה עוברים הגבולות.

## מקלדת

- **לשוניות, שורות סרגל הצד, רשימות קבצים ותפריטי סרגל הכלים** ניתנים לפוקוס
  ומופעלים ב־Enter או ב־Space. כפתורים מפוצלים (pull/push/stash) חושפים את חץ
  התפריט הנפתח כפקד נפרד שניתן לפוקוס.
- **גרף הקומיטים** הוא תחנת פוקוס אחת: תנו לו פוקוס והשתמשו בחצים
  למעלה/למטה (או j/k) כדי לצעוד בהיסטוריה. הקומיט הנבחר מוכרז עם הנושא,
  המחבר והמיקום שלו. Shift+F10 (או מקש התפריט) פותח את תפריט ההקשר של
  הקומיט הנבחר.
- **תפריטי הקשר** נפתחים עם פוקוס: החצים מזיזים, Enter מפעיל,
  ArrowRight/ArrowLeft נכנסים לתפריטי משנה ויוצאים מהם, Escape סוגר.
- **דיאלוגים** כולאים את Tab בתוכם, מחזירים את הפוקוס למקום שבו הייתם כשהם
  נסגרים, ונסגרים ב־Escape.
- **לוח הפקודות** (Cmd/Ctrl+K) הוא combobox: התוצאות מוכרזות תוך כדי הקלדה
  ותוך כדי מעבר עליהן בחצים.

## קוראי מסך

- כל דיאלוג מוכרז עם הכותרת שלו. טוסטים — ערוץ המשוב של האפליקציה — הם
  אזורים חיים: הצלחות מוכרזות בנימוס, שגיאות קוטעות.
- התקדמות (שכפול, הורדת עדכון) נחשפת כסרגל התקדמות עם אחוזים, ומצבי עבודה
  ("מביא…") מכריזים על עצמם.
- מצב הקובץ נאמר בקול ("נוסף", "שונה", "בקונפליקט"), ולא רק מוצג כסמל צבעוני.
- החלון בנוי עם ציוני דרך (landmarks) — banner, main, סרגל צד ושורת מצב —
  כך שניווט לפי ציוני דרך עובד.

## הגבולות, בפשטות

- **הטרמינל** הוא xterm.js ויורש ממנו את סיפור קורא המסך שלו, שהוא חלש.
  התייחסו אליו כמשטח למשתמשים רואים; כל פעולת git שהוא מציע קיימת גם כפעולה
  בממשק.
- **Cosmos (היסטוריה בתלת־ממד), מסלולי גרף הקומיטים ודיפים של תמונות** הם
  ויזואליים מטבעם. הנתונים שמאחוריהם — רשימת הקומיטים, רשימות הקבצים —
  נגישים; התמונה עצמה לא.
- **גרירה ושחרור** (סידור מחדש של שלבי ריבייס אינטראקטיבי, גרירת ענפים
  למיזוג) היא לסמן בלבד היכן שצוין; לכל פעולת גרירה יש מקבילה בתפריט או
  בכפתור.
- הבדיקה שמאחורי העמוד הזה נעשתה עם VoiceOver ב־macOS. NVDA/JAWS ב־Windows
  אמורים להתנהג באופן שקול אך לא נוסו בשטח — דיווחים יתקבלו בברכה בתור
  [issues](https://github.com/MyAppDesk/gitcito/issues).

## הגדרות קשורות

**הפחתת תנועה** מכובדת מהגדרת מערכת ההפעלה — אנימציות קורסות למעברים
מיידיים. את ניגודיות ערכת הנושא אפשר לכוונן לכל ערכה בנפרד
ב[הגדרות ← מראה](themes.md).
