# 안전한 공유

새 기기를 준비한다는 건 보통 모든 걸 처음부터 다시 입력한다는 뜻이에요. 안전한
공유는 그 대신 그것들을 암호화된 번들 하나로 묶어 줘요.

![저장소 하나의 설정을 암호화된 번들로 내보내기](../../screenshots/secure-share.webp)

![작업 공간 전체를 같은 방식으로 내보내기](../../screenshots/secure-workspace.webp)

## 담을 수 있는 것

| 섹션 | 내용 |
|---|---|
| **설정** | 테마, 레이아웃, 단축키, 환경 설정 |
| **금고** | 전역 비밀과 저장소별 비밀 |
| **저장소** | 작업 공간의 저장소들 — 가져올 때 원격이나 폴더로 대조돼요 |

비밀은 **체크 상자를 켰을 때만** 들어가요. 그 체크가 없는 번들에는 자격 증명이
하나도 들어 있지 않아요.

## 가져오기

가져오기 화면은 무엇이든 적용하기 **전에** 안에 무엇이 들었는지 섹션별로
보여주고, 저장소는 이미 가지고 있는 것과 대조돼요 — 먼저 원격 URL로, 그다음
폴더로 — 그래서 가져오기가 세상을 다시 클론하는 일은 없어요.
