# Analyses

Un tableau de bord construit à partir de votre historique Git — aucun service,
aucun compte, juste `git log` lu localement. Ouvrez-le depuis la roue dentée des
réglages du dépôt, à côté des outils de la barre d'outils.

![Le tableau de bord d'analyses](../../screenshots/insights.webp)

| Panneau | Ce qu'il vous dit |
|---|---|
| **Cartes de synthèse** | Commits par jour, contributeurs, fichiers touchés, lignes modifiées |
| **Agitation hebdomadaire** | Ajouts contre suppressions, semaine par semaine |
| **Principaux contributeurs** | Par commits et par lignes |
| **Points chauds de fichiers** | Les fichiers les plus modifiés — cliquez-en un pour sauter dans son historique |

Filtrez l'ensemble par **30 jours / 90 jours / 1 an / depuis toujours**.

Les points chauds sont le panneau intéressant : un fichier en tête de cette
liste, semaine après semaine, vous dit généralement quelque chose sur la
conception plutôt que sur les gens qui l'éditent.

Pour le même historique en images animées, voir le
[timelapse](timelapse.md).
