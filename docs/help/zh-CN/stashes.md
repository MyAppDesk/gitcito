# 贮藏

Gitcito 里的贮藏（stash）不是要么全上、要么全不上。

| 动作 | 它做什么 |
|---|---|
| **贮藏** | 全部内容，愿意的话连未跟踪文件一起，还可以带一条说明 |
| **部分贮藏** | 只勾选你想放进去的文件；可选加上 `--keep-index` |
| **应用 / 弹出** | 整个贮藏，或者**只取其中一部分文件** |
| **贮藏 → 分支** | `git stash branch`——当一个贮藏没法干净地应用时的逃生门 |

选中一个贮藏，就能看到它的文件和差异，和看一个提交一模一样。

![部分贮藏：只勾选该进去的那些文件](../../screenshots/stash-partial.webp)

## 当一个贮藏应用不上

如果应用某个贮藏会覆盖掉未跟踪的文件，git 会停手。Gitcito 会提出替你覆盖它们并重试，而不是把你丢在那儿自己去琢磨那句咒语。

如果工作区已经跑得太远，**贮藏 → 分支**会把这个贮藏当初所在的那个分支重建出来，在那里干净地应用它，然后丢掉这个贮藏。

## 别和快照弄混

[WIP 快照](recovery.md)是自动且隐藏的；贮藏是刻意为之且列在明面上的。快照从不碰你的贮藏列表。
