# שכפול

**מאגר חדש ← שכפול**, או `⌘K` ← *שכפול*. הדביקו כתובת URL, או התחברו אל GitHub,
GitLab, Bitbucket או Azure DevOps ובחרו מתוך המאגרים שלכם — הטוקן של
[הפרופיל](profiles.md) הנבחר משמש לשכפול ואז נזרק, ולעולם אינו נכתב אל
`.git/config`.

בחרו תיקיית אב ושם; השורה מתחת לשדות מראה בדיוק היכן המאגר ינחת. תיקייה שכבר
קיימת נדחית במקום להתמזג לתוכה.

## מתקדם — צמצום השכפול

כל מה שתחת **מתקדם** כבוי כברירת מחדל: אל תיגעו בו ותקבלו שכפול רגיל ומלא. הוא
מצדיק את מקומו במאגרים שבהם ״מלא״ פירושו עשרים דקות וכמה ג׳יגה־בייטים.

![חלון השכפול כשמתקדם פתוח: חלקי, רדוד, ענף בודד, תת־מודולים ובורר ענפים](../../screenshots/clone-advanced.webp)

| אפשרות | מה git עושה | מה זה עולה |
|--------|---------------|---------------|
| **שכפול חלקי** | `--filter=blob:none` | היסטוריה מלאה, בלי תוכן הקבצים. הבלובים מגיעים לפי דרישה, ולכן פתיחת קובץ ישן דורשת רשת. |
| **שכפול רדוד** | `--depth=N` | רק N הקומיטים האחרונים קיימים. blame, log, bisect ו־range-diff נעצרים בחתך. |
| **רק ענף אחד** | `--single-branch` | שאר הענפים נשארים ברימוט עד שתביאו אותם. |
| **שכפול תת־מודולים** | `--recurse-submodules` | גם כל תת־מודול עובר צ׳קאאוט — יותר זמן עכשיו, בלי תיקיות חסרות אחר כך. |
| **הענף לצ׳קאאוט** | `--branch <name>` | מתחיל על הענף הזה במקום על ברירת המחדל של הרימוט. |

**חלקי לפני רדוד.** שכפול חלקי שומר כל קומיט — ההיסטוריה נשארת ניתנת לחיפוש, ורק
תוכן הקבצים מובא בעצלתיים. שכפול רדוד באמת זורק היסטוריה: `git log` נגמר בחתך
ו־blame לא רואה מעבר לו. אם אתם משכפלים מונורפו כדי לעבוד בו, חלקי הוא בדרך כלל
מה שאתם רוצים.

רדוד ניתן לביטול: הפקודה `git fetch --unshallow` ב[טרמינל](terminal.md) ממלאת
את ההיסטוריה בחזרה.

### בחירת הענף

הקלידו שם ענף, או לחצו **רשימת ענפים** כדי לשאול את הרימוט מה יש לו
(`git ls-remote --heads`) ולבחור מרשימה נפתחת. זו נסיעת רשת אחת, שנעשית רק
כשלוחצים על הכפתור — שום דבר לא נשאל בזמן ההקלדה.

אם הרישום נכשל — כתובת פרטית בלי טוקן עדיין, שגיאת הקלדה, אין רשת — השדה נשאר
תיבת טקסט רגילה, והשכפול עצמו מדווח על השגיאה האמיתית.

### שתי הערות על הדגלים

- **`--depth` גורר `--single-branch`.** בשכפול רדוד, השארת *רק ענף אחד* לא
  מסומנת היא מה שמבקש את שאר הענפים בחזרה (`--no-single-branch`), ולכן הרמז
  שמתחתיה משתנה.
- **שכפול תיקייה מקומית** מתעלם בדרך כלל מ־`--depth` לגמרי, כי git יוצר קישורים
  קשיחים למחסן האובייקטים במקום להביא אותו. Gitcito משכפל דרך כתובת `file://`
  כשאתם מבקשים עותק רדוד של מאגר מקומי, כך שהעומק שביקשתם הוא העומק שתקבלו.

## התקדמות

הסרגל מדווח את מה ש־git מדווח: ספירה, דחיסה, קבלה, פענוח, צ׳קאאוט. שלב שאינו
יכול לדווח על סך הכול מציג סרגל בלתי מוגדר במקום אחוז מזויף.

המאגר החדש נפתח בלשונית, מוצמד לפרופיל שאיתו שכפלתם.
