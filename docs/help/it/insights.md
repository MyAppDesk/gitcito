# Insight

Un cruscotto costruito a partire dalla tua storia Git — nessun servizio, nessun
account, solo `git log` letto in locale. Lo apri dall'ingranaggio delle
impostazioni del repository, accanto agli strumenti nella barra.

![Il cruscotto degli insight](../../screenshots/insights.webp)

| Pannello | Cosa ti dice |
|---|---|
| **Schede di riepilogo** | Commit al giorno, contributori, file toccati, righe cambiate |
| **Churn settimanale** | Aggiunte contro rimozioni, settimana per settimana |
| **Migliori contributori** | Per commit e per righe |
| **Punti caldi nei file** | I file cambiati più spesso — cliccane uno per saltare nella sua storia |

Filtra tutto quanto per **30 giorni / 90 giorni / 1 anno / sempre**.

I punti caldi sono il pannello interessante: un file in cima a quell'elenco,
settimana dopo settimana, di solito ti sta dicendo qualcosa sul progetto del
software più che sulle persone che lo modificano.

Per la stessa storia sotto forma di immagine in movimento, vedi
[timelapse](timelapse.md).
