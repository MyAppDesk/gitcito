# ミッションコントロール

リポジトリが 20 個あっても、疑問はいつも同じです。どれが自分を必要としているのか。

ミッションコントロールはそれに答えます。**アクティブなワークスペース** のすべての
リポジトリを 1 画面に並べ、本当に手を入れるべき順に並べます。

1. **停止中** — リベースやマージが途中で止まっている、コンフリクトしている、
   そもそも読めないリポジトリ。
2. **同期が必要** — まずプルすべきコミット、次にプッシュすべきコミット。
3. **作業中** — 未コミットの変更、追跡されていないファイル。
4. **きれい** — 静かなものたちは、いちばん下、いるべき場所へ。

![すべてのリポジトリを 1 画面に、ひどいものから順に](../../screenshots/mission-control.webp)

## 1 行が教えてくれること

ブランチとその上流 · ↑進んでいる数 / ↓遅れている数 · 未コミットと未追跡の件数 ·
スタッシュ · 未クローズの PR（そのリポジトリが読み込み済みのとき） ·
**14 日分のコミットのスパークライン** · 最後のコミットからの経過時間。

行を展開すると（シェブロン、または <kbd>space</kbd>）、プッシュ待ちのコミットが
どれで、どのファイルが汚れているかまで正確に見えます。

## 一覧をさばく

- 上部の状態ピルは **フィルタ** です。「停止中 3」をクリックすればそれだけが残ります。
- **緊急度**、**名前**、**活動** で並べ替えられます。
- **複数のリポジトリにチェック** を入れてまとめてフェッチしたり、遅れているものだけを
  プルしたりできます（ボタンが対象の数を数えてくれます）。
- 開いている間は 30 秒ごとに自分で更新します。

| キー | 動作 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> または <kbd>j</kbd> <kbd>k</kbd> | 一覧を移動 |
| <kbd>Enter</kbd> | そのリポジトリを開く |
| <kbd>f</kbd> / <kbd>p</kbd> | フェッチ / プル |
| <kbd>space</kbd> | 展開する |
| <kbd>/</kbd> | フィルタへ移動 |

## これはタブではなく、ビューです

ワークスペース名の隣のゲージで開閉し、どれかのタブをクリックすれば作業に戻ります。
自分でタブを増やすことはなく、いま開いているワークスペースに属します。ワークスペースを
切り替えれば、そのワークスペースのダッシュボードになります。

読み取りは **完全にローカル** です。リポジトリごとに `git status` を 1 回走らせる
だけで、ネットワークもトークンも使いません。ダッシュボードを開いてどこかに認証しに
いくことはありません。フェッチは常に、あなたが頼んだから起きます。
