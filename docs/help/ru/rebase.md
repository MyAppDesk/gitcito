# Интерактивный ребейз

Todo-список `git rebase -i` в виде списка, который можно перетаскивать.

![Редактор интерактивного ребейза](../../screenshots/interactive-rebase.webp)

| Действие | Что означает |
|---|---|
| **pick** | Оставить как есть |
| **reword** | Оставить изменение, отредактировать сообщение |
| **squash** | Влить в коммит выше, объединив оба сообщения |
| **fixup** | Влить в коммит выше, сообщение этого выбросить |
| **edit** | Остановиться здесь, чтобы можно было поправить коммит |
| **drop** | Выбросить коммит |

Перетаскивайте строки, чтобы менять порядок. Редактор никогда не открывается в
терминале — todo за вас пишет Gitcito.

## Autosquash в один клик

- **Подшить проиндексированные изменения в этот коммит** создаёт `fixup!` за вас.
- **Autosquash отсюда** вливает каждый `fixup!` / `squash!` в его цель.

Если у вас не одна правка после ревью, а целая куча, [поглощение](absorb.md)
само разберётся, какому коммиту принадлежит каждый ханк, — чтобы этого не делали
вы.

> Ребейз переписывает историю. Всё, что уже запушено, потребует форс-пуша, а
> тому, кто это ревьюил, понадобится [что изменилось с тех пор](range-diff.md).
