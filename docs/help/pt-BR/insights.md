# Insights

Um painel construído a partir do seu histórico do Git — sem serviço, sem conta,
apenas o `git log` lido localmente. Abra pela engrenagem de configurações do repo,
ao lado das ferramentas na barra.

![O painel de insights](../../screenshots/insights.webp)

| Painel | O que ele te conta |
|---|---|
| **Cartões de resumo** | Commits por dia, contribuidores, arquivos tocados, linhas alteradas |
| **Churn semanal** | Adições contra remoções, semana a semana |
| **Principais contribuidores** | Por commits e por linhas |
| **Hotspots de arquivo** | Os arquivos mais alterados — clique num para pular para o histórico dele |

Filtre tudo por **30 dias / 90 dias / 1 ano / desde sempre**.

Os hotspots são o painel interessante: um arquivo no topo daquela lista, semana
após semana, geralmente está te dizendo algo sobre o design, e não sobre as pessoas
que o editam.

Para o mesmo histórico em forma de filme, veja [timelapse](timelapse.md).
