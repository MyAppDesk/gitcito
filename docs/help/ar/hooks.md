# خطافات git وملف .gitignore

## الخطافات

اسرد كل خطاف في المستودع، وانظر أيّها حقيقي وأيّها ما زال `.sample`، وفعِّلها أو
عطّلها أو حرّرها أو أنشئ خطافًا جديدًا.

![مدير الخطافات](../../screenshots/hooks.webp)

يكتشف Gitcito أي **`core.hooksPath`** مخصص (husky وأشباهه) وإعدادات **إطار
pre-commit**، ويخبرك حين تكون الخطافات في مكان غير `.git/hooks` — وإلا لحرّرت
ملفًا لا يشغّله git أبدًا.

> تعمل الخطافات مع التزامات Gitcito تمامًا كما تعمل مع `git commit`. الخطاف الذي
> يفشل يمنع الالتزام، ويعود خرجه إليك ضمن رسالة الخطأ.

## ملف .gitignore ذكي

انقر بالزر الأيمن على ملف ← **تجاهل**، ثم اختر:

| الخيار | ما يُكتب |
|---|---|
| هذا الملف | `path/to/file.log` |
| كل `*.ext` | `*.log` |
| المجلد بأكمله | `path/to/folder/` |

![منتقي ملف .gitignore](../../screenshots/gitignore-chooser.webp)

تذهب القاعدة إلى ملف `.gitignore` في **أقرب مجلد**، أو إلى جذر المستودع، مع
معاينة حيّة للسطر قبل أن تلتزم به. أما الملفات المتتبَّعة أصلًا فتحصل على
**تجاهل وإلغاء التتبع** في المربع نفسه.
