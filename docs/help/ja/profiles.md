# プロファイル

プロファイルは **Git のアイデンティティ**（名前とメールアドレス）と、その
**連携トークン** を 1 つに束ねたものです。プロファイルを切り替えれば両方が同時に
変わるので、コミットの作者が正しくなり、API 呼び出しも正しいアカウントを使います。

同じマシンで仕事用と個人用のリポジトリを扱うとき、あるいは GitHub のアカウントを
2 つ持っているときに便利です。

![プロファイル。片側に git のアイデンティティ、もう片側にその連携トークン](../../screenshots/settings-profiles.webp)

## リポジトリごとの紐付け

リポジトリは **プロファイルに紐付ける** ことができます。そうすると、そのリポジトリ
のバックグラウンドフェッチは常に正しいアカウントで認証されます — あなたがもう一方の
アカウントに属するリポジトリを眺めている最中でも同じです。

トークンは [OS のキーチェーン](security.md) に置かれ、設定ファイルには決して入り
ません。
