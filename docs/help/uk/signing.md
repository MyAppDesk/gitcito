# Підписані коміти

Вмикайте підписування окремо для кожного репозиторію (**Налаштування →
шестерня репозиторію**): GPG, SSH або X.509, з ключем на ваш вибір. Gitcito
записує `commit.gpgsign`, `gpg.format` і `user.signingkey` для цього
репозиторію — той самий конфіг, який читає будь-який інший інструмент.

| | |
|---|---|
| ![Колонка підписів, світла тема](../../screenshots/signed-commits-light.webp) | ![Колонка підписів, темна тема](../../screenshots/signed-commits-dark.webp) |

Граф отримує окрему **колонку підписів**, яку можна переставляти:

| Значок | Означає |
|---|---|
| **Перевірено** | Добрий підпис ключем, якому git довіряє |
| **Не перевірено** | Підписано, але ключ невідомий або не підтверджений |
| **Прострочено** | Підпис або його ключ втратили чинність |
| *(нічого)* | Без підпису |

Теги теж можна підписувати — див. [Теги](tags.md).
