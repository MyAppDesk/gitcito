# 洞察

一个完全由你的 Git 历史构建出来的仪表盘——没有服务，没有账号，只是在本地读了 `git log`。从工具栏工具旁边的仓库设置齿轮打开它。

![洞察仪表盘](../../screenshots/insights.webp)

| 面板 | 它告诉你什么 |
|---|---|
| **概览卡片** | 每天的提交数、贡献者、被改动的文件、变更行数 |
| **每周变更量** | 新增对删除，一周一周地看 |
| **主要贡献者** | 按提交数，以及按行数 |
| **文件热点** | 改动最频繁的文件——点一个就跳进它的历史 |

整个页面都可以按 **30 天／90 天／1 年／全部时间**筛选。

热点是这里最有意思的一个面板：一个文件周复一周地待在那份榜单的顶端，通常告诉你的是关于设计的事，而不是关于编辑它的人的事。

想把同一段历史看成一段动态影像，见[延时回放](timelapse.md)。
