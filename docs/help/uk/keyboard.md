# Клавіатура та скорочення

Натисніть <kbd>?</kbd> будь-де, щоб отримати шпаргалку.

![Шпаргалка зі скороченнями](../../screenshots/cheatsheet.webp)

## Ті, що варто вивчити

| Клавіші | Що роблять |
|---|---|
| <kbd>⌘K</kbd> | [Палітра команд](search.md) — гілки, коміти, файли, дії |
| <kbd>⌘⇧F</kbd> | [Пошук по коду](search.md) в робочому дереві |
| <kbd>⌘⇧V</kbd> | [Сейф](vault.md) |
| <kbd>⌘O</kbd> / <kbd>Ctrl+O</kbd> | Відкрити репозиторій |
| <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd> | Відкрити налаштування |
| <kbd>⌘F</kbd> | Пошук усередині файлу чи діфа, який ви читаєте |
| <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> | Відкрити вибір репозиторію чи групи для нової вкладки |
| <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> | Закрити активну вкладку — або вікно, коли вкладок не лишилось |
| <kbd>⌘1</kbd>–<kbd>⌘9</kbd> / <kbd>Ctrl+1</kbd>–<kbd>Ctrl+9</kbd> | Перейти до вкладки за її позицією |
| <kbd>⌘⇧T</kbd> | Знову відкрити останню закриту вкладку |
| <kbd>?</kbd> | Ця шпаргалка |

## Рух без миші

| Де | Клавіші |
|---|---|
| Граф комітів | <kbd>↑</kbd> <kbd>↓</kbd> або <kbd>j</kbd> <kbd>k</kbd> |
| Списки файлів (коміт, WIP, стеш) | те саме |
| [Машина часу](time-machine.md) | <kbd>←</kbd> <kbd>→</kbd>, <kbd>⇧</kbd> — по десять, <kbd>Home</kbd>/<kbd>End</kbd> |
| [Центр керування](mission-control.md) | <kbd>↑</kbd><kbd>↓</kbd>, <kbd>Enter</kbd> — відкрити, <kbd>f</kbd>/<kbd>p</kbd> — фетч/пул, <kbd>/</kbd> — фільтр |
| Поле повідомлення коміту | <kbd>↑</kbd> <kbd>↓</kbd> згадує ваші недавні повідомлення |

## Перепризначення

**Налаштування → Скорочення**. Основні навігаційні скорочення (палітра, пошук по
коду, сейф, відкриття репозиторію, налаштування) можна перепризначити — із
виявленням конфліктів і скиданням кожного окремо.

Фіксовані скорочення з таблиці вище перепризначити не можна, і як _ціль_ вони
теж відхиляються: застосунок обробляє <kbd>⌘T</kbd>, <kbd>⌘W</kbd>,
<kbd>⌘1</kbd>–<kbd>⌘9</kbd>, <kbd>⌘⇧T</kbd>, <kbd>⌘S</kbd>, <kbd>⌘Z</kbd>,
<kbd>⌘⇧Z</kbd> і <kbd>⌘F</kbd> ще до того, як заглядає у ваші прив’язки, тож
скорочення, призначене на одне з них, виглядало б налаштованим і ніколи не
спрацьовувало б. Виберіть таке — і редактор скаже вам про це, замість того щоб
його прийняти.
