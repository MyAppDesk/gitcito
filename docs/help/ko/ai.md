# AI 기능

모든 AI 기능은 **선택 사항**이고, 공급자를 설정하기 전까지는 꺼져 있어요.
구체적으로 무언가를 요청하기 전에는 아무것도 어디로도 전송되지 않아요.

![AI 설정](../../screenshots/settings-ai.webp)

## 계정

**계정**은 모델에 닿는 하나의 경로입니다. 어떤 제공자인지, 어디로 접속하는지,
어떻게 인증하는지. 여러 개를 설정할 수 있고 서로 공존합니다 — 업무용 키, 개인
키, 로컬 모델, 이미 로그인해 둔 CLI.

프리셋은 **OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, Mistral** 과
**Ollama**(완전히 로컬)를 포함하며, OpenAI 호환 엔드포인트도 쓸 수 있습니다.

Anthropic 은 OpenAI 형태의 호출 대신 자체 `/v1/messages` API 를 사용합니다.
그래서 Claude 모델이 되는 것처럼 보이기만 하는 게 아니라 실제로 동작합니다.
Gemini 는 Google 의 OpenAI 호환 엔드포인트로 호출합니다.

### API 키 대신 구독 사용하기

이 컴퓨터에 이미 설치되어 로그인된 에이전트 CLI 로 답하게 하려면 제공자에서
**로컬 CLI** 를 고르세요 — `claude`, `gemini`, `codex`. Gitcito 가 프롬프트와
함께 실행 파일을 돌리고 그 답을 읽습니다. 붙여 넣을 API 키도, 저장되는 토큰도
없습니다.

Gitcito 는 사용자가 계정으로 설정한 명령만 실행하며, 셸이 아니라 항상 인자
배열로 넘깁니다. 그래서 diff 나 브랜치 이름 속 어떤 내용도 명령으로 해석될 수
없습니다.

> **이것이 API 키보다 더 사적인 것은 아닙니다.** 프롬프트는 키를 쓸 때와 똑같이
> 당신 계정으로 같은 업체에 전달됩니다. 달라지는 것은 청구와 설정이지, 텍스트가
> 가는 곳이 아닙니다.

명령이 `PATH` 에 없다면 계정에 전체 경로를 입력하세요.

### 어느 계정이 무엇을 담당할지

**어느 계정이 무엇을 담당할지** 아래에서 커밋 메시지, 채팅, 코드 설명, PR 리뷰,
충돌 해결, 위키, 테마 같은 각 기능이 저마다 다른 계정과 모델을 가리킬 수
있습니다. 기본값으로 두면 기본 계정을 따릅니다. 커밋 메시지에는 저렴한 모델,
채팅에는 강력한 모델이 흔한 배분입니다.

### 업그레이드 안내

계정이 생기기 전 버전에서 올라오면 이 안내가 한 번 표시됩니다. 쓰던 제공자와 키가 첫 계정이 되며, 손으로 다시 설정할 것은 없습니다.

![업그레이드 안내](../../screenshots/ai-accounts-notice.webp)

## 모델

모델 목록은 제공자에서 직접 가져오며 하루 동안 캐시됩니다. **모델 가져오기** 는
하나를 즉시 갱신합니다. 목록 아래에 Gitcito 가 출처를 밝힙니다 — 실시간인지,
캐시인지(언제 가져왔는지 포함), 내장 대체 목록인지와 그 이유.

목록은 채팅 요청에 답할 수 있는 모델로 걸러지므로 임베딩·음성·이미지 모델은
빠집니다. 모든 모델 입력란은 자유 입력도 받으므로 프리뷰 모델, 사설 배포,
방금 받은 Ollama 태그는 제공자가 나열하지 않아도 언제든 쓸 수 있습니다.

아직 키를 주지 않았거나 연결되지 않는 제공자는 빈 드롭다운 대신 작은 내장
목록으로 물러납니다.

순위를 매기거나 선별한 목록을 내놓는 제공자는 없습니다. 그래서 다듬는 일은 Gitcito 의 몫입니다 — 날짜가 붙은 스냅숏은 원본 모델로 접히고(`gpt-4o` 가 `gpt-4o-2024-08-06` 을 대신합니다), 남은 것은 알파벳순이 아니라 최신순으로 놓입니다. 목록 맨 아래의 **모든 모델 보기** 를 고르면 제공자가 돌려준 것이 전부 다시 나타납니다.

## 할 수 있는 일

| 기능 | 얻는 것 |
|---|---|
| **커밋 메시지** | 스테이징된 차이를 바탕으로, 원하는 스타일의 요약(과 선택적 본문) |
| **이 파일 설명하기** | 사이드 패널에 쉬운 말로 된 설명 — 보통, 간결, ELI5… 심지어 해적 말투까지 |
| **가리켜서 설명 보기** | <kbd>⇧</kbd>를 누른 채 식별자를 가리키면 한 줄 설명과, 근거로 삼은 줄들이 나와요 |
| **충돌 해결** | 편집 가능한 출력에 머지 결과를 제안해요 — 절대 자동으로 적용하지 않아요 |
| **PR 리뷰** | 차이를 요약하고 위험을 짚어 주며, 각 항목은 실제 `path:line`에 고정돼요 |
| **PR 설명** · **브랜치 이름** | 브랜치의 커밋과 차이를 바탕으로 초안을 만들어요 |
| **테마** · **그래프 팔레트** | 프롬프트로 생성해요 |
| **스마트 스테이징** | 이번 커밋에 무엇이 들어가야 할지 제안해요 |
| **AI 설정 마법사** | 저장소를 위한 어시스턴트 설정 파일(지침, 에이전트, 훅)을 생성해요 — 채팅 패널 머리글의 마법봉 버튼 |

## 추측이 아니라 근거

리뷰는 차이를 **라벨이 붙은 헝크**로 보고, 그 라벨만 인용할 수 있어요. 그다음
Gitcito가 각 라벨을 실제 파일과 줄로 되돌려 풀어요. 존재하지 않는 위치를
지어내는 모델은 **거부되고 다시 요청받기** 때문에, 지적 사항은 언제나 실제로
존재하는 코드를 가리켜요.

가리켜서 설명 보기는 토큰 주변의 번호가 매겨진 구간만 읽어요. 차이 화면에서는
화면에 보이는 헝크만 읽죠. 그래서 정의가 다른 곳에 있으면 지어내는 대신 그렇다고
말해요. 답변은 파일 버전별로 캐시돼요.

**마스킹된 비밀 파일은 절대 전송되지 않아요.** 비밀 마스킹 규칙이 적용되는
파일도 마찬가지예요.

## 한계

- 내장 대체 목록은 릴리스 사이에 낡습니다. 실시간 조회가 바로 그것을 위한
  것이고, 대체 목록은 조회 자체가 불가능한 경우만 메웁니다.
- 채팅 가능한 모델로 거르는 일은 이름으로 하므로, 이름이 특이한 채팅 모델은
  걸러질 수 있습니다. 그럴 때는 직접 입력하세요.
- CLI 계정은 CLI 가 알려주지 않는 한 토큰 사용량을 보고할 수 없습니다. 설정의
  사용량·비용 수치는 그런 호출을 적게 셉니다.
- CLI 응답은 API 를 직접 호출하는 것보다 느립니다. 요청마다 세션을 통째로 새로
  띄우기 때문입니다.
- 키는 계정별로 OS 키체인에 저장됩니다. 계정을 삭제하면 그 키도 삭제됩니다.
