# Клавиатура и горячие клавиши

Нажмите <kbd>?</kbd> где угодно — откроется шпаргалка.

![Шпаргалка по горячим клавишам](../../screenshots/cheatsheet.webp)

## Те, что стоит выучить

| Клавиши | Что делают |
|---|---|
| <kbd>⌘K</kbd> | [Палитра команд](search.md) — ветки, коммиты, файлы, действия |
| <kbd>⌘⇧F</kbd> | [Поиск по коду](search.md) во всём рабочем дереве |
| <kbd>⌘⇧V</kbd> | [Сейф](vault.md) |
| <kbd>⌘O</kbd> / <kbd>Ctrl+O</kbd> | Открыть репозиторий |
| <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd> | Открыть настройки |
| <kbd>⌘F</kbd> | Поиск внутри файла или диффа, который вы читаете |
| <kbd>⌘T</kbd> / <kbd>Ctrl+T</kbd> | Открыть выбор репозитория или группы для новой вкладки |
| <kbd>⌘W</kbd> / <kbd>Ctrl+W</kbd> | Закрыть активную вкладку — а когда вкладок не осталось, окно |
| <kbd>⌘1</kbd>–<kbd>⌘9</kbd> / <kbd>Ctrl+1</kbd>–<kbd>Ctrl+9</kbd> | Перейти на вкладку по её позиции |
| <kbd>⌘⇧T</kbd> | Вернуть последнюю закрытую вкладку |
| <kbd>?</kbd> | Эта шпаргалка |

## Перемещение без мыши

| Где | Клавиши |
|---|---|
| Граф коммитов | <kbd>↑</kbd> <kbd>↓</kbd> или <kbd>j</kbd> <kbd>k</kbd> |
| Списки файлов (коммит, WIP, стеш) | то же самое |
| [Машина времени](time-machine.md) | <kbd>←</kbd> <kbd>→</kbd>, <kbd>⇧</kbd> — на десять, <kbd>Home</kbd>/<kbd>End</kbd> |
| [Центр управления](mission-control.md) | <kbd>↑</kbd><kbd>↓</kbd>, <kbd>Enter</kbd> — открыть, <kbd>f</kbd>/<kbd>p</kbd> — фетч/пул, <kbd>/</kbd> — фильтр |
| Поле сообщения коммита | <kbd>↑</kbd> <kbd>↓</kbd> достают ваши недавние сообщения |

## Переназначение

**Настройки → Горячие клавиши**. Основные навигационные сочетания (палитра, поиск
по коду, сейф, открытие репозитория, настройки) переназначаются, с обнаружением
конфликтов и сбросом по каждому сочетанию отдельно.

Фиксированные сочетания из таблицы выше переназначить нельзя, и в качестве
_цели_ они тоже отвергаются: приложение отвечает на <kbd>⌘T</kbd>, <kbd>⌘W</kbd>,
<kbd>⌘1</kbd>–<kbd>⌘9</kbd>, <kbd>⌘⇧T</kbd>, <kbd>⌘S</kbd>, <kbd>⌘Z</kbd>,
<kbd>⌘⇧Z</kbd> и <kbd>⌘F</kbd> раньше, чем заглядывает в ваши привязки, так что
назначенное на них сочетание выглядело бы установленным и никогда бы не
срабатывало. Выберите такое — и редактор скажет об этом, вместо того чтобы молча
согласиться.
