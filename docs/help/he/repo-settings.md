# הגדרות לכל מאגר

הגלגל שליד כלי סרגל הכלים פותח הגדרות ששייכות ל**מאגר הזה**, לא לאפליקציה.

![הגדרות לכל מאגר](../../screenshots/repo-settings.webp)

| לשונית | מה יש בה |
|---|---|
| **כללי** | ענפים מוגנים (בחירה מרובה של ענפים, נשמרת בתצורת git), חתימה, תמונת הלשונית |
| **Config** | [הכללים שהמאגר הזה נושא איתו](repo-config.md) ב-`.gitcito.json`, והדוקטור שבודק אותם |
| **מידע** | הערות ושדות חופשיים על המאגר הזה, נשמרים מקומית |
| **כספת** | רשומות ה[כספת](vault.md) של המאגר הזה |
| **תובנות** | [לוח המחוונים של ההיסטוריה](insights.md) |
| **אנליטיקה** | מה עשיתם במאגר הזה, נספר מקומית |
| **היסטוריה** · **לוגים** | יומן הפעולות: כל פקודת git ש־Gitcito הריץ, עם הפלט שלה |

יומן הפעולות הוא הכן שבהם: כשמשהו מתנהג מוזר, הוא מציג את הפקודה המדויקת ואת
השגיאה המדויקת, כך שדיווח באג יכול לשאת עובדות במקום שמות תואר.

## תמונת לשונית

כשפתוחות עשר לשוניות, קשה להבדיל בין שמות שמתחילים אותו דבר — `api`,
`api-gateway`, `api-docs`. תמונה קטנה על הלשונית נמצאת מהר יותר מטקסט.

ב־**כללי**, לחצו על שדה התמונה. הוא מציג את התמונות של המאגר עצמו — PNG,‏
JPEG,‏ GIF,‏ WebP,‏ SVG,‏ ICO,‏ BMP ו־AVIF — כל אחת עם תמונה ממוזערת, וקבצים
ששמם כמו לוגו או סמל מופיעים ראשונים. הקלידו כדי לצמצם (`logo dark` מוצא את
`assets/logo-dark.png`), נווטו בחיצים ובחרו ב־Enter; או הקלידו נתיב ידנית.
הנתיב נשמר **יחסית לשורש המאגר**, כך שהתמונה הולכת עם המאגר בכל מקום שבו
התיקייה שלו נמצאת.

מה שהלשונית מציגה הוא בחירה לכל האפליקציה, ב־**הגדרות ← כללי ← לשוניות מאגרים
מציגות**:

| אפשרות | הלשונית מציגה |
|---|---|
| **תמונה ושם** (ברירת מחדל) | התמונה במקום סמל התיקייה, ואחריה השם |
| **שם בלבד** | סמל התיקייה והשם, כאילו אין תמונה |
| **תמונה בלבד** | רק התמונה; השם עובר לחלונית העצה |

מגבלות שכדאי להכיר:

- הרשימה כוללת את הקבצים ש־git רואה — במעקב ושלא במעקב, לא קבצים מוּתעלמים —
  ולכל היותר 40 בכל פעם; הקלידו כדי להגיע לשאר. אפשר עדיין להקליד ידנית תמונה
  שמתעלמים ממנה.
- תמונות מעל 1 MB, או כאלה שאי אפשר לקרוא, מוצגות מעומעמות ואי אפשר לבחור
  בהן: לסמל של 20 פיקסלים לא צריך יותר.
- מאגר **בלי** תמונה תמיד מציג את שמו, לא משנה איזו אפשרות נבחרה — לשונית ריקה
  הייתה בלתי ניתנת לזיהוי.
- אם הנתיב **שבור** — הקובץ נמחק, שונה שמו, אינו תמונה או גדול מדי — הלשונית
  חוזרת בשקט לשם, ולשונית ההגדרות הזו מציגה אזהרה מתחת לנתיב. שום דבר אחר לא
  מתלונן.
- התמונה נקראת פעם אחת בכל הפעלה. אם החלפתם את הקובץ באותו שם, פתחו שוב את
  לשונית ההגדרות הזו כדי לטעון אותה מחדש.
- ההגדרה נשמרת בהגדרות של Gitcito במחשב הזה, לא במאגר, ולכן חברי הצוות לא
  יורשים אותה.
