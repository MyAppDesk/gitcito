# ワークツリーとサブモジュール

## ワークツリー

ワークツリーとは、同じリポジトリの 2 つ目のチェックアウトを、それ専用のフォルダに
置いたものです。だから `feature/x` を置いたそのままの状態に保ちながら、`main` を
覗きに行けます。スタッシュは要りません。

- サイドバーからワークツリーを作成・削除できます。**ダブルクリック** すると、その
  ワークツリーが独立したタブとして開きます。右クリックには *ワークツリーを開く*、
  *フォルダーで表示*、削除があります。
- ローカルブランチを右クリック → **ワークツリーで開く** で、隣のフォルダに 1 つ作り、
  タブとして開きます。
- 1 つのブランチが同時に居られるワークツリーは 1 つだけなので、別のワークツリーが
  持っているブランチのチェックアウトは成立しません — git は *already used by
  worktree at …* と断ります。Gitcito はその代わりに連れて行きます。ブランチの
  メニューは *`x` をそのワークツリーで開く* と表示し、行をダブルクリックすると
  失敗する代わりにそのワークツリーのタブが開きます。

## サブモジュール

サブモジュールの追加、更新（init とチェックアウト）、URL の同期、削除ができ、それぞれの
状態がその場でわかります。

| 状態 | 意味 |
|---|---|
| **同期済み** | 親が記録しているコミットでチェックアウトされている |
| **変更あり** | 別の場所でチェックアウトされているか、作業ツリーが汚れている |
| **未初期化** | 記録はあるが、一度もチェックアウトされていない |
