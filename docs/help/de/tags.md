# Tags & Releases

Erstelle einen Tag von jedem beliebigen Commit aus:

| Art | Wann |
|---|---|
| **Leichtgewichtig** | Ein Zeiger. Reicht für eine persönliche Markierung |
| **Annotiert** | Trägt eine Nachricht, einen Autor und ein Datum — das, was ein Release sein sollte |
| **Signiert** | Annotiert, plus eine GPG/SSH-Signatur |

![Einen Tag erstellen: Name, optionale Nachricht und ob er signiert wird](../../screenshots/create-tag.webp)

Lösche Tags lokal, pushe sie, oder lösche sie auf dem Remote. Remote-Tags lassen
sich durchsehen, ohne sie vorher alle zu fetchen.

Auf GitHub werden veröffentlichte **Releases** in der Seitenleiste mit einer
Changelog-Seite aufgeführt — siehe [Hosting](hosting.md). Zum Verfassen der Notizen
nimm den [Changelog-Generator](changelog.md).
