# תפריט ההקשר של המאגר

לחצו לחיצה ימנית על מאגר — לשונית עצמאית, צ׳יפ בתוך קבוצה, צ׳יפ בתוך תיקייה
מקוננת, שורה ברשימת מסך הפתיחה/המשגר, או שורה ברשימה הנפתחת של המאגרים בסרגל
הכלים — ותקבלו את אותו תפריט ברמת המאגר. צ׳יפ הקבוצה עצמו עדיין פותח את תפריט
הקבוצה; הלחיצה צריכה לנחות על המאגר.

![תפריט ההקשר של המאגר על צ׳יפ בתוך קבוצה](../../screenshots/repo-context-menu.webp)

הרשימה הנפתחת של המאגרים בסרגל הכלים מציגה כל מאגר פתוח, בדיוק כפי שהרשימה
הנפתחת של הענפים מציגה ענפים. לחיצה שמאלית על שורה עוברת אל המאגר. לחיצה
ימנית על שורה (או על תג המאגר הנוכחי עצמו) נותנת כינוי, עצי עבודה, GitHub,
מסוף, הצגה, עורך והסרה. **פתיחת מאגר…** בתחתית פותחת את המשגר.

![לחיצה ימנית על שורה ברשימה הנפתחת של המאגרים בסרגל הכלים](../../screenshots/repo-dropdown-context-menu.webp)

## מה כל פעולה עושה

| פעולה | תוצאה |
|---|---|
| **יצירת כינוי…** / **שינוי כינוי…** | שם תצוגה בלבד. Gitcito לעולם אינו משנה שם או מזיז את התיקייה בדיסק. אותו כינוי מלווה את המאגר בין לשוניות, קבוצות וסביבות עבודה. |
| **הסרת כינוי** | מוצג כשקיים כינוי. משחזר את שם התיקייה. |
| **הצגת עצי עבודה** | ממקד את המאגר הזה ופותח את מדור עצי העבודה בסרגל הצד. |
| **עץ עבודה חדש…** | אותה תיבת יצירת עץ עבודה שמשמשת מענף. מושבת כשהנתיב חסר או כשמיזוג/ריבייס/צ׳רי־פיק/ריוורט בעיצומו. |
| **העתקת שם המאגר** | מעתיקה את שם התיקייה הקנוני, לא את הכינוי. |
| **העתקת נתיב המאגר** | מעתיקה את הנתיב המוחלט. |
| **הצגה ב-GitHub** | ‏origin אם הוא github.com, אחרת הרימוט הראשון של GitHub שאפשר לפענח. מושבת כשאי אפשר לגזור אף אחד. |
| **פתיחה במסוף** | פותחת את המסוף של Gitcito עם המאגר הזה כתיקיית העבודה. |
| **הצגה ב-Finder / בסייר הקבצים** | מדגישה את תיקיית המאגר במנהל הקבצים של המערכת. |
| **פתיחה בעורך חיצוני** | העורך שהוגדר בהגדרות. גלוי אך מושבת עד שמגדירים אחד. |
| **הסרה…** | סוגרת את הלשונית או מסירה את הצ׳יפ מהקבוצה. משתמשת באותה אזהרת עבודה שלא נכנסה לקומיט כמו כפתור ה־**×**. היא לעולם אינה מוחקת קבצים מהדיסק. |

נתיב חסר או לא תקין משאיר את ההעתקה, הכינוי וההסרה זמינים, ומאפיר כל מה שהיה
פותח או בוחן את התיקייה.
