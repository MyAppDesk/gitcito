# Diff와 미리 보기

## Diff 읽기

| 토글 | 하는 일 |
|---|---|
| **통합 ↔ 분할** | 비교하고 싶을 땐 나란히, 그냥 읽고 싶을 땐 위아래로 |
| **단어 단위** | 수정된 줄 안에서 바뀐 토큰만 강조해요 — 옛것은 빨강, 새것은 초록 |
| **공백 무시** | 들여쓰기만 바뀐 부분을 감춰서 진짜 변경이 드러나게 해요 |
| **줄 바꿈** (분할 보기 전용) | 긴 줄을 가로 스크롤 대신 해당 열 안에서 줄 바꿈합니다 |
| **연동** (분할 보기, 줄 바꿈 끔) | 양쪽을 세로와 가로로 함께 스크롤합니다 — 끄면 각 열이 따로 움직입니다 |
| <kbd>⌘F</kbd> | diff 안에서 찾기. 다음/이전으로 넘어갈 수 있어요 |

줄 바꿈은 기본적으로 꺼져 있습니다. 한 줄이 한 행에 머무르므로 양쪽을 행 단위로
비교할 수 있고, 각 열은 자체 스크롤바로 가로 이동합니다. 긴 줄을 쫓기보다 읽고
싶을 때 켜세요. 대신 세 행으로 접힌 줄은 맞은편 줄과 나란히 놓이지 않습니다.
모든 토글은 파일과 세션을 넘어 상태를 기억합니다.

줄 바꿈이 꺼져 있으면 양쪽은 기본적으로 **연동**되어 스크롤됩니다 — 세로로는 행이
서로 마주 보게 유지되고, 가로로는 왼쪽 90번째 칸이 오른쪽 90번째 칸 위에 놓입니다.
들여쓴 블록과 들여쓰지 않은 블록, 모든 줄을 밀어낸 이름 변경처럼 양쪽이 어긋났을 때,
또는 같은 파일의 멀리 떨어진 두 영역을 비교하고 싶을 때는 연동을 풀고 각 절반을 자기
내용이 있는 곳에 두세요.

![단어 단위 강조가 적용된 분할 diff](../../screenshots/split-diff.webp)

모든 diff 위에는 [의미 기반 요약](semantic-diff.md)이 자리해요 — 줄 단위가 아니라
심볼 단위로 무엇이 바뀌었는지 알려 주는 거예요.

바뀐 이미지는 제대로 비교돼요. 나란히 놓거나, 스와이프 손잡이를 끌어서 이전과
이후 사이를 오갈 수 있어요.

## 무엇이든 미리 보기

**미리 보기** 모드는 파일의 소스를 보여 주는 대신 파일을 렌더링해요. Markdown,
Word(`.docx`), Excel(`.xlsx`), PDF, 동영상, 오디오, 이미지, 그리고 그 밖의 모든
것에는 구문 강조된 코드가 나와요.

![Markdown 미리 보기](../../screenshots/markdown-preview.webp)

## 매우 큰 파일

미리보기와 파일 보기는 파일 전체를 메모리에 불러오므로, 크기 상한(미리보기
32 MB, 텍스트 16 MB)을 넘는 파일은 거부하고 대신 파일이 얼마나 큰지
알려줍니다. **그래도 불러오기**는 해당 파일에 한해 상한을 해제합니다 — 열 수
없는 파일은 없으며, 큰 파일 로드가 옵트인으로 바뀔 뿐입니다. 수천 줄이 넘는
파일과 diff는 여전히 전부 렌더링되지만, 화면 밖으로 스크롤된 줄은 더 이상
배치·페인트되지 않으므로 거대한 lockfile diff가 노트북 메모리를 통째로
잡아먹는 일이 없어집니다.

![크기 상한을 넘은 파일과 그래도 불러오기 버튼](../../screenshots/file-too-large.webp)

## 파일 탭

왼쪽 사이드바의 **파일** 탭은 작업 트리 자체를 둘러봐요. 폴더에는 그 안에 든
것들을 합산한 상태 배지(추가 / 수정 / 삭제)가 붙어요.
