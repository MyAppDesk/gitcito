# Аналитика

Дашборд, собранный из вашей истории Git — без сервиса, без аккаунта, только
`git log`, прочитанный локально. Открывается из шестерёнки настроек репозитория
рядом с инструментами на панели.

![Дашборд аналитики](../../screenshots/insights.webp)

| Панель | Что показывает |
|---|---|
| **Карточки сводки** | Коммитов в день, участники, затронутые файлы, изменённые строки |
| **Недельный оборот** | Добавления против удалений, неделя за неделей |
| **Топ участников** | По коммитам и по строкам |
| **Горячие файлы** | Наиболее изменяемые файлы — клик по одному перебрасывает в его историю |

Всё это фильтруется по **30 дням / 90 дням / 1 году / всему времени**.

Горячие точки — самая интересная панель: файл, который держится в верху этого
списка неделя за неделей, обычно говорит вам что-то о дизайне, а не о людях,
которые его правят.

Та же история в виде движущейся картинки — см. [таймлапс](timelapse.md).
